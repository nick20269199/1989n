## 反馈回路设计（现在的缺口）

这是生态闭环最关键的部分，当前完全没有：

```
早盘预测 ──→ 午盘验证 ──→ 修正下午策略
收盘复盘 ──→ 更新持仓数据库 ──→ 隔夜计划引用最新数据
隔夜计划 ──→ 第二天执行 ──→ 收盘复盘检查是否按计划执行
止损触发 ──→ 追因审计 ──→ 规则库修正
```

**新增一个轻量反馈任务（17:05运行）**：
1. 对比今天晨报预测 vs 实际走势
2. 检查今天操作是否按隔夜计划执行
3. 记录偏差 → 写入知识库
4. 一句话结论写进收盘复盘
