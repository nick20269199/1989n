# 晨报 v2.0 设计方案

> 基于：PDF范文结构 + 用户画像(2026-05-18) + 现有morning_brief.py代码

---

## 新版结构

### 【今日导读】 ← 新增
4-5条核心头条，每条一行+受益标的，让你30秒抓住重点

### 一、持仓影响 ← 保留增强
现有持仓映射保留，增加"今日计划"建议（基于规则硬判断，不是模糊建议）

### 二、专题聚焦 ← 新增（替代散装"重要政策/行业"）
对有深度影响的主题展开（如SpaceX IPO、茅台涨价），标注相关标的

### 三、行业要闻 ← 大幅增强
每条新闻标注受益A股标的（用全市场股票名称匹配），取代原来零散的公告列表

### 四、公告精选 ← 重新组织
- 日常公告（合同/中标/投资）
- 地雷阵（减持汇总） ← 新增
- 解禁提醒 ← 新增
- 异动澄清 ← 新增

### 五、全球市场 ← 保留
美股指数+龙头板块+（可加商品/汇率）

### 六、今日关注+风险 ← 保留增强

---

## 技术实现

### 需要新增的能力

| 能力 | 实现方式 | 难度 |
|------|---------|------|
| 新闻→A股标的标注 | 建股票名称→代码查表，新闻标题匹配 | 低（已有get_stock_a_code_name） |
| 今日导读 | 从新闻中选热度最高的4-5条 | 低 |
| 地雷阵 | 已有extract_announcements，只是没展示 | 低 |
| 专题聚焦 | 识别热点主题+聚合相关新闻 | 中 |
| 输出时间改08:30 | 改cron时间+改代码时间判断 | 低 |

### 不需要改的
- 美股数据采集（akshare已有，正常工作）
- 持仓映射逻辑（已有concept_mapping）
- 飞书发送（已有feishu_sender路由）
