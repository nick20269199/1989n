## 2级管线（铁律）

管线调用顺序：
```
对话启动
  → 检查是否是交易日 + 是否涉及持仓/交易/分析话题
  → 是 → 执行 轻量级管线（/verify-data）
       → 无异常 → 继续对话
       → 有异常 → 报告异常项，继续对话
       → 硬止损触发 → 第一段就报告
  → 否 → 跳过
```

### 轻量级（自动触发）

**触发条件**: 交易日首次对话涉及持仓/交易/分析话题时自动执行
**执行**: `/verify-data` skill
**耗时**: ~30s
**产出**: 数据源状态 + 持仓PnL快照 + 错误检查
**硬约束**: 超30秒自动截断，有已查到的数据直接出

### 深度级（手动触发）

**触发条件**: 
- 用户说"分析一下XXX"、"扫一遍持仓"、"看看XX"
- 每次触发对抗审查（adversarial-review）前先跑深度级

**执行**: 
1. `daily_task.py position_check` → 三层持仓检查
2. `daily_task.py tech_scan` → 技术形态+VCP扫描
3. `data_source_router` / `stock_quote.py` → 实时价
4. 按5维度框架出分析报告
**耗时**: 30s-2min
**产出**: 完整5维度分析报告

### 不可用时的备用方案

- MCP(东方财富)挂 → 切 data_source_router(新浪/腾讯/搜狐)
- data_source_router 全挂 → 标注"今日所有数据源不可用",不做分析
- 某个脚本报错 → 读 last_error.txt,尝试修复后重跑一次

## 分析维度（每次分析必须覆盖）

1. **技术面** — 价格趋势、均线、MACD、RSI、成交量
2. **资金面** — 主力资金流向、超大单/大单/中单/小单分布
3. **题材面** — 所属概念板块表现、板块资金净流入
4. **消息面** — 多源新闻（财联社+东方财富+新浪）
5. **情绪面** — 市场情绪指标、涨停/跌停分布

## 质量标准

- 每份报告：数据+分析+建议 三段式
- 持仓分析三方交叉校验（多源数据对比）
- 盘前资讯架构：隔夜外盘+政策+题材+个股公告
- 盘中实时监控：量能异动+资金突变+涨停板变化
- 置信度分级：高(>80%) / 中(60-80%) / 低(<60%)
- R7 超大单监控：主力异动跟踪

## 数据源优先级

1. 财联社（新闻主源）
2. 东方财富（行情+资金）
3. 新浪财经（新闻补充）
4. StockAPI（数据接口）
5. 腾讯证券（行情备选）
