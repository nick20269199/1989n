## 📋 飞书模块总览

这个项目深度集成了飞书开放平台，构建了一套 **"多Bot消息收发 + 文档推送 + 表格同步 + 事件处理"** 的完整体系。以下是各模块的功能：

---

### 🤖 1. 飞书 Bot（消息机器人）

| 文件 | 功能 |
|------|------|
| **`feishu_bot.py`** | v1 版 Bot，WebSocket 长连接，支持多 Bot 模式（primary/passive），回复自动分类（行情/持仓/风险/问答），卡片消息彩色展示 |
| **`feishu_bot_v2.py`** | v2 版 Bot，**部门路由**（6个部门 + AI fallback），@mention 过滤，指数退避自动重连，健康监控 |
| **`feishu_multi_bot.py`** | 多 Bot 启动器，同时运行 **3 个 Bot 实例**（"街溜子"、"海盗船长"、"当前Bot"），各自独立进程 |

**3个Bot的分工：**
- **街溜子** — `cli_a952c17c65f85cb2`
- **海盗船长** — `cli_a935549489381bc4`
- **当前Bot** — 从 `.env` 读取默认配置

---

### 📨 2. 消息发送层

| 文件 | 功能 |
|------|------|
| **`feishu_im_sender.py`** | 底层 IM API 封装，通过 `tenant_access_token` 发送文本/卡片消息，带 token 缓存（7000s 刷新） |
| **`feishu_sender.py`** | 上层封装，支持路由名发送（如 `news`），**速率限制**（15条/分钟），紧急告警（红色高优先级） |
| **`feishu_bridge.py`** | 桥接服务，后台运行，将 NLP 分析报告和告警实时推送到飞书 |

---

### 📄 3. 文档与表格

| 文件 | 功能 |
|------|------|
| **`feishu_doc.py`** | 飞书文档创建器，把 Markdown 分析报告转为飞书 Docx 文档，支持标题/列表/代码块/引用等格式，通过 IM API 推送文档链接到群 |
| **`feishu_table_sync.py`** | 飞书表格同步，通过 Sheets API 将 **持仓/报告/新闻** 数据同步到飞书电子表格，自动刷新 Token |

---

### 🔄 4. 双向通信（Inbox/Outbox）

| 文件 | 功能 |
|------|------|
| **`feishu_inbox.py`** | **Bot ↔ Claude Code 双向桥接**：Bot 收到的消息写入 `feishu_inbox.jsonl`，Claude Code 的回复写入 `feishu_outbox.jsonl`，Bot 自动发送 |

---

### 🧠 5. AI 引擎

| 文件 | 功能 |
|------|------|
| **`feishu_claude_agent.py`** | Tool-calling 引擎，通过 DeepSeek API 驱动，支持代码执行 + 本地数据读取，处理飞书消息中的复杂查询 |

---

### 🔐 6. 安全与事件

| 文件 | 功能 |
|------|------|
| **`feishu_event_handler.py`** | 飞书事件订阅处理，AES-256-CBC 解密、URL 验证、消息事件解析 |

---

### 🔄 工作流程

```
用户发消息 → 飞书群
    ↓
feishu_bot_v2.py (WebSocket 接收)
    ↓
部门路由 (dept_handlers) → 6个部门分类
    ↓
feishu_inbox.py (写入 inbox.jsonl)
    ↓
feishu_claude_agent.py (DeepSeek AI 处理)
    ↓
feishu_inbox.py (写入 outbox.jsonl)
    ↓
feishu_im_sender.py (发送卡片/文本消息回群)
```

同时，**定时任务**通过 `feishu_bridge.py` / `feishu_sender.py` 推送行情分析、持仓报告、风险提醒等到群里；**长报告**通过 `feishu_doc.py` 转为飞书文档链接；**数据同步**通过 `feishu_table_sync.py` 写入飞书表格。
