# Branch 8: 分析哲学: 语言与逻辑 — 跨域连接

## 与物理

| 语言哲学 | 物理 | 连接 |
|---------|------|------|
| 逻辑实证/可验证性 | 物理方法论 | 维也纳学派的"可验证性"=物理理论的经验基础 |
| 可能世界语义学(Kripke) | 多世界解释(Everett) | 可能世界≈量子多世界,但前者是逻辑概念后者是物理假设 |
| 意义整体论(Quine) | 理论整体论(Duhem-Quine) | 物理假设不能单独验证=信念网络整体面对经验 |
| 逻辑与语言的结构 | 信息/熵(Shannon) | Shannon信息论=意义的载体但Shannon明确排除"意义" |
| 反事实条件句(Lewis) | 因果关系(Counterfactual) | 因果=反事实依赖,与可能世界比较同构 |
| 因果指称理论(Kripke) | 因果链在物理中的对应 | 初始条件→因果链→指向参考系 |

## 与经济学

| 语言哲学 | 经济学 | 连接 |
|---------|--------|------|
| Grice含义/会话合作 | 博弈论/信号博弈 | 会话的合作原则=博弈中的信号传递 |
| 言语行为(Austin/Searle) | 制度经济学/言语制度 | "宣布"某事=创造制度的言语行为(公司/合同/货币) |
| 翻译不确定性(Quine) | 理性选择/偏好不可比 | 翻译的不确定性=偏好的不可通约性 |
| 规则遵循 | 制度/规范演化 | 规则如何在社群中维持/演化=制度的博弈论 |
| 可能世界/反事实 | 决策理论/预期效用 | 决策=在可能结果(可能世界)间的比较 |
| 分析的/综合的 | 实证vs规范经济学 | 事实判断和价值判断的界限(和争议) |

## 与中华文明

| 语言哲学 | 中华文明 | 连接 |
|---------|---------|------|
| 正名(孔子) | 语言哲学的原型 | "名不正则言不顺"=名称的意义决定社会的秩序 |
| 白马非马(公孙龙) | 指称/概念分析 | 公孙龙≈Russell的摹状词理论: "白马"不是"马"=内涵不同 |
| 坚白同异(惠施/公孙龙) | 属性vs实体 | 石的坚和白可以分离=属性的独立存在性 |
| 言不尽意(易传/庄子) | 语言的界限 | "书不尽言言不尽意"≈Wittgenstein不可说的 |
| 名实之辩(先秦) | 概念与实在的对应 | 名实关系=中国哲学对meaning-reference问题的千年讨论 |
| 六经注我/我注六经 | 意义=使用/诠释 | 经典的意义不在历史原文而在当代使用 |
| 礼/名分 | 言语行为/制度事实 | 礼=言语行为在制度层面的固化(命名即创造) |

## 与认知科学

| 语言哲学 | 认知科学 | 连接 |
|---------|---------|------|
| 思想语言假说(Fodor) | 心理表征/计算主义 | 思想语言=LOT(思维的语言)≈认知的计算表征理论 |
| 语言本能(Pinker/Chomsky) | 先天vs后天 | 语言=器官还是学习?=认知科学的核心辩论 |
| Grice意图识别 | 心智理论(ToM) | 理解说话者意图=理解他人的心智状态 |
| 规则遵循悖论 | 程序性知识/机器学习 | 机器学习中的"规则"不是哲学中的"规则" |
| 概念=推理角色 | 语义网络/概念空间 | 概念=在语义网络中的位置=统计关系模式 |
| 意义社会分工 | 分布式认知/文化学习 | 意义在社群中的分布=知识的社会性 |

## 与宗教

| 语言哲学 | 宗教 | 连接 |
|---------|------|------|
| 逻辑实证/可验证 | 宗教信仰的语言 | 宗教语言的认知意义vs情感意义(Ayer/逻辑实证批判宗教语言) |
| Tractatus神秘主义(Wittgenstein) | 神秘的不可说 | "确实有不可说的东西,它们显示自己"=神秘主义的逻辑界限 |
| 语言游戏(Wittgenstein) | 宗教语言游戏 | 宗教语言=一种语言游戏(祈祷/忏悔/赞美=言语行为) |
| 信仰的语言(Phillips) | 维特根斯坦式宗教哲学 | 信仰不是不完全的知识而是不同的语言游戏 |
