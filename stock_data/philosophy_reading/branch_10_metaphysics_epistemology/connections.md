# Branch 10: 形而上学与知识论 — 跨域连接

## 与物理

| 形而上学/知识论 | 物理 | 连接 |
|---------------|------|------|
| 本体论承诺 | 物理实在论 | 物理实体(波函数/场/弦)的本体论地位=形而上学核心问题 |
| 反事实因果 | Pearl因果图/干预 | Woodward干预主义=Pearl的do-运算在哲学中的对应 |
| 必然/可能 | 物理定律/对称性 | 物理必然性=在自然规律下所有可能中的必然 |
| 时间本体A/B理论 | 相对论的时间/块宇宙 | 特殊相对论支持B理论(块宇宙)的时间观 |
| 随附性 | 层展/多尺度 | 高属性随附低≈宏观涌现依赖于微观 |
| 自由意志/决定论 | 量子不确定/经典决定 | 自由意志≈量子随机/宏观不可约 |

## 与中华文明

| 形而上学/知识论 | 中华文明 | 连接 |
|---------------|---------|------|
| 本体论 | 名实之辩(先秦) | "名"≈范畴,"实"≈本体,名实关系=本体论的基本问题 |
| 可能世界/反事实 | 经权/常变 | 经=基本原则(在所有可能中),权=变通(在特定可能中) |
| 因果 | 感应/感通(易传) | 因果的中华版本="感而遂通天下之故" |
| 知识论 | 格物致知(大学/朱熹) | 知=通过接触事物获得,不是先天观念 |
| 怀疑论 | 六合之外存而不论(庄子) | 悬搁不确定领域≈实用主义怀疑论 |
| 德性知识论 | 智仁勇(三达德) | 德性=认知+情感+行动的合一 |

## 与经济学

| 形而上学/知识论 | 经济学 | 连接 |
|---------------|--------|------|
| 反事实因果 | 反事实/因果推断 | 计量经济学的因果识别=反事实的统计版本 |
| 知道/相信 | 预期/信念 | 经济主体的"信念"决定决策=知识论的应用 |
| 不确定/风险 | Knight不确定/风险 | 不知道概率(不确定)vs知道概率(风险) |
| 模态/可能 | 决策理论/可能结果 | 决策=在不同的可能结果之间选择 |
| 怀疑论 | 怀疑/审计 | 审计=怀疑论在制度层面的实践 |

## 与认知科学

| 形而上学/知识论 | 认知科学 | 连接 |
|---------------|---------|------|
| 知识=可靠的信念 | 可靠认知过程 | 功能主义=认知过程的可信性决定知识 |
| 德性知识论 | 认知能力/元认知 | 理智德性≈元认知能力的监控 |
| 反事实 | 反事实思维/模拟 | 反事实=心理模拟的认知能力 |
| 怀疑论 | 认知偏差/盲点 | Agent的"盲点"=怀疑论在认知中的体现 |
| 先验/后验 | 先天/后天认知 | 认知的先天结构(康德)vs后天数据驱动 |
| 证成 | 推理/解释 | 证成=能推理出理由=解释自己判断的能力 |
