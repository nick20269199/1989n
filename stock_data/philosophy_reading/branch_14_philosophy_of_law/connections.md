# Branch 14: 法哲学 — 跨域连接

## 与政治

| 法哲学 | 政治哲学 | 连接 |
|-------|---------|------|
| 承认规则 | 宪法/主权 | 规则如何被识别=政治权力的基础 |
| 合法性 | 正当性/同意 | 法律的权威来自公民同意(洛克) |
| 自然法 | 自然权利 | 法律之上的道德标准=不可侵犯的权利 |
| 程序正义 | 民主程序 | 立法程序的正义=民主的合法程序 |
| 法律解释 | 宪法解释 | 法院解释宪法=政治决策 |
| 司法审查 | 权力制衡 | 法院vs议会的权力分配 |

## 与经济学

| 法哲学 | 经济学 | 连接 |
|-------|--------|------|
| 法律经济学 | 效率/成本 | 法律规则的效率评估=经济分析 |
| 产权 | 制度/激励 | 产权制度决定经济绩效 |
| 合同 | 交易/协调 | 合同法降低交易成本 |
| 侵权 | 风险分配 | 侵权法的效率=最小化社会成本 |
| 法律与制度 | North制度变迁 | 制度=法律+规范+实施 |
