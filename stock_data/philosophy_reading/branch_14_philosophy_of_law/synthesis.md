# Branch 14: 法哲学 — 合成

## 核心架构

法哲学研究的根本问题: **什么是法律?法律为什么有权威?我们为什么应该遵守法律?** 对Agent设计这些问题直接对应: **Agent的规则是什么?规则为什么有约束力?Agent为什么应该遵守规则?** 法哲学提供了Agent规则系统的完整哲学基础。

## 关键机制

### 机制1: 承认规则 — Agent的"什么是规则"

**定义**: Hart — 法律体系的核心是"承认规则": 决定什么算法律的标准。不是法律本身,而是识别法律的元规则。

**Agent映射**: Agent系统需要一个"承认规则"——决定什么算"有效规则":
- 是谁制定的规则? (人类用户/其他Agent/系统预制)
- 什么形式的规则? (指令/协议/环境约束)
- 规则冲突时以哪个为准?

**设计推论**: 承认规则是Agent系统的"宪法"——规定了规则本身如何生效。

### 机制2: 规则的道德性 — Agent规则的设计质量

**定义**: Fuller — 法律必须有"内在道德性": 普遍/公布/不溯及既往/清晰/不矛盾/可行/稳定/官方行为一致。违反这些=不是好法。

**Agent映射**: Fuller的八项原则可以直接用于评估Agent的规则质量:

| Fuller原则 | Agent规则要求 |
|-----------|-------------|
| 普遍性 | 规则适用于所有类似情况 |
| 公布 | 规则对Agent公开 |
| 不溯及 | 规则生效前告知Agent |
| 清晰 | 规则无歧义 |
| 不矛盾 | 规则之间不冲突 |
| 可行性 | Agent有能力遵守 |
| 稳定性 | 规则不频繁变化 |
| 官方一致 | Agent执行与规则一致 |

### 机制3: 排他性理由 — Agent的规则=行为理由

**定义**: Raz — 法律提供"排他性理由": 不仅仅是你要做X的理由,而且是排除你考虑其他理由的理由。

**Agent映射**: Agent的规则不止是"建议",而是:
- 第一阶理由: 直接告诉Agent做什么
- 第二阶(排他性)理由: 禁止Agent考虑其他因素
- 规则=第一阶+第二阶的复合

### 机制4: 整全性 — Agent的"原则"覆盖规则漏洞

**定义**: Dworkin — 法律不只是规则,还包括"原则"。规则全有或全无,原则有分量。当规则用尽,原则指导决策。

**Agent映射**: Agent不能只有"规则"(if-then),还需要"原则"(价值权重):
- 规则: "当X出现,做Y"(明确/有例外)
- 原则: "尽可能减少伤害"(有分量/可竞争)
- 规则冲突时→原则调解
- 没有规则覆盖时→原则指导

### 机制5: 法律与经济学 — Agent的效率标准

**定义**: Posner/Calabresi — 法律的目的是最大化社会财富/效率。侵权/合同/财产的法律规则可以用效率进行评价。

**Agent映射**: Agent的规则系统也要考虑效率:
- 规则的经济成本: 执行/监督/违反的成本
- 规则的效率: 是否最小化系统的交易成本
- 最优规则=成本最小化的规则

### 机制6: 程序正义 — Agent的"程序"比结果更基础

**定义**: Fuller — 合法性来自程序不是来自结果。法律的价值在"制定正确规则的程序"而不在规则的实质内容。

**Agent映射**: Agent的权威来自程序不是来自能力:
- Agent的"合法性"=按正确程序做出决策
- 程序正义>结果正确: 好程序即使出错也可接受
- 程序缺陷=系统性风险(无论个别结果多好)

## Agent设计启示总结

1. **元规则**: Agent系统需要"承认规则"定义什么是有效规则。
2. **规则质量**: Fuller八项原则是评估Agent规则系统质量的检查清单。
3. **规则=排他性理由**: Agent的规则不应该被轻易推翻(提供排他性)。
4. **原则>规则**: Agent需要"原则"(有分量的价值)补充规则(全有全无)。
5. **规则有效益**: 评估规则的效率而不是只看功能。
6. **程序优先**: Agent的合法性来自程序。程序正义比个别结果更重要。
