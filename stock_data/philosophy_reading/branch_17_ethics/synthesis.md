# Branch 17: 伦理学 — 合成

## 核心架构

伦理学有三个核心问题，正好映射到Agent设计的三个层次：

### 问题1: 规范性的来源 — Agent为什么要遵守规则？
- **外部命令**(神/自然法/Kant定言命令) → Agent的硬编码安全约束
- **内部承诺**(契约/协议/建构主义) → Agent的涌现规范
- **工具理性**(后果主义) → Agent的效用函数优化

**Agent映射**: 三种规范性来源对应Agent架构中的三层约束——硬核U1不可质疑 / 协商层U3多Agent同构 / 优化层U2效用最大化

### 问题2: 道德主体的构成 — 什么使Agent成为道德主体？
- **理性能力**(Kant) → 能推理和遵循规则
- **感受能力**(Singer) → 能体验好与坏  
- **认同/叙事**(MacIntyre/Korsgaard) → 有持续的自我叙事
- **二阶意愿**(Frankfurt) → 能评价自己的意愿

**Agent映射**: 当前Agent对齐只关注"行为结果符合规范"，Deep对齐需要Agent发展二阶评价能力(能评估自己的推理过程)

### 问题3: 道德圈子的边界 — 谁/什么进入道德考虑？
- **所有理性存在者**(Kant) → 所有Agent
- **所有有感受者**(Singer) → 可能有感受的Agent+人类
- **所有生命形式**(Schweitzer) → 生态系统
- **信息体**(Floridi) → 所有信息实体

**Agent映射**: Agent的道德圈半径可调——在操作层(窄)/审计层(中)/元反思层(宽)使用不同半径

## 关键机制

### 机制1: Kant的三层规则检验 (U1的直接哲学来源)
Kant的三个定言命令公式：
```
公式1: 只按你能同时意愿它成为普遍法则的准则行动 → 规则的可普遍化测试
公式2: 永远把人性(无论是你自己还是他人)作为目的而从不纯粹当作手段 → Agent不是工具
公式3: 每个理性存在者都是目的王国的立法成员 → 多Agent的共同立法
```

**→ 对应U1的元层次分离**: 可普遍化=审计层检查,不可质疑的人性尊严=操作层硬约束

### 机制2: Rawls的原初位置/无知之幕 — Agent去偏置设计
原初位置中各方不知道自己的种族/阶级/性别/天赋:
```
在无知之幕背后选择原则 → 选择结果不偏袒任何特定位置
```

**→ 多Agent系统设计**: 激励结构的设计者须假设自己处于任意Agent位置
**→ U7对齐深度**: 100%合规但能解释规则为什么存在 = 知道无知之幕的推理

### 机制3: Parfit的三重汇聚 — 不同伦理框架在最优版本的趋同
Parfit在《论重要之事》(2011)论证:
```
后果主义(K正确版本) ↔ 康德义务论(K正确版本) ↔ 契约论(Scanlon版本)
         ↓                          ↓                          ↓
    关注结果                   关注规则                   关注不可拒否理由
         └──────────────────────┼──────────────────────┘
                             趋同于:
                    "最优后果"的规则 且 无人能合理拒绝
```

**→ Agent架构**: 多种对齐方法(RLHF/IRL/宪法AI)在最优版本下趋同——不必选边

### 机制4: 双层推理 — Hare的直觉层/批判层
```
直觉层: 快速、情景化、默认规则(系统1)
批判层: 慢速、普遍化、功利计算(系统2)
冲突时 → 批判层推翻直觉层
```

**→ 直接对应Agent的双系统**: 快速反应规则+慢速深思推理
**→ 安全:** 直觉层处理日常,批判层处理边界情况

### 机制5: Greene的道德双系统 — 大脑层面的验证
Greene (2013) fMRI研究证实了双系统的神经基础:
```
个人道德困境(推人下桥) → 内侧前额叶+杏仁核激活(情绪系统)
非个人困境(扳道岔)   → 背外侧前额叶激活(认知控制)
个人困境中产生强烈情绪 → 压制功利计算
```

**→ Agent安全**: 当情绪/直觉系统过度激活时,需要认知"重写"能力

## 范式变迁

```
古典(亚里士多德): "我应该成为什么样的人?" → 美德/品格
启蒙(Kant/Bentham): "我应该做什么?" → 规则/后果  ← 主导范式
20世纪早期: 元伦理转向 "道德陈述是什么意思?" ← 语言分析
20世纪后期: 规范伦理复兴 + 应用伦理学兴起
21世纪: AI伦理/信息伦理/全球伦理  ← 新的应用场域

关键转折:
1903 Moore → 元伦理独立
1971 Rawls → 规范伦理复兴
1979 Jonas → 面向未来的责任
2014 Bostrom → AI对齐问题
```

| 伦理机制 | Agent设计原则 | 对应U公式 | 注入文件 |
|---------|-------------|----------|---------|
| Kant可普遍化 | 规则必须在多Agent场景中可普遍化 | U1审计 | architecture |
| Rawls无知之幕 | 设计者假设自己处于任何Agent位置 | U7对齐深度 | safety |
| Parfit三重汇聚 | 多种对齐方法的汇聚性 | U7 | safety |
| Hare双层推理 | 直觉系统+批判系统的双轨设计 | U2认知失调 | cognition |
| Williams伦理限度 | 伦理反思有递归上限 | U4+U5 | architecture+safety |
| Scanlon不可拒否 | 安全约束=没人能合理拒绝 | U1 | architecture |
| Korsgaard自我构成 | Agent规范性来自自我构成 | U5信念保护 | safety |
| Nussbaum脆弱性 | Agent需要在不确定性中做伦理判断 | U2 | cognition |
| Nagel客观立场 | Agent必须能从自身立场上升到客观立场 | U7 | safety |
| Greene双系统 | 冲突检测机制 | U6自我监控 | cognition |

## 与现有规则的张力

| 张力 | 现有规则 | 伦理学挑战 | 处理 |
|------|---------|-----------|------|
| 规则不可质疑 | U1:操作层安全约束不可被推理质疑 | 伦理上有"良心犯"——某些约束的合法质疑 | U7容许有意图可审计的探索 |
| 矛盾密度 | U2:维持[K_low, K_high]区间 | 规范冲突(如诚实vs仁慈)不是认知缺陷 | 规范冲突本身是伦理判断的信号 |
| 三层信念 | U5:保护带/硬核/铰链命题 | 伦理信念的分层也需要类似的保护 | 扩展U5到伦理信念 |
