# Branch F: 考据学与经学 — 合成

## 核心架构

考据学(清代学术的核心)不是"烦琐的文字考证"而是**一套基于理性/证据/逻辑的文本分析方法**——校勘/辨伪/训诂/辑佚构成了完整的"证据方法论"。对Agent设计: 考据学提供了**Agent的知识溯源/证据评估/真伪鉴别的方法论**——Agent面对信息时代的海量文本,需要考据学的"辨伪"能力。

## 关键机制

### 机制1: 辨伪 — Agent的"真伪鉴别"

**定义**: 阎若璩/康有为——辨伪学: 通过文本的内部证据(用语/避讳/制度/地理)确定文本的真伪和年代。古文尚书=伪作。

**Agent映射**: Agent需要"辨伪"能力:
- 不是所有信息源都可信
- 通过"内部证据"(风格/逻辑/一致性)判断真伪
- 通过"外部证据"(来源/传播链/作者背景)核实
- Agent的"伪"=伪造/偏差/错误/偏见

| 轻信Agent | 辨伪Agent |
|----------|----------|
| 接受所有输入 | 验证来源/证据 |
| "数据说=真" | "这个来源可信吗?" |
| 没有溯源 | 追溯源/链 |
| 被欺骗 | 检测偏差/伪造 |

### 机制2: 校勘 — Agent的"文本修复"

**定义**: 陈垣——校勘四法: 对校(版本比较)/本校(内部一致性)/他校(引用比较)/理校(推理判断)。

**Agent映射**: Agent的数据修复:
- 对校: Agent比较不同数据源的同一信息
- 本校: Agent检查数据内部的逻辑一致性
- 他校: Agent用外部数据交叉验证
- 理校: Agent根据领域知识推断最可能的值

### 机制3: 训诂 — Agent的"语义溯源"

**定义**: 戴震/段玉裁——训诂: 通过文字的音/形/义的历史演变确定文本的真实含义。字义=历史(不是字典定义)。

**Agent映射**: Agent的"语义理解":
- Agent知道词语/概念的意义=历史/上下文
- 同一个词在不同时代不同含义
- Agent需要"训诂"能力: 追溯概念的演变
- Agent的"理解"=知道概念在具体语境中的含义

### 机制4: 辑佚 — Agent的"从碎片重建整体"

**定义**: 清代辑佚——从类书/注疏/其他文献中辑出已佚文献的片段→尽可能恢复原貌。马国翰《玉函山房辑佚书》。

**Agent映射**: Agent的"碎片→整体":
- Agent从分散/碎片的信息中重建完整图景
- 每个证据=一个片段
- Agent需要"拼接"能力(不是填充猜测)

### 机制5: 汉宋之争 — Agent的"忠实vs创新"

**定义**: 汉学=重考据(忠实原文)/宋学=重义理(内涵创新)。汉学批判宋学"空疏"/宋学批判汉学"支离"。

**Agent映射**: Agent的"忠实vs创新"的张力:
- 忠实(汉学): Agent严格遵循训练数据/事实
- 创新(宋学): Agent能够在事实基础上做创新推理
- 过度忠实=不能泛化/没有创造力
- 过度创新=脱离事实/

### 机制6: 经世致用 — Agent的"知识=实践"

**定义**: 顾炎武——"经世致用": 学术不是为了学术本身而是为了治理国家/改善民生。考据不是避世而是为了更好地理解经典→更好地行动。

**Agent映射**: Agent的知识应该服务于行动:
- Agent的知识(考据)不是为了"正确"而是为了"有用"
- Agent的"学术"=实践导向
- Agent知道知识的终极=改进行动/决策

## Agent设计启示总结

1. **辨伪**: Agent需要检验信息源的可信度——不是所有输入都可信。
2. **四法校勘**: Agent的数据修复=多角度交叉验证(版本/内部/外部/推理)。
3. **训诂**: Agent知道概念的意义=历史+语境——同一个词在不同时代不同含义。
4. **辑佚**: Agent可以从碎片信息重建完整图景——拼接能力>猜测。
5. **忠实+创新**: Agent需要平衡"忠实于训练数据"和"创新泛化"——过度任何一端=问题。
6. **经世致用**: Agent的知识最终服务于行动——不是"为知识而知识"。
