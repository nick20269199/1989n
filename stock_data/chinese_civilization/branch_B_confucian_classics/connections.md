# Branch B: 儒家经典与注疏 — 跨域连接

## 与哲学

| 经学 | 哲学 | 连接 |
|-----|------|------|
| 经=权威文本 | 经典/正典(Canon) | 所有文明都有"经",哲学追问"什么是经典的权威" |
| 注疏传统 | 诠释学(Hermeneutics) | 经学=中国2000年的诠释学实践(Gadamer/施莱尔马赫) |
| 汉学vs宋学 | 实在论vs观念论 | 训诂(实在)vs义理(观念)=哲学的认识论分歧 |
| 今文vs古文 | 实用主义vs历史主义 | 今文(经世致用)vs古文(还原历史) |
| 伪经问题 | 真的标准/作者意图 | 什么是"真"的?=作者意图vs文本效果 |
| 四书升格 | 经典的形成/正典化 | 经典的选择过程=权力的运作+理性的辩护 |

## 与宗教

| 经学 | 宗教 | 连接 |
|-----|------|------|
| 经典权威 | 圣经/佛经/古兰经 | 所有宗教都有"经",经学=比较释经学的中国案例 |
| 注疏层累 | 释经传统 | 犹太教塔木德/基督教教父/佛教论疏=注疏层累 |
| 门户之争 | 教派/宗派分裂 | 今文vs古文≈天主教vs新教 |
| 伪经判定 | 真经vs伪经 | 宗教的经典正典化过程(次经/伪经的排除) |
| 通经致用 | 信仰实践 | 经不是知识而是生活的指南/行动的原则 |

## 与政治

| 经学 | 政治 | 连接 |
|-----|------|------|
| 独尊儒术 | 意识形态/国家宗教 | 经=国家统一的思想基础/科举=知识-权力机制 |
| 通经致用 | 治理/合法性 | 经学不是书斋学问而是治理国家的工具 |
| 经学与科举 | 精英选拔 | 经学=官僚的共同语言/知识共同体 |
| 今文经学 | 改革/变法 | 今文家(康有为)以经学推动政治变革 |
| 古文经学 | 保守/守成 | 古文家(章太炎)以经学维护传统 |
| 经学废除 | 现代性危机 | 1905废科举=经学制度的崩溃 |

## 与经济学

| 经学 | 经济学 | 连接 |
|-----|--------|------|
| 经学制度 | 制度/路径依赖 | 经学的持续2000年=制度惰性的典型案例 |
| 注疏的积累 | 知识积累/增长 | 经学的边际增长=正常科学的渐进积累 |
| 范式转换 | 创造性破坏 | 每个经学转向=熊彼特的创造性破坏 |
| 通经致用 | 实用主义 | 知识的经济价值=在实践中的应用 |

## 与物理

| 经学 | 物理 | 连接 |
|-----|------|------|
| 经典不变 | 守恒律 | 经(不变)+注(变化)=对称性与对称破缺 |
| 注疏层累 | 层级结构/重整化 | 不同尺度的理论=不同层次的注疏 |
| 门户之争 | 多理论竞争 | 并行理论解释同一现象=经学的学派竞争 |
| 范式转换 | 科学革命 | Kuhn的范式不可通约≈汉宋不可通约 |
