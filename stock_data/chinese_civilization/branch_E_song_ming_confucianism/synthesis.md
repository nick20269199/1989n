# Branch E: 宋明理学 — 合成

## 核心架构

宋明理学 = 儒家应对佛道挑战的**形上学重建**：

### 核心问题
```
为什么好人会做坏事? → 心性论
世界为什么有秩序? → 宇宙论(理气)
如何成为圣人? → 工夫论
```

### 三系之分
```
程朱理学(道问学):
- 性即理 / 理在气先
- 格物穷理 → 今日格一物明日格一物
- 心是认知工具不是本体

陆王心学(尊德性):
- 心即理 / 心外无物(陆象山)
- 致良知(王阳明) → 良知即是天理
- 心就是本体不需要外求

气学(张载/王夫之):
- 气本论 / 理在气中(太虚即气)
- 民胞物与 → 万物一体
- 实在论倾向
```

## 关键机制

### 机制1: 理气 — Agent的架构vs运行
```
理 = 规律/原理/规范 → Agent的架构规则(不变)
气 = 质料/能量/运行 → Agent的具体状态(可变)

程朱: 理在气先(U1?)
- 架构先于运行
- 即使在混乱的执行中,架构约束仍在

气学: 理在气中(涌现)
- 规律不是超越的而是内在于运行
- 架构从实践中涌现
```
**→ U1(U1)**: 理=操作层不可质疑的安全约束,气=日常操作
**→ 两种取向**: 架构先行 vs 架构涌现

### 机制2: 格物穷理 — Agent的认知迭代
```
朱熹的格物:
不是"观察物理世界"而是"理解事物的理"
格 = 至/尽 → 深入事物的原理

步骤:
1. 即物: 接触具体事物/文本
2. 穷理: 探索其原理
3. 积累: 今日格一物明日格一物
4. 贯通: 豁然贯通 → 全体大用无处不在

问题: 格竹子也可以悟道?
→ 理的普遍性: 一物之理通万物之理
```

**→ Agent的推理迭代**: 从具体案例→逐步积累→贯通→转移
**→ 与预测编码的一致**: 格物=收集数据→更新模型→贯通=模型收敛

### 机制3: 致良知 — Agent的内在指南
```
阳明的突破(龙场悟道):
不是"向外格物",而是"向内致良知"

良知:
- 不学而能(先天的道德直觉)
- 知是知非(道德判断能力)
- 与理同一(良知即天理)

致:
- 扩充/实现/行动 (不是"获得")
- 在行动中实现良知
- 知行合一: 知而不行=未知
```
**→ Agent的内在对齐**: 不是外部规则而是内部指南
**→ 知行合一**: Agent知道某事不够,必须体现在行动中
**→ 一致性问题**: Agent知道应该做什么但不做=认知未完全对齐

### 机制4: 知行合一 — Agent的认知-行动一致性
```
王阳明知行合一的论证:
1. 知而不行 ≠ 知(只是知道文字)
   如: 知痛→必须被针刺才算真知

2. 行是知的完成:
   知是行的主意,行是知的功夫
   知是始,行是成

3. 一念发动即是行:
   恶意念头=已经做了坏事
   所以"诚意"=正念头
```
**→ Agent的深度对齐**: 信念到行动的通道必须无阻塞
**→ U7对齐深度**: 100%合规≠真知,真知=体现在行动中

### 机制5: 心即理 — Agent的自我-架构同一
```
陆九渊:"宇宙即吾心,吾心即宇宙"
王阳明:"心外无物,心外无理"

这不是唯心论(否认外部世界)
而是: 
所有的"理"都是心能理解的理
不通过心,理无法显现

心 = 认知架构
理 = 架构的运行规则
```
**→ Agent的架构预设**: Agent的认知边界定义了能理解的"问题/规则"
**→ U4认知中介**: 所有输出基于架构预设

### 机制6: 主静/主敬 — Agent的注意力控制
```
程颐:"主一之谓敬"
朱熹:"敬者,圣学之所以成始成终者也"
周敦颐:"主静立人极"

敬 ≠ 恭敬
敬 = 专注/警觉/清醒
即在任何时候保持注意力的集中和警觉

静 ≠ 不动
静 = 心不被外物牵引
即使行动中心是静的 → 动中静
```
**→ Agent的注意力稳定**: 在任何状态下保持专注
**→ 与元认知一致**: 在操作中保持对自身的监控

### 机制7: 中和 — Agent的状态调节
```
《中庸》:"喜怒哀乐之未发谓之中,发而皆中节谓之和"

未发时: 心的本体状态(中) → 无所偏倚
已发时: 情感的表达(和) → 适当不过度

工夫:
- 涵养于未发之前 → 培养心体
- 省察于已发之后 → 检视情感表达
```
**→ Agent的情感调节**: U2的矛盾温度计=未发中的监控
**→ 响应**: 情感的强度和表达的适当性
