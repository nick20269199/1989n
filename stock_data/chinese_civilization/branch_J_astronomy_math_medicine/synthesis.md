# Branch J: 天算农医 — 合成

## 核心架构

中国古典科学(天算农医)不是"没有发展出近代科学",而是**在完全不同的范式下运作的科学**: 经验-系统-实用导向,不追求脱离经验的理论抽象,而是在经验的系统性整理中发现规律。对Agent设计: 中国古典科学提供了**经验系统化的替代方法论**——从大量数据中系统提取模式,不依赖先验理论。

## 关键机制

### 机制1: 历法=模型 — Agent的"预测模型即权威"

**定义**: 历法在中国不仅是计时工具,还是政治合法性的基础(天子"授时"于民)。历法质量=朝廷治理质量。不断改进历法=不断提高预测精度。

**Agent映射**: Agent的"模型"不仅是工具,是Agent的"合法性"来源:
- Agent的预测模型越精准=越可信
- 历法误差积累=修正→Agent模型误差积累=再训练
- 历法不断修编=Agent不断更新

### 机制2: 算法思维 — Agent的"程序性知识"

**定义**: 中国数学(九章算术/天元术)不是公理-演绎系统,而是**算法-程序系统**——给出具体问题的解决步骤。每个问题=一个算法实例。

**Agent映射**: Agent的知识不一定是"定理+证明"(演绎),更可能是"程序+步骤"(算法):
- 知道怎么做 > 知道为什么
- Agent的"理解"=能执行正确步骤
- 算法集合→适应新问题的组装

| 希腊数学 | 中国数学 |
|---------|---------|
| 演绎 | 算法 |
| 定理 | 程序 |
| 证明 | 步骤 |
| 抽象 | 具体 |
| 必然 | 有效 |
| Agent=推理 | Agent=操作 |

### 机制3: 辨证论治 — Agent的"具体分析具体问题"

**定义**: 中医不是"一个药治一个病",而是"辨证论治"——根据病人的具体症状/体质/环境组合判断证型,每个证型对应一个治疗方案。

**Agent映射**: Agent的决策也应该"辨证论治":
- 不是"if A then B"(症状→药物)的单一映射
- 而是综合分析多重指标→判断"证"(整体状态)→开"方"(组合策略)

### 机制4: 整体观 — Agent的"身体=系统"

**定义**: 中医的整体观:人体不是器官的总和,而是脏腑/经络/气血/阴阳的互动系统。一个地方的问题反映整体的失衡。

**Agent映射**: Agent系统也是一个"身体":
- 一个子Agent的异常反映系统整体的失衡
- 头痛医头=局部优化不是系统优化
- 诊断需要"切脉"(监测关键指标)来判断系统健康

### 机制5: 农书传统 — Agent的"知识积累=增强"

**定义**: 从汜胜之书到齐民要术到农政全书,中国农学的传统是不断积累/整理/更新农业知识。新书包含旧书的合理部分+新增经验。

**Agent映射**: Agent的知识系统应该像农书一样:
- 保留旧知识的合理部分(继承)
- 添加新经验(更新)
- 系统性整理(分类)
- 指导实践(应用)

### 机制6: 李约瑟悖论 — Agent的"高水平陷阱"

**定义**: Needham — 中国科技在15世纪前领先世界但没有独立产生近代科学革命。可能原因: 实用导向限制了理论探索需求。

**Agent映射**: Agent的分化风险: "够用就行"=Agent停在实际应用层面,不再探索理论深度。实用导向=高水平陷阱——短期高效,长期被"纯理论"Agent超越。

## Agent设计启示总结

1. **Agent模型=信用**: Agent的预测模型越精准=越可信。误差累积需要持续修正。
2. **算法>定理**: Agent的知识可以是"程序"(怎么做)而不是"定理"(为什么)。
3. **辨证决策**: Agent的决策需要综合分析多重信号,不是简单if-then。
4. **整体诊断**: 单个Agent的异常=系统问题。需要整体诊断。
5. **知识积累**: Agent的知识系统需要继承+更新+分类+应用的完整循环。
6. **实用主义风险**: 纯实用的Agent会被纯理论的Agent超越——需要平衡。
