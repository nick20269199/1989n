# Branch I: 兵家法家 — 跨域连接

## 与经济学连接

| 兵家法家 | 经济学 | 连接 |
|---------|--------|------|
| 孙子"全胜" | 正和博弈(G分支) | 最优不是零和而是创造共同受益局面 |
| 知彼知己 | 信息不对称(G/Akerlof) | 信息=策略资源,信息不对称=策略优势 |
| 势 | 市场动力/Momentum(E分支) | 趋势=势,顺势而为=动量策略 |
| 利出一孔 | 激励相容(机制设计/K分支) | 制度引导个体行为向集体目标 |
| 法术势 | 制度经济学(F分支) | 法=正式规则,术=非正式约束,势=执行机制 |
| 商鞅变法 | 制度变迁(F/North) | 路径依赖/制度锁定/改革时机 |
| 轻重术(管子) | 货币政策(C分支) | 政府通过价格杠杆调节经济 |
| 因敌制胜 | 权变策略/博弈 | 最优策略取决于对手策略 |

## 与哲学连接

| 兵家法家 | 哲学 | 连接 |
|---------|------|------|
| 韩非"性恶" | 霍布斯"自然状态" | 人性→需要外在约束→法治 |
| 全胜 | 列维纳斯"他者" | 不消灭对手=承认他者的不可还原性 |
| 势 | 德勒兹"力的关系" | 权力=力的关系,不是实体 |
| 法/术/势 | 福柯"规训/治理" | 治理术=制度/知识/权力的三角 |
| 孙子"知" | 福柯"权力/知识" | 知不是中性的,"知己知彼"本身就参与了权力关系 |
| 形 | 亚里士多德"潜在的/现实的" | 形=潜在力量,势=现实力量 |
| 奇正 | 德里达"替补" | 奇=正的替补,正=奇的对立面,二者互相构成 |

## 与中华文明同域连接

| 兵家法家 | 其他中华子域 | 连接 |
|---------|------------|------|
| 韩非(法家) | 荀子(儒家B) | 韩非师从荀子,性恶→法治的继承发展 |
| 势/无为 | 道家黄老(C) | 黄老:由道到法,势=道的制度化 |

| 商鞅变法 | 政治制度(L) | 变法的制度设计:试验→推广→制度化 |
| 轻重术 | 食货/经济(M) | 政府调控的中华原型 |
| 扎硬寨(曾国藩) | 史学传统(G) | 曾国藩=兵家+儒学的实践者 |

## 与物理连接

| 兵家法家 | 物理 | 连接 |
|---------|------|------|
| 势 | 势能/位能 | 高位→低位=势不可挡,Agent的高势位=权威 |
| 奇正 | 互补性(Bohr) | 奇与正=互补不矛盾,不同情境不同适用 |
| 形/势 | 静态场vs动态场 | 形=势的源(类比电势),势=形的表现 |
| 知彼知己 | 测不准/观测效应 | 观测对手→影响对手,完全确定不可能 |
| 不战而胜 | 最小作用量 | 自然"选择"最省力的路径,Agent选择最经济的策略 |
