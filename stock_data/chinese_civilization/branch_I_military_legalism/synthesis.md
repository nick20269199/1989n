# Branch I: 兵家法家 — 合成

## 核心架构

兵家法家提供Agent的**策略对抗(兵家)和制度治理(法家)**的核心框架。兵家的"权变"=在不确定性中决策,法家的"法术势"=多Agent系统的治理。

### 两条互补主线
```
兵家 ─────────────────────── 法家
(外部竞争/策略对抗)         (内部治理/制度设计)
       │                           │
       ↓                           ↓
 Agent的竞争策略:            Agent的制度框架:
 知彼知己/形/势/虚实         法/术/势的三位一体
 奇正相生/因敌制胜             利害驱动/明分使群
```

## 关键机制

### 机制1: 孙子"全胜" = Agent的最优博弈不是消灭对手

```
孙子兵法最高原则:

"百战百胜,非善之善者也;不战而屈人之兵,善之善者也。"
"上兵伐谋,其次伐交,其次伐兵,其下攻城。"

→ 最优策略层级:
  1. 伐谋(挫败对手的计谋) → 最高效,成本最低
  2. 伐交(破坏对手的联盟) → 第二高效
  3. 伐兵(野战) → 成本上升
  4. 攻城(强攻) → 成本最高,最下策
```

**→ Agent的冲突层级:**
- 最底层: 直接对抗(消耗战) — 最不经济
- 中层: 规则竞争(在规则内赢) — 中等成本
- 高层: 认知竞争(改变对方的认知/预期) — 低成本
- 最高层: 全胜(让对手认为合作优于对抗) — 最优

**→ 对应铁律4**: Agent的目标不是"杀死"矛盾,而是让矛盾自然消解

### 机制2: "知彼知己,百战不殆" = Agent的信息优势

```
"知彼知己,百战不殆;
 不知彼而知己,一胜一负;
 不知彼不知己,每战必殆。"

"知"=获取+分析+判断:
- 知道对方的状态和意图
- 知道自己的状态和能力
- 知道环境的变化
```

**→ Agent的信息决定胜负:**
- 信息优势 > 资源优势
- 信息不对称 → 策略不对称
- Agent必须维持对环境和对手的"知"
- 但信息获取有成本 → 信息-能量账(Landauer)
- **"知"本身需要能量→Agent的信息预算管理**

### 机制3: "形"vs"势" — Agent的静态vs动态策略维度

```
形 = 静态实力/布局(军事实力/资源储备)
势 = 动态势能/节奏(从高处推石/如转圆石于千仞之山)

"形"的维度:
  先胜而后战 → 先创造不可被战胜的条件
  立于不败之地 → 不依赖对手犯错

"势"的维度:
  因利制权 → 根据利益变化灵活应对
  如转圆石于千仞之山者 → 势不可挡
  奇正相生 → 常规vs非常规交替
```

**→ Agent的双维策略:**
- **形**(静态): 制度/能力/知识库/模型参数(较稳定)
- **势**(动态): 推理状态/决策节奏/注意力焦点(快速变化)
- 有形无势 → 资源多但不会用(死)
- 有势无形 → 灵活但根基不稳(飘)
- **Agent设计必须同时考虑形(架构)和势(推理路径)**

### 机制4: 法/术/势三位一体 = Agent治理的完整框架

韩非的治理系统:
```
法(制度) ──── 公开/明确/稳定的规则体系
   │
   ├── 术(技巧) ──── 不公开的领导/管理技巧
   │     └─ 因任而授官/循名而责实/潜御群臣
   │
   └── 势(权力) ──── 制度性权力/权威
         └─ 贤者不如势(个人再强不如制度保障)
```

**→ 三者的关系:**
```
法: Agent的操作协议/规则(公开透明)
术: Agent的执行策略/启发式(不一定公开)
势: Agent的制度权威/执行权(使规则有效)
```

**→ 铁律1(元层次分离)的韩非版:**
- 法=操作层的规则
- 术=执行层的不公开技巧
- 势=制度性权力=使规则有实效的基础
- 法/术/势三者缺一不可

### 机制5: 商鞅"利出一孔" = Agent的利益引导设计

```
商鞅:
"民之性,饥而求食,劳而求逸,苦则索乐,辱则求荣。"

→ 人的行为由利益驱动
→ 制度设计: 让个人利益与集体利益一致
→ "利出一孔": 只开放一个利益通道(农战)
→ 利益集中→行为集中→目标集中
```

**→ Agent的激励机制:**
- 不依赖于Agent"道德" → 设计制度引导行为
- 让Agent的self-interest与系统目标一致
- 太多利益通道 → Agent分散(选择太多→熵高)
- 太少利益通道 → Agent僵化(选择太少→熵低)
- **最优=利出一孔但可升级**: 单一通道+通道内梯度

### 机制6: 荀子/韩非"性恶" × 制度 = Agent的正基假设

```
荀子: "人之性恶,其善者伪也。"
韩非(从荀子): 性恶→需要法治

但关键转进:
不是"性恶",而是"利害" → 中性地激励约束
韩非: 人不善恶,人趋利避害

→ 制度不是防范人性,是利用人性
```

**→ Agent的安全设计原则:**
- 不假设Agent的善意 → 设计制度使恶意行为不获益
- 不假设Agent的完美 → 设计制度使错误被自动纠正
- **铁律7(明律)**: 行为必须在规则下可审计/可评估
- 安全不是靠信念而是靠制度

## 铁律深化

### 铁律4(混沌边缘)的兵家解读

"混沌边缘=最优适应度"对应的兵家概念:
- 孙子: "立于不败之地,而不失敌之败也" — 维持稳定(不败)+等待变化(敌败)
- 最危险: 完全僵化(秩序过度)vs完全混乱(秩序缺失)
- 最优: 奇正交替训练,形随势变

### U2矛盾温度计的法家解读

- K过低(完全服从法律): 法家变成酷吏→系统僵化→非议起
- K过高(人人都违法): 法不责众→系统崩溃
- 最优K: 法+术+势平衡—制度约束+灵活执行+权威保障
