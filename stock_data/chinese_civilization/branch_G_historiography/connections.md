# Branch G: 史学传统 — 跨域连接

## 与哲学

| 史学 | 哲学 | 连接 |
|-----|------|------|
| 通古今之变 | 历史哲学/Hegel | 历史有规律吗?历史的目的? |
| 直书vs曲笔 | 真理vs权力(Foucault) | 知识的客观性受权力的影响 |
| 史识/判断 | 判断力(Kant) | 历史判断≈反思判断力 |
| 考证/证据 | 证据/证成 | 历史知识的证成=多证据的融贯 |
| 春秋笔法 | 解释学/意义 | 叙事的选择=意义的赋予 |
| 历史循环论 | Vico/循环史观 | 治乱循环=历史周期律 |

## 与政治

| 史学 | 政治 | 连接 |
|-----|------|------|
| 史官独立 | 权力制衡/第四权力 | 独立史官≈独立的司法/媒体 |
| 资治通鉴 | 治理/决策 | 历史=决策者的案例库 |
| 正史/官修 | 官方叙事/意识形态 | 谁写历史=谁有权力 |
| 禁书/文字狱 | 言论控制 | 曲笔的最高形式=控制书写 |
| 史论(读通鉴论) | 政治哲学 | 从历史中提炼政治哲学 |
| 历史评价 | 公共记忆/纪念 | 谁被记住=谁是英雄 |

## 与经济学

| 史学 | 经济学 | 连接 |
|-----|--------|------|
| 食货志 | 经济史 | 历代经济制度的记录=经济史的数据库 |
| 通典/通考 | 制度变迁 | 食货(经济)在典制中排第一(杜佑) |
| 计量史学 | 数据/统计 | 历史的经济计量学 |
| 长时段(Braudel) | 结构/周期 | 长时段结构决定经济周期 |
| 制度/政策 | 增长/效率 | 历史上的经济政策效果 |

## 与认知科学

| 史学 | 认知科学 | 连接 |
|-----|---------|------|
| 叙事/编年 | 叙事心理学 | 人类通过叙事理解时间经验 |
| 史识(判断) | 专家直觉/模式识别 | 史学家的判断=专家的模式匹配 |
| 记忆/遗忘 | 记忆/遗忘的认知 | 谁记住什么/谁被遗忘≈注意的选择 |
| 考证/核实 | 事实核查/混淆 | 核实=认知的消除偏见 |
