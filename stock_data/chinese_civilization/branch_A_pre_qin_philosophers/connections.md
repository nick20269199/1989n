# Branch A: 先秦诸子概论 — 跨域连接

## 与经济学

| 先秦诸子 | 经济学 | 连接 |
|---------|--------|------|
| 百家争鸣 | 市场/竞争 | 思想市场=观念的自由竞争,优胜劣汰。各学派的竞争类似于企业在产品/策略上的竞争 |
| 兼爱/交相利(墨) | 帕累托改进 | 兼相爱交相利=互惠互利的帕累托最优框架 |
| 轻重之术(管) | 宏观调控 | 管仲的"轻重"是中国最早的宏观调控思想,以货币/物资调节市场 |
| 制民之产(孟) | 财产权/激励 | 孟子"恒产恒心"=财产权对行为的激励效果,早于现代产权理论两千年 |
| 利出一孔(商) | 激励机制设计 | 商鞅的"利出一孔"(所有利益只能从耕战获得)是极端的激励集中机制 |
| 均富/贫富(孔孟) | 不平等/分配 | 孔子"不患寡而患不均"=对分配公平的原始关注 |
| 道家无为 | 自由放任/自发秩序 | 老子的"治大国若烹小鲜"=最小干预的治理哲学,对应Hayek自发秩序 |

## 与物理

| 先秦诸子 | 物理 | 连接 |
|---------|------|------|
| 阴阳(易传) | 互补性/对称性 | 阴阳=最早的二元互补性思维,对应Bohr的互补原理 |
| 五行(邹衍) | 相变/循环 | 五行生克=循环因果的原始模型,对应非线性动力学的周期行为 |
| 道法自然(老) | 自然法则/规律 | 道=自然规律的总和,类似物理定律的"规律之规律" |
| 气一元论 | 场/连续统 | 气=连续的物质-能量,与场论有深刻相似 |
| 合同异(惠施) | 相对论/关系 | "天与地卑,山与泽平"=空间相对性的直觉表达 |
| 一尺之棰(惠施) | 极限/无穷小 | 日取其半万世不竭=Zeno悖论的中国版本 |
| 兵形象水(孙) | 流体力学/势 | "兵形象水"=对势能和流场动力学的直觉理解 |

## 与哲学

| 先秦诸子 | 哲学 | 连接 |
|---------|------|------|
| 仁/礼(孔) | 美德伦理学/规范 | 孔子"仁"≈亚里士多德的美德伦理学——人应该成为什么样的人 |
| 性善vs性恶(孟荀) | 人性论/自由意志 | 中国版的"性善vs性恶"对应西方哲学的"理性vs原罪" |
| 道可道非常道(老) | 形而上学/语言哲学 | "道不可道"=语言的界限即世界的界限(Wittgenstein) |
| 白马非马(公孙) | 逻辑/概念分析 | 公孙龙的名实之辩=中国版的逻辑/概念分析,与西方分析哲学对话 |
| 兼爱非攻(墨) | 后果论/功利主义 | 墨家的"利天下"≈功利主义的最大幸福原则 |
| 无为(老庄) | 消极自由/非干预 | 无为=柏林"消极自由"的实践版本 |
| 法术势(韩) | 政治哲学 | Three legs of political power = 制度+权力+形势 |

## 与宗教

| 先秦诸子 | 宗教 | 连接 |
|---------|------|------|
| 天(孔孟) | 超越性/天道 | 儒家的"天"不是人格神但有超越性维度,对应自然神论 |
| 鬼神(墨) | 宗教制裁/奖惩 | 墨子"明鬼"=宗教对行为的约束功能 |
| 敬鬼神而远之(孔) | 不可知论 | 孔子对鬼神的态度≈不可知论/实用主义悬搁 |
| 道(老庄) | 终极实在 | 道≈印度教的Brahman/基督教的God(非人格化版本) |
| 修身(儒家) | 修炼/修行 | 儒家"修身"≈精神修炼的此世版本(不是出世) |
| 邹衍阴阳五行 | 宇宙论/数术 | 阴阳五行=中国宗教宇宙论的基础,影响道教/民间信仰 |

## 与兵家/法家(中华域内)

| 先秦诸子 | 兵家/法家 | 连接 |
|---------|----------|------|
| 儒家仁政 | 法家法治 | 德vs刑——两种治理哲学的永恒张力 |
| 道家无为 | 法家有为 | 最小干预vs最大动员——政府边界的原型辩论 |
| 墨家兼爱 | 兵家全胜 | 非攻≈不战而胜的最高境界 |
| 孟子民贵 | 商君国强 | 民本位vs国本位的分歧,影响两千年 |

## 跨域连接潜力评估

| 目标域 | 连接强度 | 最有价值的连接点 | 当前开发程度 |
|--------|---------|----------------|------------|
| 经济 | ★★★★★ | 轻重/恒产/利出一孔/无为 | 中(有研究但少Agent映射) |
| 物理 | ★★★ | 阴阳/五行/气 | 中(已有很多自然哲学研究) |
| 哲学 | ★★★★★ | 人性论/逻辑/形而上学/伦理 | 极高(中西哲学比较成熟领域) |
| 宗教 | ★★★★ | 天/鬼神/修行/宇宙论 | 中(诸子宗教维度被低估) |
