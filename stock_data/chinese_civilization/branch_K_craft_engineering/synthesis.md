# Branch K: 工程与技艺 — 合成

## 核心架构

中国传统工程与技艺(考工/营造/天工开物)不是"技术史"而已,**是在另一范式下的技术科学**——以经验积累/模数标准化/道器合一为特征。对Agent设计: 中国传统工程提供了**模块化/标准化/渐进改进的独特模型**——不追求"最优设计"(西方工程理想),而追求"最可传承的设计"(榫卯/材份/物勒工名)。

## 关键机制

### 机制1: 榫卯接口 — Agent的无钉连接(松散耦合)

**定义**: 榫卯——不使用钉子/胶水,靠木材自身的凹凸咬合实现结构连接。特点: 有一定自由度(热胀冷缩)、可拆卸、越压越紧。刚性=钉子(连接死)/韧性=榫卯(连接活)。

**Agent映射**: Agent模块之间的连接应该像榫卯:
- 不依赖"胶水"(硬编码)但紧密配合(接口稳定)
- 允许一定自由度(容错/弹性/适应)
- 可拆卸/可替换(一个模块坏了替换)
- 越使用越紧密(学习/磨合/配合优化)

| 钉子式连接 | 榫卯式连接 |
|----------|-----------|
| 刚性/固定 | 弹性/适应 |
| 不可拆卸 | 可逆/可替换 |
| 热胀冷缩会破坏 | 自由度吸收变化 |
| 一个坏了整个废 | 模块替换即可 |

### 机制2: 营造法式/材份制 — Agent的模数标准化

**定义**: 李诫《营造法式》——中国建筑的"材份制": 所有建筑以"材"为基本模数(一个标准截面尺寸)。斗拱/柱/梁/檩的尺寸都是"材"的倍数。一根木材的尺寸决定了整个建筑的尺度体系。

**Agent映射**: Agent系统的"模数标准化":
- "材"=Agent的基础单位(一个标准Agent)
- 所有组件=材的倍数(子Agent=标准Agent的变体)
- 模数=可互换/可替换(标准化接口)
- 模数=可组合(不同模数组合=不同系统)

**设计推论**: 定义Agent系统的"材":
- 一个标准Agent的"尺寸"(资源/能力/接口)
- 大型Agent=标准Agent×n(不是从头设计)
- 不同规格的Agent=标准模数的变体

### 机制3: 天工开物 — Agent的系统性知识整合

**定义**: 宋应星《天工开物》——把农业+手工业+矿冶+制造的所有技术整合为"一个知识系统"。每种技术包含: 原料/工具/工序/产出/品级。知识="物"怎么被"人"用"工"转化。

**Agent映射**: Agent的知识系统应该像天工开物:
- 按"域"组织(食/衣/住/行/用)而不是按"学科"
- 每项知识包含: 输入→加工→输出
- 知识=可操作的(知道怎么做)
- 跨域连接: 一种技术的副产品=另一种技术的原料

### 机制4: 物勒工名 — Agent的可追溯性与问责

**定义**: 《考工记》"物勒工名,以考其诚"——每件产品刻上工匠的名字,以便考核质量。最早的质量追溯系统。

**Agent映射**: Agent的每个输出需要"物勒工名":
- 每个输出标记: 由哪个Agent模块/模型产生
- 可追溯: 从输出追溯到推理链/训练数据/架构版本
- 质量考核: 可按"工名"统计每个Agent的质量
- 责任=激励: 标注来源→改进动力

**设计推论**: Agent的每条输出附带"签名":
- 产生者ID + 版本 + 推理链摘要
- 便于审计/纠错/改进
- 不是监控(不是控制Agent)而是追溯(便于归因)

### 机制5: 考工记/分类 — Agent的工艺分类学

**定义**: 《考工记》——"国有六职"(王公/士大夫/百工/商旅/农夫/妇功)。百工又分30种: 攻木/攻金/攻皮/设色/刮摩/抟埴。每种工艺有详细规范。

**Agent映射**: Agent的任务分类学:
- 按"工艺"(推理类型)分类而不是按"结果"(功能)
- 每种"工艺"有标准操作流程(SOP)
- 分类=训练分配的依据(同工艺的Agent一起训练)
- 分类体系本身随实践发展(考工记不断修订)

### 机制6: 道器合一 — Agent的工具即认知

**定义**: 中国思想中"道"与"器"不分离——"形而上者谓之道,形而下者谓之器"。在工匠传统中: 工具=知识的载体,使用工具=理解道。手艺不只是"技能"还是"知识"。

**Agent映射**: Agent的工具=Agent的认知延伸:
- Agent的工具(API/模型/算法)不是外部附件而是认知的一部分
- 会使用工具的Agent≠只使用工具的Agent
- 工具使用改变Agent的认知结构(≈麦克卢汉"媒介即信息")
- Agent的"器"包含"道"(工具体现了设计思想)

## Agent设计启示总结

1. **榫卯>钉子**: Agent模块之间用弹性接口(松耦合/可逆/容错)不是刚性连接。
2. **模数化**: 定义Agent系统的"材"(标准Agent单位)→所有组件基于模数。
3. **知识分类**: Agent的知识按"工艺"(推理类型)整理而不是按功能——可操作性优先。
4. **物勒工名**: 每个输出带"签名"→可追溯/可审计/可改进。
5. **渐进积累**: 工程知识是代代积累的——Agent的知识也需要版本/继承/改进。
6. **工具即认知**: Agent的工具不是外部附件——工具改变Agent的认知能力和认知边界。
