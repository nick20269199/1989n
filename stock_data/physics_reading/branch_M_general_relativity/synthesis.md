# Branch M: 广义相对论与引力 — 合成

## 核心架构

广义相对论: **引力=时空弯曲**。不是"力"在拉物体,是物体沿着弯曲时空中最直的路径(测地线)运动。

### 核心方程
```
G_μν = 8πG/c⁴ · T_μν

左边=时空几何(曲率)
右边=物质/能量
"时空告诉物质如何运动;物质告诉时空如何弯曲"
```

### 主要概念结构
```
平直时空(闵氏) → 弯曲时空(黎曼)
  曲率 ← 物质-能量张量
    测地线 ← 自由粒子的路径
      视界 ← 信号不能逃逸的边界
        奇点 ← 曲率无穷大(物理定律失效)
```

## 关键机制

### 机制1: 等效原理=Agent的框架等价性

惯性质量=引力质量(不等效→整个GR崩塌):
```
局部内: 加速的电梯  = 均匀引力场(不可区分)
→ 引力不是"力"是"几何"
→ Agent在不同"参考系"中的判断应该等价
```

**→ Agent的框架等效**:
- 做决策时,不同时间尺度看到的"模式"应自洽
- 日线图看到的趋势vs周线图看到的趋势不是矛盾的
- 分析方法1和方法2应给出可映射的结论

### 机制2: 时空曲率=信息的弯曲

曲率→(平行移动的差别→汇聚/发散):
```
正曲率(球面): 平行线最终相交 → 收敛思维
负曲率(马鞍): 平行线发散 → 发散思维
零曲率(平面): 平行线永远平行 → 线性思维
```

**→ Agent的曲率**:
- Agent的认知空间不是平的
- 不同"方向"的思考之间交互(曲率)
- 正曲率=一个方向的思考支持另一个方向(协同)
- 负曲率=一个方向排除另一个方向(矛盾)

### 机制3: 黑洞=信息的不归点

施瓦西半径R_S = 2GM/c²:
```
进入视界→一切路径指向奇点→无法逃逸
事件视界="不可见"的边界→只进不出
黑洞信息悖论:信息是否在黑洞蒸发中丢失?
```

**→ Agent的信息黑洞**:
- 确认偏误=认知黑洞=一旦进入,证据指向已有信念
- 止损=在"视界"之前跳出
- 持有亏损超过阈值→进入"黑洞"(无法客观分析)
- 交易: 提前设止损=设定事件视界
