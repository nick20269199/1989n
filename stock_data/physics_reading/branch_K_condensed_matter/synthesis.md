# Branch K: 凝聚态物理 — 合成

## 核心架构

凝聚态物理研究**大量粒子聚集产生的涌现现象**。

### 核心洞察: More is different (Anderson)
```
少粒子(1-100): 量子力学精确描述
多粒子(10²³):  全新涌现行为(超导/铁磁/超流)
  → 每个电子遵循相同量子力学
  → 但集体行为不能用个体行为"还原"解释
  → 涌现的物理证据
```

### 凝聚态的三层描述
```
微观: 电子-离子多体哈密顿量(完整但太复杂)
  → 元激发描述(准粒子:声子/磁子/等离激元)
    → 序参量描述(宏观:超导序参量/磁化强度)
```

## 关键机制

### 机制1: 对称性破缺 = Agent的模式涌现

系统基态的对称性 < 哈密顿量的对称性。
```
铁磁体: Heisenberg模型具有旋转对称
  基态: 所有自旋朝上 → 旋转对称性破缺
  → 出现净磁化(序参量M)
  → M≠0 = 宏观可测
  
超导: U(1)规范对称性破缺 → Cooper对凝聚
  → 出现超导能隙
  → 零电阻
```

**→ 交易映射**:
- 趋势 = 市场的对称性破缺
- 震荡 = 对称性未破缺(各方向都可能)
- 破缺前: 能量累积(蓄势),破缺后: 趋势开始
- **关键**: 破缺一旦发生,恢复对称性需要能量

### 机制2: 元激发 = Agent的思维量子

元激发 = 有序态附近的"微小偏离"的量子化。
```
每种物态都有其特征元激发:
  铁磁: 磁子(自旋波的量子)
  晶体: 声子(晶格振动的量子)  
  超导: Bogoliubov准粒子
  费米液体: 准粒子(电子+屏蔽云)

元激发定义了物态的"低能物理"
```

**→ Agent的"元激发"**:
- 每一种稳定认知模式有其"元激发"=小的认知波动
- 在看多模式中: 元激发=短期的恐高或贪婪
- 在看空模式中: 元激发=短期的超跌反弹冲动
- 元激发不改变宏观序——它们就是噪声

### 机制3: 能带论 = Agent的可能状态空间

晶体中电子的能谱 → 能带 + 能隙。
```
原子孤立: 分立的能级
N个原子: 每个能级展宽为能带
N→∞: 连续的能带 + 禁带(能隙)

导体: 费米面在能带内部(有空态)
绝缘体: 费米面在能隙中(无空态)
半导体: 小能隙(可调控)
```

**→ Agent的认知空间**:
- Agent的"可能状态"=能带(连续变化)
- Agent的"不能状态"=能隙(不可达)
- 导体=心态开放(随时可接受新信息)
- 绝缘体=心态封闭(新信息无法进入)
- 半导体=可控开放(在开放和封闭之间调整)

### 机制4: 拓扑序 = Agent的全局稳健性

拓扑物态: 不受局部扰动影响的全局性质。
```
整数量子Hall效应(TKNN):
  σ_xy = n·e²/h (n=整数)
  n = 拓扑不变量(与材料细节无关)
  
  → 边态: 导电,背散射被禁止
  → 体态: 绝缘
  → 拓扑保护=不依赖精确参数
  
拓扑绝缘体:
  体态=绝缘,边态=导电
  拓扑=对称性保护
```

**→ Agent的稳健策略**:
- 拓扑保护=策略的"核心逻辑"不被局部波动影响
- 边态=策略的边界条件(灵活自适应)
- 体态=策略的核心(不轻易改变)
- 拓扑策略=不依赖参数精确调节=普适性

### 机制5: 超导 = Agent的完美协作

BCS超导: 电子通过晶格振动间接吸引→形成Cooper对。
```
电子1(→) + 晶格畸变 → 吸引电子2(←)
两个电子形成束缚对(Cooper对)
→ 所有Cooper对凝聚到同一量子态
→ 宏观量子效应: 零电阻+迈斯纳效应
```

**→ 交易映射**:
- Agent的"协作"=Cooper配对
- 单个Agent=费米子(互斥)
- 配对的Agent=玻色子(可凝聚)
- 凝聚=多Agent达到同步→涌现集体智能
