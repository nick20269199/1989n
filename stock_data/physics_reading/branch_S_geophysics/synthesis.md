# Branch S: 地球物理与流体力学 — 合成

## 核心架构

地球物理=物理学在地球系统中的应用。流体力学=流体的运动规律。

### 地球系统的层次
```
大气(气体) ─── 海洋(液体) ─── 地壳(固体) ─── 地幔(粘弹性)
  │              │              │              │
气象          洋流          地震           板块运动
```

### 流体的关键参数: 雷诺数
```
Re = ρvL/μ = 惯性力/粘性力

低Re: 层流(有序/可预测)
高Re: 湍流(混沌/宽谱)
超高Re: 完全湍流(普适统计)
```

## 关键机制

### 机制1: 湍流=市场的能量级联

湍流的能量从大涡旋传到小涡旋->最终耗散:
```
大涡旋(注入能量) → 非线性能量传递 → 小涡旋(耗散)
   ↓                    ↓               ↓
宏观趋势(基本面)     中尺度(政策)     微观(噪声)

Kolmogorov -5/3定律: E(k) ∝ k^(-5/3)
→ 能量谱=幂律=标度不变
```

**→ 市场的湍流**:
- 价格波动=能量从宏观传到微观的"湍流"
- 大趋势(大涡)→ 中继调整(中涡) → 微波(小涡)
- 功率谱呈幂律(不是白噪声)
- 识别:"湍流"vs"噪声"=相干结构vs无结构

### 机制2: 混沌=长期不可预测

洛伦兹方程的发现: 确定性系统不可长期预测:
```
dx/dt = σ(y-x)
dy/dt = x(ρ-z) - y
dz/dt = xy - βz

蝴蝶效应: 初始条件微小差异→指数发散
→ 天气预报>2周基本不可能
```

**→ 交易映射**:
- 市场预测也有Lyapunov时间=可预测的时间窗口
- 短线(<Lyapunov时间): 可预测性较好
- 长线(>Lyapunov时间): 只能做"气候"预测(概率分布)
- 找到Lyapunov时间=知道你的策略能预测多远

### 机制3: 板块构造=Agent的范式转换

大陆漂移理论在1960s被接受的过程:
```
证据积累: 海岸线吻合→化石匹配→古地磁→地震数据
旧范式: 大陆固定(常识上"显然")
新范式: 板块运动(一开始被认为"荒谬")
→ 范式转换一代人→新范式成为新的"正常"
```

**→ 交易中的范式转换**:
- 旧方法失效→积累证据→但还是继续用
- 直到"地磁反转"般的清晰证据→转换
- 关键是: 能在证据足够时转换,不等到"灾难"
