# Branch R: 数学物理 — 跨域连接

## 与哲学

| 数学物理 | 哲学 | 连接 |
|---------|------|------|
| 对称/不变性 | 柏拉图的形式论 | 对称=形式的永恒,变化中的不变 |
| 数学有效性(Wigner) | 实在论/反实在论 | 数学是发明还是发现? 有效=实在论证据 |
| 范畴论/态射 | 关系本体论/过程哲学 | 存在=being的过程怀特海,范畴=过程 |
| 拓扑不变量 | 本质/共相 | 在变化中保持不变=本质的数学定义 |
| 信息/最大熵 | 认识论/理性的选择 | 在无知时的最佳策略=最大熵(Jaynes) |
| 等价/同构 | 同一性/不同中的相同 | 同构=不同表示中的相同结构 |

## 与经济学

| 数学物理 | 经济学 | 连接 |
|---------|--------|------|
| 对称性→守恒 | Noether定理→经济守恒 | 市场对称性→财富/货币的"守恒" |
| 相空间/流 | 状态空间/轨线 | 经济系统的状态=相空间的点 |
| 费舍信息/KL | 信息效率 | 价格的信息含量=Fisher信息的反面 |
| 最大熵 | 最大熵经济体 | 在没有约束时经济系统最大化熵 |
| 凸/凹 | 效用/风险 | 效用函数的凸性=风险偏好 |
| 范畴/态射 | 市场/交易 | 交易=从一种状态到另一种的态射 |

## 与中华文明

| 数学物理 | 中华文明 | 连接 |
|---------|---------|------|
| 对称/不变 | 理一分殊 | 理=不变的分=多样=对称性破缺 |
| 阴阳/变换 | 群论的自发对称破缺 | 太极→两仪=对称性自发破缺 |
| 生生(易) | 信息/熵/创生 | "生生之谓易"≈信息的创造不是熵增 |
| 名实 | 范畴/关系 | 名=范畴,实=对象,正名=正确分类 |
| 格物致知 | 信息/学习 | 格物=获取信息=降低不确定性 |
