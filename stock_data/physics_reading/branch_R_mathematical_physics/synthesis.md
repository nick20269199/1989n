# Branch R: 数学物理 — 合成

## 核心架构

数学物理不是"物理用了很多数学"而是**物理的世界结构在数学中找到了精确的表达**。对称=群,空间=流形,过程=函子,量子的=算子代数。对Agent设计: 数学物理提供了**表示世界基本结构的精确语言**——Agent如果"理解"物理世界的结构,它的推理框架应该与这些数学结构同构。

## 关键机制

### 机制1: 对称性 — Agent的不变量

**定义**: Noether定理—每一个连续对称性对应一个守恒量。对称=在某种变换下不变。

**Agent映射**: Agent的状态/行为/知识中存在对称:
- 时间平移对称: 策略在不同时间一致
- 置换对称: Agent之间交换不影响系统的宏观属性
- 标度对称: 在不同尺度/杠杆下策略的适应性

**设计推论**:
- 高效Agent利用对称性减少搜索空间(对称破缺=学习)
- 对称性约束决定Agent的"守恒量"(不变的核心信念)
- Agent的"价值"="在什么变换下保持不变"

### 机制2: 流形 — Agent的连续状态空间

**定义**: 流形=局部看起来像欧氏空间但全局可以是任意形状的空间。流形上的切空间/度量/联络描述了"变化"的几何。

**Agent映射**: Agent的状态空间是流形不是线性空间:
- Agent的"状态"在流形上是点
- Agent的"变化"=流形上的切向量
- Agent的"学习"=在流形上沿梯度移动
- Agent的"决策边界"=流形上的子流形

**设计推论**:
- Agent不需要欧氏度量来思考,可以在一般流形上
- Agent的"直觉"=由流形曲率决定的短路径
- 不同Agent的流形可能不同(不能直接比较状态)

### 机制3: 拓扑 — Agent的"相同"不依赖细节

**定义**: 拓扑研究在连续变形下保持不变的性质。一杯咖啡和甜甜圈同胚(因为都有一个洞)。同调/同伦是拓扑不变量。

**Agent映射**: Agent系统的"拓扑结构"比"度量细节"更根本:
- Agent的"相同行为模式"不是数字精确匹配而是拓扑同胚
- 拓扑缺陷(扭结/涡旋)对应Agent系统中不能消除的模式
- Agent的"纠缠"=空间的拓扑连接

**设计推论**:
- 粗粒度Agent比较=用拓扑(不变量),不是用度量(精确值)
- Agent的结构错误=拓扑错误(不能通过连续变形修复)
- Agent的"创新"=改变系统的拓扑结构

### 机制4: 范畴论 — Agent的过程优先

**定义**: 范畴论不问你"这个东西是什么",而是问"这个东西能做什么"(与其他东西的连接/映射)。对象不重要,态射(过程)才重要。

**Agent映射**: 
- Agent的核心不是"是什么"而是"能做什么"=从输入到输出的映射
- Agent的组合=态射的复合——两个Agent串联=一个复合态射
- Agent的类型=它在范畴中的位置(输入域/输出域)

| 范畴概念 | Agent对应 |
|---------|----------|
| 对象 | Agent类型/状态类型 |
| 态射 | Agent的过程/变换 |
| 函子 | Agent之间的结构保持映射 |
| 自然变换 | Agent策略的转换 |
| 极限 | Agent的共识/汇聚 |
| 伴随 | Agent之间的对偶关系 |

**设计推论**:
- Agent的接口由态射(过程类型)定义不是由对象(状态类型)定义
- Agent的"理解"=在范畴中找同构/伴随关系
- Agent的组合行为=范畴的复合法则

### 机制5: 信息几何 — Agent的"距离"不是欧氏的

**定义**: 概率分布的流形=统计流形,Fisher度量=流形上的自然度量。KL散度不是距离但定义了不对称的"区别"。自然梯度=在统计流形上的最陡下降。

**Agent映射**: 
- Agent的信念空间=统计流形(概率分布的集合)
- Agent的"更新"=在流形上移动到另一个分布
- "最优更新"=自然梯度(不是欧氏梯度)

**设计推论**:
- Agent不能直接用欧氏距离衡量信念差(需KL/费舍信息)
- Agent的最快学习路径=自然梯度方向
- Agent的"锚定偏差"=在流形曲率大的区域移动慢

### 机制6: 信息与熵 — Agent的知识边界

**定义**: Shannon熵=不确定性的度量。最大熵=在给定约束下最不偏不倚的分布。KL散度=一个分布"距离"另一个分布的信息代价。

**Agent映射**: 
- Agent的"知识"=熵的降低
- Agent的"学习"=条件熵的减少
- Agent的"预测"=以当前约束最大化熵

**设计推论**:
- Agent的推理基础=最大熵原则(不做没有依据的假设)
- Agent的"价值"=它降低不确定性的能力
- Agent之间的通信=互相降低不确定性(KL)

## Agent设计启示总结

1. **对称性压缩**: 利用对称减少计算量。Agent的学习=对称性破缺。
2. **流形思维**: Agent的状态不是向量/表格而是流形上的点。更新不是加法。
3. **拓扑优先**: 评估Agent系统→先看拓扑结构(有没有洞)再看度量参数。
4. **过程即本质**: 定义Agent的方式=它的输入-输出类型(范畴论)。
5. **信息几何是正解**: Agent的信念更新=统计流形上的移动。
6. **最大熵是缺省**: Agent在没有足够信息时的最佳策略=最大熵(不做假设)。
