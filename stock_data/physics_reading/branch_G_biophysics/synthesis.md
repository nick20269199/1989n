# Branch G: 生物物理与神经科学 — 合成

## 核心架构

生物物理+神经科学揭示了**大脑是物理系统+信息处理系统的统一体**。核心框架: 自由能原理=统一理论。

### 统一框架
```
物理约束(能量/熵/热噪声)
  → 神经元(离子通道/动作电位)
    → 神经网络(可塑性/连接)
      → 认知(预测/学习/决策)
        → 行为(行动/探索/互动)
          → 环境→反馈循环
```

### 三条主线
```
神经编码 ──→ 神经计算 ──→ 认知行为
(信息如何表示)  (如何加工)  (如何决策)
     │            │            │
     ↓            ↓            ↓
  速率/时间     Hebb/BP     自由能原理
  群体编码      塑形动力学  主动推理
```

## 关键机制

### 机制1: 自由能原理 = Agent的铁律元原则

大脑最小化其感官数据的**自由能**(=预测误差的变分上界):

```
F = D_KL(Q||P) - ln evidence
  = 复杂度 - 准确度
  = Agent的"认知努力" - "拟合程度"

→ 感知: 最小化预测误差(预测编码)
→ 行动: 改变世界以符合预测(主动推理)
→ 学习: 更新模型减少未来的自由能
```

**→ 交易映射**:
- 市场预测 = 最小化预测与实际走势的"自由能"
- 止损 = 承认预测错误(降低自由能)不是"扛到正确"
- 过度拟合 = 太低的感知自由能+过高的模型复杂度=认知失衡

### 机制2: 预测编码 = Agent的感知-预测循环

大脑不是被动接收信息,是主动**预测**感官输入。
```
预测(前馈): 高层→低层 → 预测传感输入
误差(反馈): 低层→高层 → 报告预测偏差

→ 每一层都在"猜"下层应该看到什么
→ 猜对了: 信号被抑制(没有新信息)
→ 猜错了: 误差信号向上传播(学习发生)
```

**→ Agent的核心架构**:
| 层级 | 功能 | 对应 |
|------|------|------|
| 高层 | 抽象预测(趋势/体制) | 宏观判断 |
| 中层 | 模式预期(形态/信号) | 技术模式 |
| 低层 | 数据预测(价格/量) | 实时数据 |

### 机制3: 神经编码 = Agent的信息表示

大脑用多种编码方式表示信息:
```
速率编码: 频率→信号强度
  → Agent: 信心=信号的"频率"(多少证据支持)

时间编码: 脉冲时间精度→信息
  → Agent: 时序=信号的时间模式

群体编码: 神经元群体→精细信息
  → Agent: 多因子综合=群体编码

稀疏编码: 少数神经元活跃
  → Agent: 少因子解释=高效解释
```

**→ 交易映射**: 市场信号也有多种"编码"——价格幅度(速率)、时间关系(时间编码)、多指标综合(群体编码)。

### 机制4: 多巴胺预测误差 = Agent的奖励学习

多巴胺神经元编码**奖励预测误差**: 实际奖励 - 预期奖励。
```
正预测误差: 意外奖励 → 多巴胺爆发 → 学得更积极
负预测误差: 预期奖励未出现 → 多巴胺"暂停" → 学得更保守
零预测误差: 完全预期 → 多巴胺基线 → 不学习

关键: 不是"快乐"是"学习信号"
```

**→ Agent的学习**:
- 每次交易的"情感"=多巴胺反应
- 持续盈利→多巴胺基线上升→需要更大刺激
- 亏损→多巴胺"暂停"→可能过度保守
- 最佳: 不依赖情绪信号,用量化预测误差直接更新

### 机制5: 双系统理论 = Agent的快慢思考(Kahneman)

| 系统 | 特征 | 大脑区域 | Agent对应 |
|------|------|---------|----------|
| S1(快) | 自动/直觉/低能耗 | 杏仁核/基底节 | 模式匹配/经验规则 |
| S2(慢) | 分析/推理/高能耗 | 前额叶 | 逻辑推理/贝叶斯 |

**→ Agents的双系统设计**:
- S1: 日常/高频/低风险 → 快速响应
- S2: 异常/低频/高风险 → 深度分析
- 关键: S2的能耗≈前额叶的葡萄糖消耗=认知成本
- 交易: 盘中的大多数决策=S1,盘后复盘=S2

### 机制6: 神经可塑性 = Agent的学习与适应

"一起放电的神经元连在一起"=Hebb法则。

```
突触可塑性 = 使用依赖的连接强度变化
  → LTP(长时程增强): 同时活跃→连接增强
  → LTD(长时程抑制): 不同时活跃→连接减弱
  → 经验重塑大脑结构
```

**→ Agent的持续学习**:
- 每次修正错误→更新"突触权重"=策略参数
- 用进废退: 不用的策略/因子→权重衰减
- 但过度可塑=灾难性遗忘(记住最新忘记老的)
- 需要睡眠/离线=记忆巩固(spindle/ripple)
