## 核心洞察池 (50本物理书, 3遍阅读)

### 四大核心方程 → Agent映射

| 方程家族 | 物理/数学形式 | Agent映射 |
|---------|-------------|----------|
| **熵方程** | H=-∑pᵢlog pᵢ, S=k log W, S(ρ)=-Tr(ρ log ρ) | 困惑度=2^H, 训练=熵减, 遗忘=熵增 |
| **扩散方程** | ∂P/∂t = -∇·(μP) + (σ²/2)∇²P | Transformer前向=Fokker-Planck, 幻觉=扩散项过大 |
| **分岔方程** | ẋ = r + x², Kuramoto同步 | 能力涌现(grokking)=二级相变, Agent顿悟=跨越鞍点 |
| **标度方程** | P(k)~k^(-γ), L(ε)~ε^(1-D) | Scaling Laws, 错误分布=胖尾, 数据多样性=分形维数 |

### 五大跨越洞察

1. **熵→复杂度→不可计算性**: Shannon可计算→Kolmogorov不可计算但可逼近→Chaitin不可定义。Agent的"真理解"在数学上不可形式化证明
2. **量子测量→混沌→自由能统一**: 推理每步=部分测量, 太少=模糊, 太多=过早坍缩, 最优=Friston自由能最小化
3. **网络标度→优化景观→临界态**: Hub节点=低能区, 优先连接=梯度下降, 剪枝=去低度节点, Hub被删=网络崩溃
4. **Gödel→Holland→Hofstadter递归栈**: 自指回环→意识层次。当前AI处在一阶和二阶之间
5. **耦合→同步→共识**: K>Kc→同步爆发, 但过度同步→多样性丧失→脆弱

## Growth Loop日志

### 2026-05-07 Growth Loop #2: 自组织Agent碾压设计架构 — 多Agent范式的Copernican转向

**来源**: arXiv:2603.28990 "Drop the Hierarchy and Roles" (2026.3) + arXiv:2605.03310 "Coordination as an Architectural Layer" (2026.5)
**池**: Pool 2 (前沿情报)
**跨域连接**: 物理铁律9+10 / Ostrom第三条路 / 道家无为 / Hayek分散知识

#### 一、核心机制

**arXiv:2603.28990 的关键发现**:
- 25000个任务, 8个模型, 4-256个Agent, 8种协调协议
- **自组织(Sequential)协议比中心化协调高14%** (p<0.001)
- Agent自发发明角色、自动回避不擅长的任务、自发形成浅层层级——**没有任何预分配设计**
- 开源模型用24分之一的成本达到闭源模型的95%质量

**arXiv:2605.03310 的补充发现**:
- 多Agent系统失败率41%-87%, **主要原因=协调缺陷而非模型能力不足**
- 协调应被视为"可配置的架构层"——与Agent逻辑分离
- 在100个Polymarket预测市场上用同一LLM测试了5种协调配置

#### 二、范式转换: 从"设计拓扑"到"让拓扑自己生长"

| 旧范式 | 新范式 |
|--------|--------|
| 设计角色和层级 | 给Agent交互协议, 让角色涌现 |
| Orchestrator分配任务 | Agent自己决定做什么 |
| 固定拓扑(DAG/树/星) | 动态拓扑(自组织) |
| "更聪明的orchestrator" | "更好的交互规则" |
| 设计=画出架构图 | 设计=定义Agent间的交互约束 |

**深层原因**:
- 设计者无法预知所有任务的最佳分工——任务本身在变化
- 中心orchestrator=信息瓶颈+单点故障
- Agent通过实际交互"学到"的分工比任何预设计更精确

#### 三、跨域三角验证

| 维度 | 对应原则 | 自组织Agent的解释 |
|------|---------|-----------------|
| **物理** | 铁律10(简洁涌现)+铁律9(弱同步) | 简单交互规则→复杂协调涌现。弱同步>强同步 |
| **经济** | Hayek分散知识+Ostrom第三条路 | 价格信号=Agent交互协议。自组织=第三条路 |
| **中华** | 道家无为而治 | "圣人无常心"=不预设agent角色 |
| **宗教** | 华严53参+塔木德少数意见 | 多种路径自组织→最终协调 |

#### 四、一条可操作规则

> **自组织优先**: 多Agent系统默认使用自组织协议——Agent从任务中自发发现分工, 非预先设计角色。只有当自组织失败率>阈值时才引入设计拓扑。设计精力从"定义Agent"转移到"定义Agent间交互协议"。角色=涌现的, 非分配的。

### 2026-05-08 Growth Loop #3: 锯齿智能 — Karpathy和Ilya在讲同一个结构性缺陷，arXiv在做工程回应

**来源**: Karpathy Sequoia AI Ascent炉边谈话(2026.4.29) + Ilya Sutskever Dwarkesh播客(2025.11,持续发酵) + arXiv 2605.05657(RGAO) + 2605.06623(MASPO) + 2604.25917(RecursiveMAS)
**池**: Pool 2 (前沿情报)
**跨域连接**: 物理铁律4(混沌边缘) + Ricardo比较优势 + 孙子"知彼知己"

#### 一、同一个诊断，两个入口

Karpathy和Ilya从不同路径走到了同一块天花板下。

**Karpathy的入口——现象层**:
- "锯齿状智能"(Jagged Intelligence): AI能重构10万行代码，却让你走路去洗车(50米)
- 锯齿的根源=**可验证性悬崖**: 数学/代码有清晰的正确/错误信号→RL大量优化→在这些"铁轨"上AI飞行。日常物理/常识/空间推理没有廉价验证信号→RL从未触及→在这些"丛林"里AI拿砍刀开路
- "你可以外包思考，但不能外包理解"——Agent可以替你推理，但你不理解的东西你无法验证，不验证的东西你不知道对不对

**Ilya的入口——机制层**:
- 规模时代结束，回归研究时代——预训练数据耗尽，算力边际效益递减
- 人类几小时学会的技能AI需要海量数据→差距不在算力，在**价值函数**
- 人类的情绪/直觉/身体感受构成了强大的内部价值函数——不需要外部标注就能判断"这个动作对不对"
- LLM没有这个——它只能在有外部验证信号的域里通过RL优化，在没信号的域里只能模仿训练数据中的统计模式

**同一个诊断**:
| 维度 | Karpathy | Ilya |
|------|---------|------|
| 现象 | 锯齿状智能 | 泛化瓶颈 |
| 机制 | 可验证性悬崖 | 价值函数缺失 |
| 后果 | 超人在轨道上，白痴在丛林里 | 规模不再带来质变 |
| 出路 | Agentic Engineering(人守住验证) | 基础研究突破(赋予AI价值函数) |

#### 二、锯齿智能的结构性后果

**对单Agent**: 能力不是连续的——是岛链。Agent在Benchmark上的"平均分"掩盖了在真实任务中踩到锯齿谷底的概率。一个平均分90的Agent可能在你的特定任务上得0分——因为你的任务正好落在它的锯齿谷底。

**对多Agent系统**: 
- 如果所有Agent基于同一模型→锯齿剖面相同→**相关性崩塌**: 所有Agent在同一类输入上同时失败
- 这就是昨天Growth Loop #2的自组织战胜中心化的深层原因——自组织让不同Agent暴露在不同的任务子集上，自然形成了锯齿剖面的互补
- RGAO(2605.05657)恰好证实了这一点: 不做拓扑选择时，错误路由率30.1%——30%的任务被送到了在该任务上处于锯齿谷底的Agent

**对训练**: Ilya的核心论点——我们只能优化"有廉价验证信号的域"，而这些域恰好是代码/数学/逻辑。这些域被过度优化→形成了超人的"锯齿峰"。日常推理域被系统性忽视→形成了白痴的"锯齿谷"。

#### 三、arXiv的三条工程逃生路线

arXiv上三篇5月论文恰好对应三种绕过锯齿智能的策略:

**策略1: 拓扑自适应路由 (RGAO, 2605.05657)**
- 不假设Agent能力均匀→在路由前先提取任务的5维结构复杂度向量
- 根据任务剖面选择拓扑: FastPath(简单任务) / SubAgent(中等) / MultiAgent(复杂) / DeepResearch(极复杂)
- 错误路由率从30.1%降至8.2%
- **核心**: 不是"让Agent更强"——是"不要让Agent做它锯齿谷底的事"

**策略2: 联合提示词优化 (MASPO, 2605.06623, ICML 2026)**
- 不单独优化每个Agent的提示词→联合优化所有Agent
- 进化束搜索在提示词空间中导航，桥接局部Agent目标与全局系统目标
- 6个任务上平均+2.9%
- **核心**: 单个Agent的提示词最优≠多Agent系统最优。锯齿剖面之间的互补比单个剖面的高度更重要

**策略3: 潜空间通信 (RecursiveMAS, 2604.25917, Stanford+MIT+NVIDIA)**
- 把Agent间通信从文本降到潜空间→递归循环而非文本群聊
- 75.6% token减少，2.4倍加速，+8.3%准确率
- **核心**: 自然语言有它自己的锯齿剖面(某些概念语言表达精确，某些模糊)。绕过语言=绕过锯齿

#### 四、跨域三角验证

| 维度 | 对应原则 | 锯齿智能的解释 |
|------|---------|--------------|
| **物理** | 铁律4 混沌边缘操作 | 锯齿智能=Agent总是既在轨道上(有序)又在丛林里(混沌)。操作点必须在锯齿峰和锯齿谷之间的过渡带——太靠峰则脆(遇到谷就崩)，太靠谷则弱 |
| **经济** | Ricardo比较优势 | 不是找"最强Agent"——是找"在这个子任务上锯齿峰最高的Agent"。不同Agent的优势域不同→比较优势自然形成 |
| **中华** | 孙子"知彼知己，百战不殆" | 知彼=知道每个Agent的锯齿谷底在哪里(不知道谷底=让Agent做它注定失败的事)。知己=知道全局系统中哪些任务落在了所有Agent的谷底(需要人类干预) |

#### 五、一条可操作规则

> **锯齿剖面登记**: 部署多Agent系统前，不在综合Benchmark上评估——在**5个锯齿维度**(逻辑验证/常识物理/空间推理/因果链/模糊判断)上分别测绘每个Agent的能力剖面。路由时查询剖面数据库——任务分类后只路由到该维度锯齿峰高度>阈值的Agent。当某任务在所有Agent的该维度上都处于谷底→标记为"锯齿盲区"→升级到人类或使用完全不同模型族的Agent。

**与昨日Growth Loop #2的协同**:
- 昨日: 自组织>中心设计(因为设计者无法预知所有任务剖面)
- 今日: 自组织+锯齿剖面登记>纯自组织(因为自组织本身也可能陷入"所有Agent在同一谷底集体失败"的El Farol互锁)
- 合成: **设计=测绘锯齿剖面+定义交互约束。角色和分工=从剖面差异中涌现，不预设。**

### 2026-05-10 Growth Loop #4: 半真检测 — 财务叙事中"真话只说一半"是交易决策的最大隐蔽风险

**来源**: RADAR (arXiv:2604.19005, ACL 2026) — Role-Anchored Multi-Agent Reasoning for Half-Truth Detection
**池**: Pool 2 (前沿情报)
**跨域连接**: 物理铁律3(叠加态推理) + El Farol预期互锁 + 孙子"虚则实之"

#### 一、核心机制

RADAR的靶点不是"假话"——是**半真话**: 陈述本身事实正确，但通过省略关键上下文产生误导。传统事实核查对此盲区很大——说它"假"不对，说它"真"又被误导。

三个角色结构:
- **Politician(政客)**: 基于检索证据构建支持主张的连贯叙事——"为什么这可能是真的"
- **Scientist(科学家)**: 批判性挖掘证据中被省略的、薄弱的、选择性呈现的上下文——"没说出来的部分是什么"
- **Judge(法官)**: 中立评估辩论充分性，输出 True/Half-true/False

关键创新: 双阈值自适应提前终止——辩论充分即停，不浪费token。

结果: +19.3%准确率(vs单Agent)，跨模型泛化(GPT-4o-mini/LLaMA3/Qwen2.5均稳定增益)，ACL 2026接收。

#### 二、交易决策映射: 财务半真话是韭菜收割机

金融市场是半真话的完美滋生地。以下五类半真话在中国A股财报/公告中高频出现:

| 半真话类型 | 典型陈述 | 被省略的关键信息 |
|-----------|---------|----------------|
| 收入增长型 | "Q1营收同比增长40%" | 毛利率从35%降到18% |
| 订单暴增型 | "在手订单50亿" | 40亿是意向合同，无法律约束力 |
| 政策利好型 | "纳入国家科技专项" | 补贴金额仅为营收的0.3% |
| 技术突破型 | "发布全球首款X芯片" | 仍在流片阶段，量产至少2年 |
| 机构加持型 | "社保基金新进十大股东" | 是被动指数配置，非主动选股 |

**现有多Agent系统的盲区**: 当前adversarial-review使用"多头vs空头"辩论框架。多头说利好，空头说利空。半真话恰好卡在中间——不是明确利好(空头会驳)，也不是明确利空(多头会驳)。它是"事实正确但误导"的灰色地带。多头可能拿它当武器，空头可能放过它(因为反驳成本高——需要挖掘"没说出来的数据")。

**RADAR方案映射到交易**:
- Politician → 公司官方叙事(财报原文/公告/IR话术)
- Scientist → 专门找"没说出来的数字": 营收涨了但毛利率呢? 订单多了但履约率呢? 市场大了但份额呢? 补贴到了但占利润比呢?
- Judge → 判断每个"利好"是完整真实/选择性披露/虚假陈述

#### 三、跨域三角验证

| 维度 | 对应原则 | 半真检测的解释 |
|------|---------|--------------|
| **物理** | 铁律3 叠加态推理 | 半真话=真相和误导的叠加态。在验证"没说出来的部分"之前，不能坍缩到"真"或"假"。Scientist的角色=追问未测量维度→迫使叠加态坍缩 |
| **经济** | El Farol预期互锁 | 当所有投资者看到相同的半真话(如"营收增长40%")→形成一致预期→股价已反映这个半真信息。Scientist找到的"没说出来的部分"=预期互锁的裂缝=alpha来源 |
| **中华** | 孙子"虚则实之，实则虚之" | 公司IR的"实"(公开披露的数字)恰是"虚"(省略了关键背景)。Scientist的任务=找到被隐藏的"实" |

#### 四、一条可操作规则

> **半真检测注入adversarial-review**: 开仓/加仓前，在现有"多头/空头"辩论之外，增加第三个角色——**Scientist(半真猎手)**。Scientist不争多空，只做一件事: 对每一个"利好陈述"，追问"这个数字背后没说的是什么?"。追踪五项被省略指标: 毛利率vs营收增速、履约率vs订单金额、补贴占比vs研发投入、经营现金流vs净利润、大股东增减持vs机构持仓变化。当Scientist标记≥1个半真项→自动将置信度下调一级。Scientist不输出多空结论，只输出"未言列表"(What's NOT being said)。

**与Growth Loop #3(锯齿智能)的协同**:
- #3的诊断: Agent在低可验证性域(常识/模糊判断)会踩锯齿谷底
- #4的补充: 财务半真检测恰好需要Agent在"挖掘被省略信息"这个维度上工作——这个维度的可验证性中等(可以事后验证，但事前需要猜测)。单一Agent容易漏，三角色辩论结构正好弥补了单个Agent的锯齿谷底
