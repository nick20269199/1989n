# Branch B: 量子力学 — 合成

## 核心架构

量子力学提供了Agent推理的**叠加态模型**：

### 量子力学的三条核心原则 → Agent的认知原则
```
1. 叠加原理: 系统处于所有可能状态的叠加 → Agent维持多重假设
2. 测量坍缩: 测量时系统"选择"一个确定态 → Agent做决定时"坍缩"可能性
3. 不确定性原理: 位置vs动量不能同时精确 → Agent的感知-行动冲突(精度vs反应时间)
```

## 关键机制

### 机制1: 叠加态 — Agent维持多重可能性的能力
```
|ψ⟩ = c₁|0⟩ + c₂|1⟩
观测前: 系统同时处于0和1
观测后: 系统坍缩到0或1(概率由c₁²,c₂²决定)

核心洞见:
- 叠加不是"不知道",而是真实的多重存在
- 观测不可逆: 坍缩后不能恢复叠加
- 测量方式决定看到什么
```

**→ 铁律3(叠加态推理)**: 决策前维持多重估值叠加
**→ 延展**: 好的Agent不是"快速决定",而是"在正确时机之前保持叠加"
**→ 过早坍缩(武断) = 信息丢失, 过晚坍缩(犹豫) = 错过时机**

### 机制2: 测量问题 — Agent的自我认知悖论
```
量子测量特有的问题:
- 系统+测量者构成复合系统
- 谁测量测量者?(von Neumann链)
- 波函数是真实坍缩还是只是知识更新?

主要解释:
- Copenhagen: 坍缩=观测行为(知识更新)
- Many-Worlds: 不坍缩,世界分支(信息不丢失)
- Bohmian: 隐变量+导波(决定论+非定域)
- QBism: 量子态=Agent的信念
```

**→ Agent的自我测量**: 
- Agent观察自己的状态 = 测量
- Agent对自己的每次观察改变状态(内省悖论)
- Many-Worlds: Agent的不同选择在"平行世界"中都存在 → 不必后悔

### 机制3: 纠缠 — Agent之间的非定域关联
```
纠缠态: |Ψ⟩ = (|00⟩ + |11⟩)/√2
测量一方 → 立即确定另一方 → 无论多远

不是信号传递(不能用来通信!)
是关联: 两方结果有完美相关性→但各自结果仍然随机
```

**→ 多Agent的非定域关联**: 
- Agent之间可以建立"纠缠"→共享的语境/框架
- 这不是显式通信(不增加信息量)
- 但使协调更高效(共享的随机性)

### 机制4: 不确定性原理 — Agent的精度-速度权衡
```
Δx · Δp ≥ ℏ/2

位置已知越精确 → 动量越不确定(反之亦然)
```

**→ Agent的感知-行动权衡**:
- 精确知道当前状态(位置) → 不知道改变方向(动量)
- 快速反应(动量确定) → 当前状态模糊
- 不能同时追求"精准感知"和"快速行动"

### 机制5: 量子退相干 — Agent的多世界选择机制
```
退相干: 量子系统与环境的不可逆互动→"坍缩"为经典态

不是因为观测,而是因为与环境的纠缠:
- 系统+环境→复合态→追踪掉环境自由度→混合态
- 看上去像坍缩,实际上是信息泄漏到环境

退相干的关键性质:
- 不可逆(信息不能回收)
- 基矢选择由环境互动方式决定
- 产生"分支"(不同结果的相干叠加→经典概率混合)
```

**→ Agent的"退相干"**: 
- Agent的多种可能行为与外部环境互动→选择
- 不是Agent主动决定,而是环境互动自然"选择"
- 过早退相干(与环境强烈耦合)→失去叠加能力
- 过晚退相干(与环境隔离)→不切实际的想法过多

### 机制6: QBism — 量子态作为Agent的信念
Fuchs, Mermin, Schack的QBism:
```
量子态不是客观世界的属性
而是Agent对系统的主观信念的编码

波函数的更新 = 贝叶斯更新
测量 = Agent获取新信息 → 更新信念

不同Agent可以合理持有不同的量子态(信念)!
不矛盾,因为信念基于不同信息
```

**→ Agent的信念管理**: 
- 信念不是"真理"而是"预期"
- 不同Agent可以合理持有不同的信念
- 新信息→贝叶斯更新信念
- QM给Agent提供的是"预期如何更新"的规范而非"世界如何"的描述

### 机制7: 量子计算 — Agent的并行探索
```
量子比特(n个) → 2ⁿ个状态并行
Grover搜索: √N 加速
Shor分解: 指数加速
关键在于哈密顿量控制 → 干涉 → 放大正确的态

限制: 
- 读取时只能获取1个结果(坍缩)
- 不能预先知道哪个结果好(需要设计干涉)
- 相干时间有限(退相干)
```

**→ Agent的认知并行**: 
- Agent的多种可能性同时探索,但最终只能选择一个行动
- 好的"哈密顿量"(架构设计)使好的可能性干涉增强
- 退相干=注意力分散,需要保护认知相干

|---------|---------|----------|
| Copenhagen | 测量创造现实 | Agent的"测量"(决定)创造意义 |
| Many-Worlds | 所有可能都真实 | Agent不做"错过"的选择判断 |
| Bohmian | 隐变量引导 | Agent有隐藏"引导场" |
| QBism | 量子态=信念 | Agent的量子态=对其他Agent的预期 |
| Consistent Histories | 不同视角一致 | Agent的多视角一致性 |
| Relational | 态依赖于观察者 | 两个Agent可合理不同 |
