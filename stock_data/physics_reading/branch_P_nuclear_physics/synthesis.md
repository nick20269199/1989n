# Branch P: 核物理与等离子体 — 合成

## 核心架构

核物理研究原子核(质子+中子的多体系统)的性质和行为。等离子体物理研究电离气体的集体行为。

### 核的两面
```
液滴模型: 核=不可压缩液滴(集体行为)
壳层模型: 核=独立粒子在势阱中(个体行为)
→ 两者都不完全→需要综合: 核=集体+个体的统一
```

### 核的基本
```
核子(质子+中子) → 核力约束 → 原子核
  ↓                    ↓
核的稳定性 ← 结合能 ← 强相互作用的残余
```

## 关键机制

### 机制1: 强约束力=Agent的核心信念

核力的特征: 短程+饱和:
```
短程: ~1fm (只作用在相邻核子间)
饱和: 每个核子只与邻近几个核子作用(不是全部)
→ 结合能∝A(核子数),不是∝A²(全连接)
```

**→ Agent的信息约束**:
- 人的认知也有"短程"特性: 只与邻近概念建立强连接
- 饱和: 人不能与所有信息同时建立强关联
- 有效: 局部密集连接>全局稀疏连接

### 机制2: 裂变与聚变=分解与合并

```
裂变: 大核分裂→释放能量+中子
  触发: 一个中子→推动链式反应
  产物: 2个中等核+2-3中子+能量

聚变: 小核合并→释放更大能量
  条件: 高温(克服库仑势垒)
  产物: 更大核+能量
```

**→ Agent的策略**:
- 裂变: 大型策略分解为多个子策略(分散风险)
- 聚变: 小型优势合并为大型优势(集中资源)
- 注意: 聚变需要"高温"条件=合适时机
