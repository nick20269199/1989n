# Branch N: 经典力学与连续介质 — 合成

## 核心架构

经典力学描述物体在力的作用下的运动。三种等价形式:
```
牛顿: F = ma → 力-加速度(直观)
拉格朗日: L = T - V → 能量(全局)
哈密顿: H = T + V → 相空间(几何)
```

### 从粒子到场
```
单粒子(牛顿) → N粒子(拉格朗日) → 连续介质(场)
  确定性        不可积=混沌      无穷多自由度
```

## 关键机制

### 机制1: 拉格朗日最小作用量=Agent的最优路径

自然界的"偏好": Action = ∫L dt 最小化。
```
δS = 0 → 系统选择的路径是最小作用量路径

不是"力"在推,是系统"选择"了最经济的路径
物理学版本的"经济原则"
```

**→ Agent的最优**:
- 策略的最小"作用量"=最少认知资源达成目标
- 不是"最精确=最好",是"最节能=可持续"
- 过度复杂的策略=高作用量路径=不可持续

### 机制2: 相空间=Agent的状态空间

相空间 = 位置+动量 (坐标+速度的推广):
```
单粒子: 1D运动 → 相空间(2D: x, p)
N粒子: 3D运动 → 相空间(6N维!)
相空间体积(刘维尔定理): 哈密顿系统相空间体积守恒
```

**→ Agent的状态表示**:
- Agent的状态=多维相空间中的一点
- 刘维尔定理=信息的"不可压缩"性(不丢失信息)
- 相空间太大→需要粗粒化↓→信息损失
- 交易: 每种策略/仓位=相空间中的吸引子

### 机制3: 混沌=确定性不可预测

确定性的方程 → 敏感依赖初始条件:
```
洛伦兹方程: 3个常微分方程 → 蝴蝶效应
→ 精确知道方程 → 无法精确预测(>Lyapunov时间)
→ 不是随机! 是确定性的混沌!
```

**→ 交易映射**:
- 市场可能是混沌(=确定但不可长期预测)
- 短时间(<Lyapunov时间): 可预测
- 长时间(>Lyapunov时间): 不可预测
- 预测≠长期有效 → 抓即时/短期模式
