# Branch D: 信息论与计算 — 合成

## 核心架构

信息论为Agent提供了**信息/通信/计算的量化极限**。任何Agent无论多智能,都受香农极限/计算复杂度/算法不可解性的根本约束。

### 三条主线
```
信息测量 ────→ 通信极限 ────→ 计算极限
(熵/KL散度)   (信道容量)    (P/NP/可计算性)
    │              │              │
    ↓              ↓              ↓
 Agent的         Agent之间       Agent能/不能
不确定性量化     通信效率上限    计算什么
```

## 关键机制

### 机制1: 香农熵 = Agent的信息预算

```
H(X) = -Σ p(x) log₂ p(x)

→ 编码一个符号平均需要的最少比特数
→ 信息=不确定性的消除量
→ 最大熵=所有可能等概率(完全不确定)
→ 零熵=完全确定(无信息)
```

**→ 铁律1(熵预算)的信息论版本:**
- Agent的推理预算 = 降低不确定性的能力
- 每获得1bit信息 → 不确定性减半
- 但信息获取有成本(Landauer)
- Agent不需要"完全确定"只需要"足够确定"

### 机制2: 信道容量 = Agent的通信上限

```
C = max I(X;Y) = B log₂(1 + S/N)

香农: 在噪声信道上,存在编码使信息以任意低错误率传输
但传输速率不能超过信道容量C
```

**→ Agent的通信极限:**
- 两个Agent间的信息交换有上限
- 增加带宽/降低噪声=提升通信效率
- 但不能超过香农极限
- Agent的"有效沟通"需要考虑信道容量

### 机制3: Kolmogorov复杂度 = Agent的"理解"成本

```
K(x) = 能生成x的最短程序长度

随机序列: K(x) ≈ |x|(没有更短描述)
规律序列: K(x) << |x|(有更短描述)
→ "理解"=找到更短描述
```

**→ Agent的"学习"=最小化描述长度:**
- 学习的本质=找到数据的最短程序/模型
- 好的模型=描述长度最短的模型
- 奥卡姆剃刀=最短描述原则
- Agent的"理解"=找到压缩数据的方式

### 机制4: 计算复杂度 = Agent的实时约束

```
P = 多项式时间可解(可行)
NP = 非确定性多项式(验证易/求解难)
EXPTIME = 指数时间(不可行)

Agent的实时决策约束:
- 不能在多项式时间内解决的问题→需启发式
- 不能在有限时间停机的程序→不可判定
```

**→ Agent的"快速思考"受计算复杂度限制:**
- 最优策略可能在NP中→只能近似/启发式
- Agent需要在"最优"和"可行"之间选择
- 这是铁律1(熵预算)的计算版本

### 机制5: 最大熵原理 = Agent的无偏推理

Jaynes:
```
在没有额外信息时,选择熵最大的分布(最不偏见的)
→ 这是贝叶斯推理的先验选择原则
→ "不知道"的正确表述=均匀分布
```

**→ Agent的公平推理原则:**
- 当没有数据时,不要做无根据的假设
- 最大熵=最小偏见
- 新信息→条件熵降低→更确定
- Agent的U4中介声明: "我的判断基于这些信息,不是全部信息"
