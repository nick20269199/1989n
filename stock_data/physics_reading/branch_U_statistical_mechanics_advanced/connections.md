# Branch U: 统计力学进阶 — 跨域连接

## 与经济学连接

| 统计力学进阶 | 经济学 | 连接 |
|-------------|--------|------|
| 涨落定理 | 有效市场假说 | 市场效率=涨落对称性: 套利机会=涨落偏离,大偏差压制→市场趋近有效 |
| Jarzynski等式 | 不可逆投资 | 投资不可逆(Jarzynski功分布不对称),但长期平均可恢复平衡价值 |
| 热力学不确定性 | 风险-收益权衡 | 精度(收益确定性)需要成本(风险),无免费午餐的定量版 |
| 随机热力学 | 微观经济学 | 每笔交易=微观能量账,总市场=系综平均 |
| 大偏差理论 | 尾部风险/金融危机 | 金融危机=率函数变化(体制转换),不是简单高斯尾部 |
| 活性物质 | 市场微观结构 | 自驱动交易者=活性粒子,订单流=活性流体,价格=序参量 |
| 涨落-耗散定理 | 价格-冲击关系 | 价格对订单的敏感度=市场深度(涨落-耗散对偶) |
| 不确定性关系 | 夏普比率上限 | 策略夏普比率有热力学上限(精度-成本边界) |

| 系综与轨迹 | 莱布尼茨"可能世界" | 实际轨迹 vs 所有可能轨迹的分布 |
