# Branch J: 粒子物理与标准模型 — 合成

## 核心架构

粒子物理回答"物质的最基本构成是什么?"。

### 标准模型概要

```
物质粒子(费米子)         传递力(玻色子)
  ┌────┴────┐            ┌────┴────┐
夸克        轻子        规范玻色子  Higgs
(u/d/c/s/t/b) (e/μ/τ/ν)  (γ/g/W/Z)  (H)

第一代   第二代   第三代       力         载体
(u,d,e,ν) (c,s,μ,ν) (t,b,τ,ν)  电磁       γ
                               强力       g
                              弱力     W/Z
                              质量   Higgs
```

### 核心观念: 物质=粒子+相互作用+对称性

## 关键机制

### 机制1: 物质的三代结构

三代夸克和轻子,每代是上一代的"重版本"。
```
第一代: 构成日常物质(稳定)
第二代: 只在高能中存在(不稳定)
第三代: 更重,更不稳定

为什么是三? → 不知道(开放问题)
```

**→ Agent的分层分类**:
- 第一代因子=每日使用(稳定可靠)
- 第二代因子=特殊场景使用
- 第三代因子=仅在极端条件出现
- 类似: 交易中的主策略/辅助策略/应急策略

### 机制2: 相互作用=力的传递

四种基本力通过交换玻色子传递:
```
电磁力: 光子(∞范围,α≈1/137)
强力: 胶子(~10⁻¹⁵m,αₛ≈1)
弱力: W/Z (~10⁻¹⁸m,α_w≈1/30)
引力: 引力子(∞,极弱,未发现)

力≠接触 → 力的本质=交换"信使粒子"
```

**→ Agent的"相互作用"**:
- 信息传递=交换"信使"(数据/消息)
- 每类交互有不同"耦合常数"(效率)
- 强力=高带宽高成本通信,电磁=低成本低带宽
- 弱力=稀少但关键的交互

### 机制3: Higgs机制=质量起源

粒子通过与Higgs场相互作用获得质量:
```
无Higgs: 所有粒子无质量(像光子在真空中)
有Higgs: 粒子"拖曳"Higgs场→表现为质量

Higgs玻色子= Higgs场的量子化激发(2012年发现)
粒子质量∝ 与Higgs场的耦合强度
```

**→ Agent的"惯性"**:
- 信念的"质量"=改变它有多难
- "重"信念=被常识/经验/数据强化的
- "轻"信念=临时的假设/猜测
- Higgs→使信念有惯性(不容易被每一条新信息翻转)
