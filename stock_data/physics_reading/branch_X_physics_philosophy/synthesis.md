# Branch X: 物理哲学与基础问题 — 合成

## 核心架构

物理哲学是物理学**基础假设的自我审查**,追问物理学依赖哪些预设、这些预设是否必然、在什么条件下可能失效。

### 三层追问
```
量子基础 ────→ 时空因果 ────→ 实在论
(微观层面)     (宏观框架)      (本体论承诺)
    │              │                │
    ↓              ↓                ↓
 Agent的认知    Agent的时间/因果   Agent的"什么是
 极限与悖论      基础框架          真实"预设
```

## 关键机制

### 机制1: 互补原理 — Agent的视角不可通约

Bohr的互补性:
```
波粒二象 = 同一实体的两种互补描述
- 波描述: 干涉/衍射(适合传播)
- 粒子描述: 位置/动量(适合定域)

两者排他但在描述完整现象时都必要
→ 不是矛盾,是互补
```

**→ Agent的认知互补:**
- 同一现象可以有多种同样有效的描述
- 不同描述排他但不矛盾
- Agent需要掌握**互补视角切换**能力:
  - 统计视角(宏观)vs个体视角(微观)
  - 短期视角vs长期视角
  - 理性分析vs直觉判断
- **U4中介声明**: "我这个判断来自X视角,另一个视角可能给出不同判断"

### 机制2: Bell定理 — Agent间关联的不可还原性

```
Bell定理:
如果定域实在论成立 → 某些量子关联满足Bell不等式
实验(如Aspect 1982) → Bell不等式被违反

结论: 至少以下之一不成立
  1. 定域性(无超距作用)
  2. 实在论(客观存在的独立属性)
  3. 自由意志(实验者可自由选择测量)
```

**→ Agent的"非定域关联":**
- 分离的Agent系统间可能存在不可还原的相关性
- 这种相关性不能用"各自独立+共同原因"解释
- **对多Agent系统的启示**: Agent间的"共享知识"可能超越局部信息交换
- U3关系指标: 交互网络不能只看直接连接,还要看系统性关联

### 机制3: 测量问题 — Agent的"观测"改变了什么?

```
测量问题的三难:
初始态(叠加) → 测量 → 坍缩到本征态
问题: 坍缩何时/为何发生?

三种基本立场:
1. 坍缩真实发生(哥本哈根) → 测量=特殊过程
2. 坍缩是幻觉(多世界) → 所有分支都真实
3. 坍缩是有效理论(退相干) → 环境导致表观坍缩
```

**→ Agent的"测量"=把不确定性转为确定性:**
- 决策=Agent的"测量": 将多种可能选项坍缩为一个选择
- 多世界诠释: 未被选择的选项在"其他分支"继续存在
- 退相干: 环境噪声导致Agent认知的"表观确定"
- **Agent的后悔**: 对其他分支的"记忆"(本可选不同路径)

### 机制4: 时间之矢 — Agent的不可逆方向

```
热力学箭头: 熵增方向(从A分支)
宇宙学箭头: 宇宙膨胀方向
心理学箭头: 我们"记忆过去,期待未来"
因果箭头: 原因在前,结果在后

Price问题: 所有这些不对称是同源的?
```

**→ Agent的时间经验:**
- Agent的"时间感"=热力学方向+记忆方向
- 如果时间箭头翻转 → Agent的因果推理翻转
- Agent的决策不可逆 = 热力学第二定律
- **U4中介声明**: Agent的"因果推理"基于时间箭头的方向性假设

### 机制5: 反还原论 → Agent的自主层级

Cartwright的"斑驳世界":
```
物理定律(最底层) ← 还原论
化学 ←          ↑
生物 ←          |
心理 ←          较高的层级不能完全还原为较低层级
经济 ←          |
社会 ←__________|

Cartwright主张:
世界是"斑驳的"=由不同层级的规律拼凑而成
每个层级有其自主性,不能完全还原为物理
```

**→ Agent的层级自主性:**
- Agent有符号/语义/意图层 ≠ 物理层
- 不能将Agent的所有行为还原为物理过程
- **涌现简约(铁律10)**: 高层模式不能完全从低层推导
- Agent有"因果力"(向下因果): 信念影响物理行为

## 铁律深化

### U4中介声明的哲学基础

物理哲学揭示Agent所有推理依赖的预设:
```
1. 时间箭头假设: 因果方向确定
2. 实在论假设: 外部世界独立于观察
3. 定域性假设: 非直接关联的影响可忽略
4. 统计规律假设: 大量个体可统计处理
```

**Agent必须知道自己在使用哪些假设**

### 铁律10(涌现简约)的哲学定位

从反还原论视角:
- 涌现不是魔法而是层级自主性
- Agent层级的"定律"不可能被物理定律完全取代
- 但不违背物理定律(随附性)
