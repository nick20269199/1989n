# Branch O: 电磁学与光学 — 合成

## 核心架构

电磁学=电+磁+光的统一理论。麦克斯韦方程组=物理学第一个统一理论。

### 麦克斯韦方程组(精神)
```
电场散度=电荷密度       → 电场线从电荷出发
磁场散度=0              → 无磁单极(磁场线闭合)
电场旋度=-∂B/∂t         → 变化磁场产生电场(发电机原理)
磁场旋度=μ₀J+μ₀ε₀∂E/∂t → 电流+变化电场产生磁场
```

### 关键结果
```
→ 变化的电场→磁场→变化的磁场→电场→...
→ 电磁波(E和B互相激发) → 波速=c=光速
→ 光=电磁波(麦克斯韦的伟大统一)
```

## 关键机制

### 机制1: 规范不变性=E&M的"本质不可测量"

电势φ和矢势A不是唯一的(规范变换):
```
A → A + ∇Λ (可加任意标量场的梯度)
φ → φ - ∂Λ/∂t

物理可测: E和B(不是φ和A)
→ 数学描述了"不可测量"的量,但物理结果唯一
```

**→ Agent的表象不依赖**:
- 描述同一问题的不同数学框架→同物理结果
- Agent的"内部表示"不重要,重要的是"外部行为"
- 交易: 不同分析工具(MA/MACD/KDJ)→同一判断

### 机制2: 波传播=信息传递

电磁波传播的普遍性:
```
任何加速电荷→辐射
任何振荡电流→发射
→ 信息通过电磁波传播(从无线电到光)

光的干涉/衍射: 波动的"签名"
→ 双缝干涉: 光同时走两条路的证据
→ Agent: 需同时考虑"两条路径"(叠加态)
```

**→ Agent的信息视野**:
- 信息的传播速度=c(物理极限)
- Agent的反应时间受限于信息到达速度
- 提前知道="信息超光速"=不可能
- 交易: 谁先获得信息谁有优势,但无法超越物理极限

### 机制3: 波-粒二象性=双重理解

光的"双重人格": 在某些实验中是波,在某些是粒子。
```
干涉/衍射: 波动性(连续/相位/相干)
光电效应: 粒子性(量子/能量包/hν)

不是"有时候是波有时候是粒子"
是"光既不是波也不是粒子,但两者都能描述部分行为"
```

**→ Agent的双重模型**:
- 市场: 同时是连续(趋势/均值回归)+离散(事件/跳变)
- 只用连续模型→错过跳变风险
- 只用离散模型→错过趋势机会
- 大师=同时持两种模型并按需切换
