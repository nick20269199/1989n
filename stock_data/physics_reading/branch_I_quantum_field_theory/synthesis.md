# Branch I: 量子场论 — 合成

## 核心架构

量子场论(QFT) = 量子力学 + 狭义相对论 + 场(无穷多自由度)。

### 世界图景的转变
```
经典: 粒子(点状实体)在时空(背景舞台)中运动
量子: 粒子在势阱中运动,有波粒二象性
QFT: 场是基元,粒子是场的量子化激发,时空和粒子统一在量子场中
```

### 核心洞察
```
场(无处不在) → 激发(量子化) → 粒子(可数)
真空(基态) ← 湮灭(退激发) ← 反粒子

每个点的场是无穷维谐振子 → 无穷多自由度
相互作用 = 场的非线性耦合
```

## 关键机制

### 机制1: 量子化 = Agent的"离散化"操作

经典场→量子场的程序:
```
经典场φ(x,t)
  → 傅里叶展开 → 每个模式=谐振子
    → 量子化每个谐振子 → 量子态|n⟩
      → 粒子的解释: n个该动量粒子
```

**→ Agent的离散化隐喻**:
- 连续(模拟) → 数字(离散) = Agent必备的量化能力
- 场量子化: 连续场变成可数粒子 = Agent的数据抽象(连续价格→离散信号)
- 谐振子能级: 0,1,2,... = Agent的置信度级别(不是连续置信是离散分级)

### 机制2: 重正化群(RG) = Agent的尺度变换

RG = 逐步粗粒化: 去掉短距细节 → 保留长距关键信息。
```
微观(高能) → 逐步粗粒化 → 宏观(低能)
     ↓              ↓              ↓
  全部信息      重要模式        普适行为
  计算量太大     可管理          简单规律

RG变换:
  1. 粗粒化(block spin)
  2. 重新标度
  3. 看参数如何变化(RG流)
```

**→ Agent的跨尺度分析**:
- 时间尺度: 分时(RG)→日线→周线=不同粗粒化
- 信息尺度: 全数据→特征工程→核心因子
- 决策尺度: 盘中微观→收盘中观→月线宏观
- **不动点**: 市场在某时间尺度呈现出"自相似"=分形

### 机制3: 有效场论 = Agent的"足够好"近似

低能有效理论: 在低能量下,高能细节不可分辨。
```
高能理论(QFT完整) → 积分掉高能模式 → 低能有效理论
                                                   ↓
                     不知道微观细节 → 能做低能预测

关键: 不同微观理论在低能下可能"不可区分"
  → Agent不需要"完全正确"的模型
  → 只需要"在当前尺度上有效"的模型
```

**→ 交易映射**:
- 不追求"完全精确"的市场模型(不可能)
- 追求"在当前时间尺度上有效的模型"
- 技术分析=有效场论(忽略微观机制,只看价格行为)
- 基本面分析=高能理论(关注微观机制)

### 机制4: 自发对称性破缺 = Agent的模式形成

系统的基态具有比方程更低的对称性。
```
水(H₂O)分子: 各向同性(旋转对称)
冰(固体): 有特定晶向(旋转对称破缺)
方程有全对称性,但实际状态选择了一个方向

→ "破缺"不是"破坏"是"选择"
→ 系统选择了一个基态(随机或受微扰引导)
```

**→ Agent的市场模式**:
| 全对称(混沌前) | 破缺(趋势形成) | 对称恢复(趋势结束) |
|--------------|--------------|----------------|
| 无方向的震荡 | 选择向上或向下 | 趋势耗尽回到震荡 |
| 所有可能性开放 | 现实选择了一个 | 回到可能性开放 |

→ 交易: 趋势=对称性破缺。破缺前的"犹豫期"能量最大,破缺后释放。

### 机制5: 费曼图 = Agent的决策路径可视化

每个费曼图代表粒子相互作用的一种"路径"。
```
e⁻ + e⁺ → γ → μ⁻ + μ⁺

费曼规则:
  - 外线 = 初/末态粒子
  - 顶点 = 相互作用
  - 内线 = 传播子(粒子在中间态传播)
  - 全图 → 一个过程的贡献振幅 ≈ 一个"故事"
  
总振幅 = 所有费曼图的和(无穷多图!)
```

**→ Agent的因果分析**:
- 每个费曼图 = 一个因果"故事"
- 总概率 = 所有可能故事的加权和
- 低阶图=大概率=直观解释
- 高阶图=小概率=精细修正
- Agent的"解释"=最多用前几阶(有效理论)

### 机制6: 真空与涨落 = Agent的"背景"认知

QFT的真空不是"空",是能量最低态+不断产生湮灭的虚粒子。
```
真空 = |0⟩ ≠ "什么都没有"
  ⟨0|φ(x)φ(y)|0⟩ ≠ 0 → 存在关联函数
  虚粒子对: 产生→传播→湮灭(在不确定性原理允许的时间内)
  真空能量 = 零点能 = Σ (½ℏω) → 无穷大!
```

**→ Agent的认知背景**:
- Agent的"静默状态"≠"没在想"
- 量子涨落 = subconscious processing = 随机的念头
- 市场噪声 = QFT真空涨落
- 零点能=无穷大 → 需要重正化(减掉无穷大 → 得到有限的物理量)
