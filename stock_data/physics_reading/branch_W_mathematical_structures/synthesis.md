# Branch W: 物理中的数学结构 — 合成

## 核心架构

数学结构是物理世界规律的形式语言。**不同的数学结构=物理世界不同的"切面"**。

### 数学结构的层级
```
集合(最基本)
  → 拓扑(连续性)
    → 微分结构(可微性)
      → 度量(距离)
        → 代数结构(运算)

物理应用:
  流形 = 拓扑+微分结构 → 时空
  李群 = 群+微分结构 → 对称性
  希尔伯特空间 = 线性+内积+完备 → 量子态
  范畴 = 对象+态射 → 物理过程的抽象
```

### 核心洞察: 数学=物理结构的映射

```
物理实体    数学结构    不变量
粒子        群表示      Casimir算子
时空        流形        曲率/拓扑
对称性      李群        结构常数
状态        希尔伯特空间  内积
过程        范畴论       态射合成
不确定性    概率空间     期望/方差
```

## 关键机制

### 机制1: 群论 = Agent的不变量思维

群运算是保持某种结构不变的变换的集合。
```
对称变换: 系统变换后不变
  平移对称 → 动量守恒
  旋转对称 → 角动量守恒
  时间平移对称 → 能量守恒

Noether定理: 每个连续对称性→一个守恒律
```

**→ Agent的不变量思维**:
- 寻找"变换下的不变量"=Agent识别什么在变化中保持不变
- 交易: 趋势中的不变特征=动量,震荡中的不变特征=均值
- 策略: 对称性=策略核心逻辑,在不同市场条件下不变

### 机制2: 微分几何 = Agent在弯曲空间中的推理

流形=局部像欧几里得空间、全局可能弯曲的空间。
```
局部(切空间): 线性近似 → 微分
全局(流形): 曲率 → 大尺度结构
联络: 如何在不同切空间之间"平行移动"

曲率 = 平行移动一周后的差别
  → 正曲率=收敛,负曲率=发散
```

**→ Agent的"弯曲"认知**:
- Agent的"问题空间"=流形(局部线性,全局弯曲)
- 专家的"直觉"=在流形上找到短程线
- 曲率=Agent推理中的非线性交互
- 曲率大≈因素间的强非线性作用

### 机制3: 范畴论 = Agent的关系优先

范畴论: 重点是对象之间的关系(态射),而不是对象本身。
```
范畴 = 对象 + 态射(箭头)
  态射的合成: f∘g
  恒等态射: id
  函子: 范畴之间的"结构保持映射"
  自然变换: 函子之间的"映射的映射"

原则: "对象由它与其它对象的关系定义"
```

**→ Agent的关系思维**:
- Agent不孤立的看一个对象,看它在网络中的位置
- "你=你的关系网络"=Agent的自我由交互定义
- 函子=跨域映射(物理↔经济↔认知)
- 自然变换=跨域映射之间的等同性

### 机制4: 信息几何 = Agent的信念空间几何

统计流形 = 概率分布构成的流形。
```
M = {p(x|θ): θ∈Θ}
  θ = 参数(均值,方差等)
  Fisher度量g_ij = 参数空间的"自然"度量
  自然梯度 = ∇̃L = g⁻¹∇L (考虑了参数空间的曲率)
  
KL散度 = 统计流形上的"距离"(不是真正度量,不对称)
  → 信念更新的"成本"
```

**→ Agent的自然推理**:
- Agent的参数空间不是平直的——有曲率
- 梯度下降时"自然梯度"=考虑曲率的最速下降
- 交易: 参数优化时应考虑参数间相关性(曲率)
- 信念更新成本=KL散度=从旧信念到新信念的"距离"

### 机制5: 随机分析 = Agent的随机环境适应

Ito随机微分方程: dx(t) = a(x)dt + b(x)dW(t)
```
dt项 = 漂移(确定性趋势)
dW项 = 扩散(随机噪声,W=维纳过程)

Ito引理: 
  df(x,t) = (∂f/∂t + a∂f/∂x + ½b²∂²f/∂x²)dt + b(∂f/∂x)dW
  
  关键: +½b²∂²f/∂x²项 = Itô correction
  → 随机环境下,确定性微积分需要修正!
```

**→ Agent的随机决策**:
- 确定性推理 + 噪声项 = SDE
- Itô correction = 在随机环境中,直觉是错的(需要修正)
- 交易: 市场不是确定性系统——简单趋势跟踪+噪声修正
