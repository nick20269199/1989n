# Branch E: 非线性动力学与混沌 — 跨域连接

## 与经济学

| 非线性动力学 | 经济学 | 连接 |
|------------|--------|------|
| 吸引子 | 市场状态 | 市场=多吸引子系统: 牛(极限环)/熊(不动点)/震荡(环面)/危机(离开吸引子) |
| 分岔 | 泡沫/崩盘 | 市场参数变化→临界点→状态突变(Sornette的LPPL预测崩盘) |
| 初值敏感性 | 不确定性/混沌 | 长期经济预测不可能(不是数据不够而是内在地不可预测) |
| 同步(Kuramoto) | 羊群效应/从众 | 交易者同步=节奏锁定=系统性风险 |
| 自组织临界性 | 市场崩溃的幂律 | 市场崩溃的大小服从幂律不是正态(Sornette/Mandelbrot) |
| 斑图形成 | 产业集聚/经济地理 | 产业的空间分布=Turing斑图(克鲁格曼核心-边缘) |
| 混沌控制(OGY) | 政策干预 | 微小干预→稳定混沌系统≈央行的小幅预期管理 |

## 与哲学

| 非线性动力学 | 哲学 | 连接 |
|------------|------|------|
| 确定性的混沌 | 自由意志vs决定论 | 决定论≠可预测→自由意志的"缺口"扩大了 |
| 吸引子 | 目的论/终极因 | 吸引子≈系统的"目的状态"(不需要意识的目的) |
| 分岔 | 偶然vs必然 | 分岔点=偶然(小波动决定方向),分岔之间=必然 |
| 涌现(Cooper Pair) | 整体论vs还原论 | 宏观有序不能还原到微观→非还原整体论 |
| 时间不可逆 | 柏格森/时间箭 | 耗散结构=时间不可逆的物理基础 |
| 复杂性/混沌 | 有限性/古典Chinese哲学 | 复杂性的有限性≈道的"不可道" |
