# Branch L: 宇宙学与天体物理 — 合成

## 核心架构

宇宙学回答"宇宙从哪来、到哪去"。标准宇宙模型=ΛCDM。

### 宇宙的热历史
```
大爆炸(奇点) → 暴涨(指数膨胀) → 重子形成 → 核合成(3min)
→ 复合(380kyr,CMB) → 黑暗时代 → 第一代恒星 → 星系形成
→ 暗能量主导(~50亿年前) → 加速膨胀 → (热寂/大撕裂?)
```

### ΛCDM宇宙的成分
```
暗能量(Λ): ~68% → 宇宙加速膨胀
暗物质(CDM): ~27% → 结构形成的骨架
普通物质: ~5% → 我们看到的星空/生命/地球
```

## 关键机制

### 机制1: 宇宙膨胀=背景的不可抗拒增长

星系的退行速度=哈勃常数×距离:
```
v = H₀·d

→ 不是星系在"移动",是空间本身在膨胀
→ 越远的星系退行越快(红移越大)
→ 可观测宇宙=退行速度<c的区域(460亿光年)
```

**→ 交易的"背景"**:
- 宏观趋势=宇宙膨胀(不可抗拒)
- 逆趋势=在膨胀宇宙中试图"静止"(失败)
- 顺趋势=借势(事半功倍)
- 可观测≈投资者能获取的信息边界

### 机制2: 结构形成=从小波动到大集聚

量子涨落→暴涨放大→引力坍缩→星系:
```
量子涨落(极早期)
  → 暴涨放大(指数膨胀使涨落成为"种子")
    → 引力坍缩(暗物质晕)
      → 普通物质落入 → 形成星系

层次结构: 小→大(不是同时形成的)
```

**→ 交易映射**:
- 小波动(噪声)→ 放大(趋势确认)→ 结构(趋势成型)
- 关键: 不是所有小波动都变成大结构
- 如何识别哪些波动是"种子"? = 有基本面的支撑

### 机制3: 暗物质与暗能量=认识未知

95%的宇宙成分我们不知道是什么:
```
暗物质: 有引力但不发光(不参与电磁作用)
  证据: 星系旋转曲线、引力透镜、CMB

暗能量: 导致宇宙加速膨胀
  证据: 超新星Ia的距离-红移关系
```

**→ Agent的"已知的未知"**:
- 市场的大部分"成分"也是不可见的
- 流动性、情绪、预期...=暗物质
- 宏观增速放缓/通胀=暗能量
- 承认"不知道"比假装知道更接近真实
