# Branch A: 热力学与统计物理 — 跨域连接

## 与经济学连接

| 热力学 | 经济学 | 连接 |
|-------|--------|------|
| 熵 | 市场有效性 | 完全有效市场=最大熵=无套利=无信息 |
| 自由能 | 效用函数 | 效用的热力学形式:收益-风险 |
| 耗散结构 | 创造性破坏 | 远离平衡≡创新的前提(铁律2已建立) |
| 涨落定理 | 黑天鹅 | 极端事件的概率限制 |
| Landauer原则 | 信息成本 | 信息获取/处理不是免费的 |
| 配分函数 | 一般均衡 | 所有可能状态的加权和 |

| 热力学 | 哲学 | 连接 |
