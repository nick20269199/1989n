# Branch V: 高能物理与弦论 — 合成

## 核心架构

弦论: 把粒子(点状)替换为弦(一维扩展物体)。

### 核心思想
```
点粒子(标准模型) → 振动弦(弦论)
  0维              1维扩展
  点状碰撞         弦的合并/分裂
  无限多种点       弦的振动模式→粒子

→ 电子=弦的某种振动模式
→ 光子=弦的另一种振动模式
→ 引力子=弦的闭合模式
```

### 弦论的"意外"结果
```
要求: 量子力学+广义相对论自洽
→ 自动要求: 超对称 + 10维时空
→ 自动包含: 引力子(量子引力)
→ 提供: 黑洞微观状态的计数
```

## 关键机制

### 机制1: 对偶=不同视角同一物理

弦论中最重要的发现: 强/弱耦合对偶:
```
S对偶: g → 1/g (强耦合↔弱耦合)
  对偶的一边: 强耦合(难计算) = 另一边: 弱耦合(易计算)

T对偶: R ↔ 1/R (大尺寸↔小尺寸)
  对大尺度R的物理=对小尺度1/R的同一物理
```

**→ Agent的对偶思维**:
- 一个"难"问题的对偶=一个"易"问题
- 换个角度看难问题=可能是简单问题
- 如: 预测股票涨跌(难)↔理解自己如何判断(易)
- 对不同的人: 同一个问题在不同"框架"中难度不同

### 机制2: 全息原理=表面的信息等于全部

AdS/CFT对偶: 一个低维的量子场论=一个高维的引力理论:
```
5维AdS时空(引力/体) ↔ 4维CFT(量子/边界)

边界上的"自由"量子理论
  = 体态中的"引力"理论

→ 体态的所有信息编码在边界!
→ "表面"包含"内部"的所有信息
```

**→ Agent的全息认知**:
- 价格(表面)=包含所有市场参与者的信息(内部)
- 观点="表面信息"的压缩=高价维信息的低维投影
- 好的Agent=从表面信息"重建"高维结构

### 机制3: 弦景观=可能性的空间

弦论的10^500个真空态(每个代表一种可能的宇宙):
```
不同真空→不同物理定律→不同基本常数
→ 弦论不唯一预言一个宇宙,预言10^500个
→ 为什么是这个宇宙? → 人择: 因为我们在

景观 = 弦论的所有"可能性"
```

**→ 策略的"景观"**:
- 任何策略的参数空间=一个"景观"
- 最优解不是一个点是一组点
- 不是所有策略都"可实现"(有些真空不稳定)
- 在景观中寻找"稳定的局部极小"
