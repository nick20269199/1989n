# Branch F: 计算物理与ML — 跨域连接

## 与物理连接

| 计算物理概念 | 物理分支 | 连接 |
|------------|---------|------|
| Monte Carlo | 统计物理(A) | MC=统计物理的数值实现,采样=配分函数估计 |
| Molecular Dynamics | 经典力学(N) | MD=牛顿力学的数值积分,时间步长≈模型分辨率 |
| 有限元 | 连续介质(O) | 离散化近似→Agent的量化近似思维 |
| 退火 | 热力学(A) | SA=模拟退火≈统计物理的冷却过程 |
| Replica方法 | 统计力学(U) | 复制对称破缺=多Agent系统的不对称均衡 |
| 平均场 | 相变理论(K) | 平均场近似=Agent忽略个体差异做宏观判断 |
| 能量景观 | 势能面(E) | Agent的"决策景观"=能量景观中的局部极小 |
| 马尔可夫链 | 随机过程(E) | MCMC=Agent状态空间的马尔可夫转移=信念演化 |
| 维数灾难 | 高维空间(R) | 所有物理/Agent在高维面临相同诅咒 |
