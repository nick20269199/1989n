# Branch F: 计算物理与ML — 合成

## 核心架构

计算物理与ML共享同一核心范式：**把连续物理世界的计算/学习问题转化为离散数值过程**。

### 统一框架
```
物理世界(连续)
  ├─ 微分方程 → 离散化 → 数值求解 (计算物理)
  ├─ 随机过程 → 采样 → 统计估计 (MC/MCMC)
  └─ 物理系统 → 状态 → 动力学 → 预测 (模拟)

学习世界(数据)
  ├─ 训练数据 → 损失函数 → 梯度下降 (ML优化)
  ├─ 先验→数据→后验 → 贝叶斯推断 (概率ML)
  └─ 输入→隐藏层→输出 → 表示学习 (深度学习)
```

**核心洞察**: 两个世界底层共享同一套数学工具(微分/积分/线性代数/概率论/最优化)。

### 三条主线

```
信念采样 ────→ 参数优化 ────→ 模式发现
│                │                │
↓                ↓                ↓
MC/MCMC          SGD/退火         神经网络
(不确定性量化)   (策略/参数调优)   (非线性模式提取)
│                │                │
↓                ↓                ↓
信念的采样近似   最优参数的迭代逼近   从数据中"发现"结构
```

## 关键机制

### 机制1: Monte Carlo = Agent的信念采样引擎

Monte Carlo方法的核心思想: **采样代替积分**。

```
物理版本:
  ⟨A⟩ = ∫ A(x) p(x) dx ≈ (1/N) Σ A(xᵢ)
  → 用N个样本xᵢ(按p分布)估计期望

Agent版本:
  Agent的"信念"=高维概率分布p(x₁, x₂, ..., xₙ)
  → 精确推理(NP难) → 采样推理(可行)
  → MCMC从后验采样 = Agent的逐步信念更新
```

**→ 交易映射**:
- 持仓PnL的分布=用MC模拟(不是单一预测)
- 信念更新=贝叶斯MCMC(新数据→后验)
- 重点: 样本数N决定信念精度,但计算成本O(N)

**MCMC的四种口味**:
| 方法 | 策略 | Agent对应 |
|------|------|----------|
| Metropolis-Hastings | 提议→接受/拒绝 | 假设生成→验证→采纳/丢弃 |
| Gibbs采样 | 逐个维度条件采样 | 拆解复杂问题→各维度逐项判断 |
| HMC(哈密顿MC) | 用梯度引导采样 | 利用梯度信号的高效信念更新 |
| SMC(序贯MC) | 逐步更新粒子 | 流数据下的在线信念更新 |

### 机制2: 模拟退火(SA) = Agent的探索-利用调度

模拟退火: 用温度参数控制从"随机搜索"到"局部精化"的过渡。

```
T → 高(高温): 接受差解概率大 → 探索
T → 低(低温): 只接受好解 → 利用
冷却调度: T(t) = T₀ / log(1+t) (理论最优)

物理: 金属缓慢冷却→能量最小→晶体结构
Agent: 推理温度缓慢降低→全局最优→收敛
```

**→ Agent的探索-利用框架**:
- 初始阶段: 高T→广泛探索(不执着于当前最优)
- 中期: 中T→筛选候选
- 后期: 低T→精化最优解
- 冷却太快→陷入局部最优(过早收敛)
- 冷却太慢→浪费计算(过度探索)

**→ 交易映射**:
- 策略搜索: 初期广泛试因子 → 后期精化参数
- 持仓管理: 入场后"温度"逐渐降低(减少调整频率)
- 市场体制切换: 体制变化→重置温度(重新探索)

### 机制3: 能量景观 = Agent的决策景观

Hopfield网络和许多物理系统的核心: **能量函数定义了一个景观**,动力学沿着景观"下滑"。

```
能量函数 E(state) = 系统状态的"代价"

物理: 系统的自然演化→能量降低→停在局部极小
Agent: "信念"向能量低的吸引子演化→认知稳定

多吸引子=多"认知模式":
- 每种模式=一个局部极小(低能量态)
- 模式切换=越过能量壁垒→外部输入/热噪声驱动
```

**→ Agent的认知模式切换**:
- 每种观点/分析框架 = 一个吸引盆地
- 切换框架 = 越过能量壁垒
- 大能量壁垒 → 固执(需要强证据)
- 小能量壁垒 → 易变(听风就是雨)
- 温度T → 认知灵活性(热→灵活,冷→固执)

**→ 交易映射**:
- 持仓时的"看多"状态=深层吸引子(难翻转)
- 止损=强制越过能量壁垒(从"持有"跳到"空仓")
- 分散持仓→在多个弱吸引子间分布,不是单一深吸引子

### 机制4: 偏差-方差权衡 = Agent的模型选择

统计学习理论的核心: 预测误差 = 偏差² + 方差 + 噪声

```
Err = Bias² + Variance + σ²

简单模型: 高偏差(欠拟合)+低方差 → 稳定但偏离
复杂模型: 低偏差+高方差(过拟合) → 精确但不稳定

物理对应:
- Ising模型: 平均场=高偏差(忽略涨落)但低方差
- 全耦合: 零偏差但高方差(每个自旋都重要)
```

**→ Agent的认知偏差管理**:
| Agent类型 | 偏差 | 方差 | 表现 |
|----------|------|------|------|
| 规则驱动 | 高 | 低 | 按固定规则,稳定但刻板 |
| 全数据驱动 | 低 | 高 | 精确拟合过去,泛化差 |
| 最优 | 中等 | 中等 | 不完美但稳健 |

**→ 物理的"正则化"=认知的"偏见管理"**:
- L2正则化(权重衰减) = 谦逊(不让单一因子权重过大)
- Dropout = 多样性(不同子集独立决策后投票)
- Early stopping = 知止(不过度拟合噪音)

### 机制5: 平均场近似 = Agent的集体化简化

平均场: 用 "平均影响" 替代 "每个个体影响力的精确计算"。

```
物理: 
  精确: H = Σ sᵢsⱼ → O(N²) 对相互作用
  平均场: H ≈ Σ sᵢ⟨sⱼ⟩ → O(N) 每个sᵢ感受平均场
  损失: 忽略涨落/相关性

Agent推理:
  精确: 考虑所有因素的交互效应 → 组合爆炸
  平均场: 假设因素各自独立 → 线性可加 → O(N)
  损失: 忽略交互项→错过协同效应
```

**→ Agent什么时候可以用平均场**:
- 因素间弱相关 → 平均场很好
- 因素间强相关/非线性互动 → 平均场崩了
- 市场常态 → 平均场可用; 危机/剧烈变化 → 崩

**→ 交易映射**:
- 因子组合: 各因子"独立"加权(平均场)vs 因子交互(二阶项)
- 板块独立性: 行业间弱相关→平均场有效; 系统性风险→全体相关→平均场失效
- 市场危机: 相关性→1→平均场崩溃→需要更精确模型

### 机制6: 符号回归 = Agent的可解释性发现

符号回归从数据中自动发现**数学表达式**,不像黑箱NN。

```
数据 (x₁, y₁), (x₂, y₂), ... → 搜索符号空间 → y = f(x)

f的可能形式:
  - 线性: y = ax + b
  - 多项式: y = ax² + bx + c
  - 物理定律: F = G·m₁m₂/r²
  - 交易信号: entry = close > MA(20) AND volume > 1.5×avg

核心: 搜索"符号表达式空间"(不是参数空间)
```

**→ Agent为什么需要符号回归**:
- NN: 高精度,不可解释,不可移植
- 符号回归: 稍低精度,完全可解释,可验证
- 在交易中: 可解释 > 精度(因为需要止损和归因)

**→ 交易映射**:
- 因子=符号表达式(不是NN权重)
- 规则=条件式(if-then-else)
- 模式=数学表达式(技术形态=价格-时间关系式)
