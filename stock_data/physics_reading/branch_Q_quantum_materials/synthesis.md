# Branch Q: 材料科学与量子材料 — 合成

## 核心架构

材料科学=结构-性能关系的科学。量子材料=量子效应决定性能的材料。

### 结构-性能关系
```
原子排列(结构) → 电子结构(中间) → 宏观性能(功能)
    ↓                ↓                ↓
  XRD/电镜        能带计算        导电/磁性/光学
```

### 材料的四个维度
```
1. 组成(元素/比例)
2. 结构(晶体/非晶/缺陷)
3. 加工(热处理/应力/掺杂)
4. 性能(力热电磁光)
```

## 关键机制

### 机制1: 缺陷即功能

完美晶体=平庸。缺陷→独特性能:
```
点缺陷: 掺杂→半导体
线缺陷: 位错→塑性变形
面缺陷: 晶界→强度
体缺陷: 孔洞→轻质

→ 没有缺陷 = 没有功能
→ 关键: 控制缺陷,不是消除缺陷
```

**→ Agent的"缺陷"**:
- 完美推理=僵化=无适应能力
- Agent的"缺陷"(偏差/启发式)=使决策可行的"掺杂"
- 关键是"可控缺陷",不是完美主义

### 机制2: 复合材料=协同

复合材料=两种以上材料的结合,产生各组分没有的性能。
```
组分A: 高强度但脆
组分B: 低强度但韧
复合: 既强又韧(各取所长)

1+1 > 2 的物理实现
```

**→ Agent的多策略**:
- 单一策略有强弱
- 多策略组合=复合材料
- 关键是互补(不是重复)
