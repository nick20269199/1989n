# Branch Y: 实验物理与测量科学 — 合成

## 核心架构

实验物理从"真实世界"获取可靠数据——所有物理理论的最终检验。

### 测量的两难
```
测量=对系统的干预 → 改变被测量 → 不确定性
想要精确 → 需要更多测量 → 更多干预 → 更难精确
```

### 误差的分解
```
总误差² = 系统误差² + 随机误差²

系统误差: 偏向一侧,可纠正但难以检测
随机误差: 正负对称,可平均但不消除
```

## 关键机制

### 机制1: 不确定度传播=Agent的信号质量传递

输入不确定度→传播→输出不确定度:
```
f(x,y) 输入误差: σ_x, σ_y
输出误差²: σ_f² = (∂f/∂x)²σ_x² + (∂f/∂y)²σ_y² + 2(∂f/∂x)(∂f/∂y)σ_xy

→ 每个环节的误差都在放大或缩小
→ 误差传递=Agent的推理链条的"噪声积累"
```

**→ Agent的推理误差管理**:
- 每个判断=一个测量(有不确定度)
- 多个判断合成→误差传递
- 链条太长→末端误差爆炸
- 交易: 简化决策链(减少中间环节)

### 机制2: 信噪比=信号的可检测性

SNR = 信号强度/噪声强度:
```
SNR > 1: 信号可见
SNR < 1: 信号淹没在噪声中
提高SNR: 增加信号功率/降低噪声/多次平均
```

**→ 交易信号检测**:
- 交易信号SNR < 1: 交易即赌博
- 多次确认=信号平均←提高SNR
- 但平均太多次→错过时机
- 黄金平衡: 足够高SNR判断,不要"100%确认"

### 机制3: 贝叶斯在测量=渐进更新

测量不是"一次给出答案",是逐步缩窄不确定性:
```
先验(测量前) → 测量 → 后验(不确定度降低)
重复测量 → 后验越来越窄 → 接近真实值

关键: 每次测量都是信念更新
```

**→ Agent的渐进决策**:
- 不是先"研究透彻"再"执行"
- 先做小仓位→"测量"→更新信念→加大
- 渐进测量=渐进开仓
- 止损=否定测量→更新信念→退出

### 机制4: 可重复性=Agent的规律验证

实验结果必须能重复→才能算"发现":
```
一次成功: 可能是偶然(统计涨落)
多次重复: 确认规律性

p值: 在零假设下,观测到结果的概率
p<0.05: 统计显著(但仍有5%错误可能)
5σ: 物理学的黄金标准(p<3×10⁻⁷)
```

**→ Agent的策略验证**:
- 回测中一次盈利≠策略有效
- 需要: 多周期/多种市场条件的重复验证
- 回测的"p值"=策略盈利是运气还是能力
- 交易中: 重复验证比单次辉煌重要
