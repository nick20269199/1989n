# 侦查评估与集成流程 v1.0

## 全生命周期状态机

```
new → evaluating → approved → integrated → verified
  ↓        ↓          ↓
rejected  deferred  rejected
```

## 评估维度（每项打分 1-5）

| 维度 | 说明 |
|------|------|
| **匹配度** | 对 1989n 当前持仓/策略/Agent 的直接相关性 |
| **成熟度** | 项目/工具维护状态、社区活跃度、文档质量 |
| **集成成本** | 从"看一眼"到"上线跑"的时间：1=几分钟 / 5=数周 |
| **风险** | 许可证问题、弃坑风险、依赖链复杂度 |

## 评估决策矩阵

| 匹配度 | 成熟度 | 决策 |
|--------|--------|------|
| ≥4 | ≥4 | approved → 本周集成 |
| ≥4 | 2-3 | deferred → 标记 watch，月检 |
| 2-3 | ≥4 | approved → 纳入备选池，需要时再集成 |
| ≤2 | any | rejected → 记录拒绝原因，不删 |

## 集成追踪

approved 后写入 `scout_integration_log.json`，记录：
- 集成日期
- 修改了哪个文件/模块
- 验证结果（成功/失败/部分）
- 如果失败：阻塞原因

## 触发时机

- **日评**：每天 16:37，评估昨天及之前的 new 条目
- **周评**：周六 10:37，评估所有 deferred 条目 + 知识保鲜检查
