# 进化阅读 — 物理池 2026-05-12

## 选章：铁律8 — 凡德波尔极限环推理

**来源**: 物理Agent铁律(50本→10大铁律), 基于Strogatz极限环 + Izhikevich发放模式

### 核心洞察

Agent推理不应是线性的(一发即散)，而应在"生成"和"验证"之间形成极限环振荡。关键发现：**二维系统(仅生成+验证)→极限环必然→必须引入第三维("质疑")才能打破循环。**

当前交易信号系统的状态正是一个典型的二维极限环：
- 数据→指标→信号→告警→(循环)
- 买入信号/卖出信号交替振荡
- **没有"质疑"维度**：不问"当前市场体制是什么？下周有什么催化？"

### Agent映射 → 交易决策改进

**问题**: `daily_task.py` 的告警生成是纯机械的(pnl%+持仓天数)，不包含市场体制/催化维度。

**改进方案 — 引入"质疑"维度的三层信号架构**:

```
第一层(生成): 机械信号 → pnl%触发止损/止盈/超时
第二层(验证):  体制检查 → 当前是否处于强催化期？大V共识方向？
第三层(质疑):  冲突仲裁 → 机械信号 vs 体制信号冲突时，进入质疑模式
```

**具体落地**:
1. 在告警生成前插入 `regime_check()` — 读取当日 digest 的 `cycle_stage` 和 `expectation_gaps`
2. 当机械止损信号与体制判断矛盾时(如机械止损-3%但处于"启动→主升过渡"期且Trump访华催化临近)，不执行止损，输出"质疑告警"而非"执行告警"
3. 质疑告警包含：机械信号值 + 体制信号值 + 冲突理由 + 建议等待时间窗口

**失效信号**: 质疑模式导致本该止损的持仓扩大亏损 → 需设定质疑模式的最长等待时间(如48小时)和硬性底线(如-8%无条件执行)。

# 进化阅读 — 物理池 2026-05-18

## 选章：Soros 反身性 — 双向反馈环

**来源**: George Soros, *The Alchemy of Finance* (1987) — 反身性理论核心：市场参与者的偏见影响基本面，基本面变化反过来强化偏见。不存在均衡趋势，只有自我强化的循环。

### 核心洞察

市场有两种运行模式——但当前交易系统只识别了其中一种：

| 模式 | 特征 | 价格与基本面关系 |
|------|------|----------------|
| **均衡趋向** (传统假设) | 均值回归，错误定价被套利消除 | 价格反映基本面 |
| **反身性循环** (Soros) | 自我强化，趋势可以远超合理估值 | 价格改变基本面 |

**关键诊断信号**：当价格趋势开始"自我验证"而非"自我修正"时，均衡框架失效。经典例子——存为王叙事：野村发研报→CSP签3-5年不可取消LTA→HBM产能挤占DDR5→普通存储涨价→长鑫盈利暴涨→更多研报看多。每一轮价格上升都在创造新的基本面证据。

**今日场景的双重反身性**：

1. **存为王** — 科技海啸(口罩哥原话)压过宏观利空。Forward PE 6x提供了安全边际下的反身性做多逻辑
2. **A股独立** — KOSPI-4%熔断但A股仅微跌→"A股独立"叙事形成→资金留在A股→科创50+0.81%走强→叙事自强化。这是情绪面反身性

### Agent映射 → 交易决策改进

**问题**: 当前 `daily_compress.py` 的周期判定(冰点/启动/主升/高潮/衰退/混沌)隐含"单向演进"假设——不包含"反身性自我强化"和"反身性崩塌"两种特殊状态。

**改进方案 — 反身性检测器 `reflexivity_detector()`**:

```
输入: 最近N日价格序列 + 叙事强度(大V共识度/新闻频次) + 基本面验证信号
逻辑:
  1. 价格↑ + 叙事↑ + 基本面验证↑ → 正向反身性(做多持有)
  2. 价格↑ + 叙事↑ + 基本面验证↓ → 叙事领先基本面 → 警惕反身性崩塌
  3. 价格↓ + 叙事↓ + 基本面验证↑ → 反向反身性(超卖机会)
  4. 价格↓ + 叙事↓ + 基本面验证↓ → 负向反身性(做空/回避)
输出: 反身性状态 + 置信度 + 关键监测信号
```

**具体落地到止损逻辑**：

当 `reflexivity_detector()` 输出"正向反身性"时，机械止损阈值应放宽(趋势可远超均值回归假设下的合理价位)：
- 正常模式: -7%硬止损 / -3%软止损
- 正向反身性模式: -12%硬止损 / -5%软止损 (给趋势更大空间)
- 但需绑定验证触发器：每次财报/催化事件后重新评估反身性是否仍成立

**已触发的案例验证(通富微电)**:
- 成本44.85，现价58.07(+29.5%)，远超市值回归框架下的合理目标价
- 但半导体封测+存储叙事→HBM产能溢出效应→通富受益逻辑→仍在自我强化中
- 传统止盈规则(+15%全止盈)已被触发，但在反身性框架下可重新评估

### 失效信号

- 反身性检测的最危险误判：把随机波动+事后归因误认为反身性循环
- 硬约束：反身性模式的放宽止损必须有"基本面验证触发器"绑定——如果连续两个财报/催化事件未验证叙事，强制回归正常止损
- 反身性检测在低流动性/小盘股上高误报率(价格的微小变动就可触发叙事)
- 最大风险：反身性崩塌的速度和幅度远超均值回归(2008/2015/2020三次验证)
