# 读书笔记 — 复杂系统与涌现 (branch_C) 2026-05-27

## 1. Arthur 经济中的复杂性
**递增回报趋势**: 突破+量增+关注同步 → 趋势自维持。上涨(主动买)比下跌(被迫卖)更持久，做多给时间，做空需快。**路径依赖审计**: 连续3月同方法亏损仍用 = 锁定信号，主动切换10%资金试不同方法。

## 2. Sterman 商业动力学
**反馈延迟**: 决策到PnL体现有延迟(短1-3d/中1-3w/长3m)。评估周期<延迟时不可调。做→等完整延迟→看→改。**领先指标**代替滞后PnL。

## 3. Meadows 系统思考
**杠杆点优先级**: 最强=认知(目标/假设/偏好)，最弱=参数。反复优化参数无改善 → 上升改规则/结构。**小改变引发大变化**=高杠杆点，记录。

## 4. Johnson 涌现
**自下而上秩序**: 局部简单规则→全局复杂行为。趋势是成千上万独立决策的涌现，不是主力画线。**价格突破+量增=涌现信号**。

## 5. Page 多样性与复杂性
**群体多样性>个体能力**: 多样策略组合稳定。单一策略在多变市场中脆弱。**多策略并行=涌现稳健性**。
