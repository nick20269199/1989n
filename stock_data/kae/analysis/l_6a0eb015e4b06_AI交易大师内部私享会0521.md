### **2. 关键观点（5–8个最具实操价值的知识点）**

| 序号 | 观点 | 解释 |
|--------|------|------|
| **① 五阶段是结构性行情中的结构性行情，难度远超一/三阶段** | “五阶段”指主升浪尾声阶段，市场从普涨转向极致分化，仅少数核心标的抗跌甚至逆势走强。此时选股能力、审美能力、节奏感成为胜负手，而非单纯看板块。课程以机器人板块中“尚伟新财破新高 vs 三花智控稳健扛跌”的对比，说明：**不是选最强的票，而是选最符合当前资金审美+产业逻辑+流动性安全边际的票**。 |
| **② 六层仓位是敬畏市场的底线纪律，非建议而是铁律** | 在五阶段，必须将总仓位控制在60%以内（即“六层仓位”）。这不是风控建议，而是对市场不确定性的**行为化敬畏**——因为“你不知道下一根是不是大阴线”，满仓=放弃容错权。课程反复强调：“今天没受伤，是因为你守住了六层；若满仓，已重伤。” |
| **③ 卖点必须是预设、唯一、可触发的客观标准，拒绝马后炮式修正** | 卖点不是盘中感觉，而是在买入那一刻就确定的**机械触发条件**。讲师明确给出三类客观卖点：<br>• 指数出现**爆量阴线**（当日确认）；<br>• 指数出现**3.6万亿以上爆量阳线**（极端反抽需离场）；<br>• **“则实系统”软件显示“空”信号**（需在14:57后查看，盘中信号无效）。<br>强调：“你定哪条都行，但必须统一执行，不可临时加戏。” |
| **④ 退潮期才是检验交易员成色的试金石** | 行情好时“人人股神”，退潮时才能暴露真实水平：是否坚守计划？能否拒绝抄底诱惑？是否分清“扛跌”与“真强”？课程用“照义创新+三花智控今日微涨”案例说明：**真正的强不是涨得多，而是在指数暴跌中相对抗跌、资金承接强、逻辑未证伪**。 |
| **⑤ 方向选择＞个股选择，补涨逻辑需匹配行情阶段** | 当AI硬科技主升结束，资金必然寻找“逃生通道”。课程指出机器人是当时**唯一具备承接力的补涨方向**（因产业逻辑清晰、资金共识强、无明显利空），并提示：补涨≠追高，而是“在调整中低吸核心”，如三花在机器人板块调整时买入，次日即启动。 |
| **⑥ “错杀”有迹可循，但需严格区分持续性与纯情绪博弈** | 课程预判三大可能错杀方向：<br>• **机器人**（资金主动回流，具中期持续性）；<br>• **玻璃基板（京东方A）**（纯消息刺激+超短博弈，需次日强修复验证）；<br>• **其他超短题材**（如“报复”“太阳眼镜”等梗代指的短线情绪标）。<br>关键区别：**机器人是资金主动选择的“避风港”，玻璃基板是被动错杀的“情绪宣泄口”**。 |
| **⑦ 交易模式必须自洽，不可混用多套标准** | 批判典型错误：“既想按软件空信号走，又因爆量阴线提前跑；既信自己选股，又怪老师没点名”。强调：**你的模式=你定义的买点+你定义的卖点+你定义的仓位，三者必须闭环**。混用标准=自我欺骗。 |
| **⑧ 落实震荡行情的生存法则：空仓优先，个股模式须严守两层仓位** | 明确宣告：“主升浪结束，进入落实震荡”。此阶段：<br>• 空仓者最优；<br>• 必须操作者，**个股模式仓位≤20%（两层）**，且接受“小赚即走、小亏认赔”；<br>• 拒绝“赌徒模式”（满仓博弈反弹），因其本质是放弃概率思维。 |
