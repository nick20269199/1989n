## 三、核心发现

### 定量分析的3个硬伤

1. **描述≠内容**: 抖音视频描述是标题/hashtag，不是正文。真正的分析内容在视频里，但597个视频无一有转录文本。这是最大的数据盲区。

2. **牛熊偏差**: 情绪数据覆盖期(2026-03~05)市场整体偏强：STRONG日占26%，WEAK占24%，其余为NORMAL。在偏强市场中，日均发帖的账号自动获得高"预测密度"分。

3. **窗口不均**: 口罩哥仅收集到11天(60条)，好运佛系跨度1574天(仅21天有发帖)，Trader韭619天。数据窗口差异使定量对比不可靠。

### 各账号定性判断（比定量更可靠）

| 账号 | 定性判断 | 理由 |
|------|---------|------|
| **口罩哥** | **行家-跟** | 研报风格/信息密度/零水分，定量低估 |
| **Trader韭** | **行家-跟** | 跨资产/盘中发帖/有实质内容，宏观框架 |
| **小司频道** | **行家-宏观参考** | 专业财经媒体，不指导买卖 |
| **好运佛系** | **专项-仅CPO** | 极端聚焦CPO赛道 |
| **周期女王** | **行家-方法论** | 输出极少但聚焦交易系统 |
| **胡大毛** | **行家-A股实战** | 低频但专注A股交易心得 |
| **凯心** | **中等-过滤噪音** | 内容有教育价值但标题党包装 |
| **子辉先生** | **水货-不跟** | 体育+科技+股票混搭，泛流量 |
| **太阳李博良** | **水货-不跟** | 非财经号，自我成长类 |
| **创业魔法师** | **假货-不跟** | 169万粉丝/95%空描述，纯流量号 |

## 四、五轮进化总结

R1→R2: 发现"描述太短"这个根本限制，话题提取命中率<5%

R2→R3: 从"说什么"转向"怎么做"——发布行为模式比话题更可靠

R3→R4: 引入市场相位，发现逆向信号极少(多数大V不表达明确多空)

R4→R5: 认识到纯定量模型在数据质量差时不可靠，必须定性修正

**最重要的进步**: 从R1的"预测密度=79.5%所以口罩哥最好"这种容易被牛市偏差误导的结论，进化到R5的"口罩哥描述短但研报风格+信息密度高，数据窗口短导致定量低估，定性上调"的综合判断。

## 五、下一步建议

1. **转录是刚需**: 597个视频需要批量转录(whisper)，有了文本才能做真正的B/S点分析
2. **拉长市场数据**: 需要2024-2026全量日频数据(大盘涨跌/板块轮动/资金流向)，覆盖好运佛系/周期女王的全部发帖期
3. **增加验证维度**: 对"喊单"视频追踪后续7日/30日表现，构建真实的"喊单胜率"指标
4. **日内对齐**: 如果视频时间戳精确到分钟，可以对齐intel_report的30min快照做更精细的日内预测评估
