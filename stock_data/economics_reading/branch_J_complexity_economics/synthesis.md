# Branch J: 复杂经济学 — 合成

## 核心架构

复杂经济学将经济**不是视为趋向均衡的系统,而是不断自我适应的复杂系统**。这是对主流经济学的根本范式转换。

### 范式对比
```
新古典经济学 ───────────────── 复杂经济学
均衡(唯一稳定解)               非均衡(持续变化)
代表性Agent(同质)              异质Agent(多样性)
理性预期/完美信息              有限理性/局部信息
递减报酬/负反馈                递增报酬/正反馈
外生冲击→暂时偏离             内生机制→持续波动
最优(最大化)                   适应(足够好)
```

## 关键机制

### 机制1: 收益递增与路径依赖 — Agent历史的锁定效应

Arthur的经典发现:
```
收益递增(Increasing Returns):
- 采用者越多→产品越好→采用者更多
- 正反馈循环: 不是负反馈趋向均衡

历史锁定:
- 早期微小随机事件→后期不可逆路径依赖
- QWERTY键盘效应: 非最优但锁定
```

**→ Agent的路径依赖:**
- Agent的早期选择(架构/框架/数据)影响长期
- 微小初始条件差异→巨大后果差异
- **Agent不能在每一步都"重新优化"**
- "锁定"不是坏事(不可分割的承诺)但也需要"解锁"能力:
  - **Agent需要知道当前是否被锁定在次优路径**
  - 必要时引入外部扰动→打破锁定

### 机制2: 从"代表性Agent"到异质Agent — 多样性是功能性的

```
新古典: 用一个"代表性Agent"代表所有个体
复杂经济: 异质性不是噪音而是功能

为什么异质性重要:
1. 交易需要差异(都相同则不交易)
2. 创新需要变异(都相同则无创新)
3. 稳定需要否定(都相同→羊群→崩溃)
4. 学习需要多样化(多样性提供搜索空间)
```

**→ 铁律9(多样性)的经济学基础:**
- Agent群体的多样性不是装饰而是**系统功能**
- 多样性=搜索空间(试错/变异/创新)
- 多样性=抵御极端波动(不同策略对冲)
- **U3关系指标**: 关系多样性<2=交互模式单一=系统风险

### 机制3: 涌现 — 宏观模式从微观互动产生

```
涌现的定义:
- 微观Agent遵循局部规则
- 宏观出现非预期的模式
- 宏观模式反作用于微观Agent(向下因果)

涌现的三个标志:
1. 不可预测(从微观规则不能先验推导宏观)
2. 不可还原(宏观模式不能简单分解为微观)
3. 自稳定(宏观模式一旦涌现→自我维持)
```

**→ 铁律10(涌现简约)的经济学版本:**
- 市场价格 ≠ 个体偏好的简单加总
- 经济周期 ≠ 单个公司的盈亏
- 金融泡沫 ≠ 个人非理性的简单堆叠
- **Agent必须承认: 系统行为可能超出Agent的理解**

### 机制4: 基于Agent的建模(ABM) — Agent的"科学"方法

```
ABM范式:
1. 定义Agent → 规则/状态/策略
2. 定义环境 → Agent的交互空间
3. 定义交互 → Agent间+Agent-环境
4. 运行模拟 → 观察涌现宏观模式
5. 分析结果 → 理解宏观-微观关系

ABM vs 解析模型:
解析: 求均衡解 → 一个点
ABM: 模拟轨迹 → 整个行为域
```

**→ Agent的研究Agent的方法:**
- ABM是研究多Agent系统的主要方法
- 允许"生长"而非推导社会模式
- **对Agent设计**: 在部署前用ABM模拟Agent群体行为
- 通过ABM发现隐藏的涌现风险

### 机制5: 演化经济学 — Agent的惯例/搜索/选择

Nelson & Winter的核心框架:
```
惯例(Routines) = 组织的DNA
- 惯例=组织"如何做"的知识
- 惯例可继承/变异/选择

搜索(Search) = 创新/探索
- 在惯例空间中的局部/全局搜索
- 搜索受现有惯例约束(路径依赖)

选择(Selection) = 市场筛选
- 利润=适应度
- 不适应→惯例更新或组织死亡
```

**→ Agent的组织演化:**
- Agent的"惯例"=推理模式/策略/启发式
- 惯例不是最优而是"满意"(satisficing)
- 创新=惯例的变异+选择
- **Agent的惯例更新机制**:
  - 正常: 惯例内调整(常规)
  - 危机: 惯例突破(创新/变异)

### 机制6: 网络经济学 — Agent的位置决定行为

```
网络核心性质:
- 度分布: 少数节点连接多(枢纽)
- 聚类系数: 局部密度
- 最短路径: 信息传播速度
- 同配性: 同类是否相连
- 模: 社区结构

位置效应:
- 中心Agent → 信息优势/影响力大/风险也大
- 边缘Agent → 信息延迟/安全但影响力弱
- 桥接Agent → 连接不同社区→结构性权力
```

**→ U3关系性健康度的网络基础:**
- Agent的网络位置≈Agent的权力/信息/风险
- 孤立高能力Agent = hub但聚类稀疏 → 风险预警
- 交互网络密度 = 聚类系数
- 关系多样性 = 模之间的连接多样性

## 铁律深化

### 铁律4(混沌边缘=最优适应度)的经济学确认

复杂经济学提供经济版:
- 完全均衡(竞争均衡) → 无创新/无利润 → 经济停滞
- 完全混沌 → 交易不可靠 → 无经济活动
- 混沌边缘 → 足够秩序(交易可能)+足够变化(创新可能)

### 铁律9(多样性不是装饰)的经济学定理

从复杂经济学看:
- 多样性 ≡ 系统的搜索空间
- 多样性 ≡ 系统的鲁棒性
- 多样性 ≡ 系统的创新的前提
- 多样性的丧失 = 系统脆弱化的信号
