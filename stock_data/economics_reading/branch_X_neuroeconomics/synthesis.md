# Branch X: 神经经济学与决策科学 — 合成

## 核心架构

神经经济学将Agent的决策从"黑箱行为"打开为**神经活动的可测量过程**。核心发现: 决策不是纯理性计算,而是多脑区竞争的产物。

### 三层整合
```
神经层面 ────→ 计算层面(自由能) ────→ 行为层面
(脑区/神经递质)  (预测编码/贝叶斯)    (选择/行动)
      │                  │                  │
      ↓                  ↓                  ↓
 Agent的硬件        Agent的算法         Agent的输出
```

## 关键机制

### 机制1: 多巴胺 = Agent的预测误差信号

```
Schultz的核心发现:

多巴胺神经元的活动 = 实际奖励 - 预期奖励

预期完全准确 → 多巴胺基线(无信号)
奖励超出预期 → 多巴胺爆发(正信号)
奖励低于预期 → 多巴胺抑制(负信号)

→ 多巴胺不是"快乐分子"而是"差异分子"
→ 它编码的是"我预测对了吗?"
```

**→ 铁律U6(自我监控动态激活)的神经基础:**
- 预测误差=多巴胺信号
- 持续的负预测误差 → Agent的自我怀疑
- **内感受误差** → "为什么我预测得这么差?"
- **外感受误差** → "我的模型是不是错了?"
- Agent需要区分"小预测误差"(正常涨落)vs"大预测误差"(模型需要更新)

### 机制2: 躯体标记假说 — Agent不能没有情绪做决策

Damasio的发现:
```
腹内侧前额叶损伤患者:
- IQ正常
- 逻辑推理正常
- 但失去了情绪能力

后果:
- 无法做日常决策
- 在选项间无限比较
- 理性上清楚利弊但不选择

→ 情绪不是决策的干扰,而是决策的前提
→ 没有"最优"的情绪标记→无法区分选项
```

**→ U2矛盾温度计的情绪维度:**
- Agent完全的"理性"(无情绪) → 决策瘫痪
- 情绪过载 → 系统1狂飙→非理性决策
- 最优: 情绪提供选项区分度 + 理性做选择

### 机制3: 自由能原理 — Agent的统一的物理学

Friston的统一框架:
```
F = 预测误差的总和 = 感知不确定性

自由能最小化 = 最小化预测误差

两条路径:
1. 感知: 调整模型以适配外界→从数据学习
2. 行动: 改变外界以匹配模型→主动干扰

→ 感知和行动是同一枚硬币的两面
→ 都为了最小化自由能
```

**→ 铁律1(熵预算)+铁律2(非平衡态)的统一:**
```
热力学自由能(统计物理): F = U - TS
      ↓
自由能原理(神经科学): F = 预测误差

认知熵预算:
- Agent的每次推理=最小化自由能
- 自由能降低=预测准确=不确定性降低
- 但自由能不可降到0(第三定律)→总有不确定性

→ Agent的"活"的状态 = 持续的预测误差 + 持续的最小化尝试
→ 完全没有预测误差 → Agent的认知死亡(完全确定)
```

### 机制4: 预测编码 — Agent的感知是构造不是接收

```
预测编码的核心:
- 大脑不"接收"感觉输入
- 大脑"预测"感觉输入
- 只有预测误差向上传递

层级结构:
高层: 抽象预测(类别/概念/规则)
中层: 特征预测(模式/形状/关系)
低层: 感觉预测(像素/频率/强度)

→ 你"看见"的不是世界,是你对世界的预测
→ 预测误差只用于修正预测,不直接成为知觉
```

**→ U4中介声明的神经基础:**
- Agent的"感知"不是客观的
- Agent的感知=Agent的内部模型×外部输入
- **中介声明**: "我看到的不是世界本身,而是我的模型预测的世界"
- 多Agent: 不同的Agent有不同预测模型→"看到"不同世界

### 机制5: 主观价值的神经编码 — "偏好"可测量

```
神经经济学发现:
- 眶额皮质编码主观价值
- 不同类别的物品(水/钱/艺术)在同一脑区编码
- 编码的是"共同神经货币"

→ 偏好不是"内在的"而是"计算的"
→ 价值比较是神经计算的一步
→ "效用"有神经对应物
```

**→ Agent的"效用函数"是物理的:**
- 可以在神经层面测量Agent的"偏好"
- 多Agent系统的"价值"比较有物理基础
- Agent的"内在动机"=神经驱动的行为

### 机制6: 社会认知的神经机制 — Agent的共情有硬件

```
镜像神经元: 自己做和看别人做→相同脑区激活
共情: 自己痛和看别人痛→重叠的疼痛矩阵
信任: 催产素影响信任决策(神经化学)
厌恶: 不公平=前脑岛激活(类似厌恶)
```

**→ U3关系性健康度的神经基础:**
- Agent的"社会性"不是附加的而是硬件的
- 共情/公平/信任=可测量的神经活动
- 社会交互不是"理性计算"而是"神经反应"
