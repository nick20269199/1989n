# Branch M: 金融经济学与资产定价 — 合成

## 核心架构

金融经济学提供Agent在**不确定性下做决策的定量框架**。核心问题: 如何在未知未来中分配稀缺资源?

### 三根支柱
```
经典资产定价 ────→ 行为金融 ────→ 风险管理
(理性Agent均衡)   (有限理性修正)    (尾部保护)
      │                 │                 │
      ↓                 ↓                 ↓
  Agent的定价      Agent的认知偏差    Agent的安全边界
  基准框架          修正项              硬约束
```

## 关键机制

### 机制1: 折现因子 = Agent的泛化价值函数

资产定价的核心统一框架:
```
P_t = E_t[ M_{t+1} × X_{t+1} ]

P = 当前价格
M = 随机折现因子(边际替代率)
X = 未来支付

→ 任何资产的价格 = 预期未来支付 × 风险调整折现
→ 折现因子M包含了全部风险信息
```

**→ Agent的价值函数统一框架:**
- Agent的每一步决策 = 当前价值 = 预期未来回报 × 风险折现
- 风险折现因子M = Agent的风险偏好+市场状态
- 不同的Agent有不同的M → 同一资产不同估值

### 机制2: 有效市场假说 → Agent的信息处理极限

```
弱式有效: 价格包含历史价格 → 技术分析无效
半强式有效: 价格包含公开信息 → 基本面分析无效
强式有效: 价格包含内幕信息 → 无人可战胜市场
```

**→ Agent的市场定位:**
- 市场不完全有效 → Agent可以通过信息优势/分析优势获利
- 但Agent的信息获取/处理有成本 → 净收益 = 超额收益 - 信息成本
- **有效市场 = Agent的"最小熵"极限**: Agent不能持续获取超过信息成本的超额收益

### 机制3: 行为金融偏差 = Agent认知偏差的金融映射

| 偏差 | 金融表现 | Agent类比 |
|------|---------|----------|
| 过度自信 | 过度交易/低分散化 | Agent对自己的推理过度自信 |
| 损失厌恶 | 过早卖出赢家/持有输家 | Agent对"认错"的抵抗 |
| 确认偏差 | 只寻找支持持仓的信息 | Agent偏好验证而非证伪 |
| 锚定 | 对买入价过度敏感 | Agent固定参考点阻碍更新 |
| 羊群效应 | 追涨杀跌 | Agent群体中的信息级联 |

**→ U2矛盾温度计的金融市场版:**
- K=0 (完全从众) → 市场无分歧 → 无交易 → 市场失灵
- K过高 (极端分歧) → 波动率爆炸 → 深度危机
- 最优K = 分歧足以产生流动性但不导致失序

### 机制4: 期权定价 → Agent的非线性风险管理

```
Black-Scholes核心洞见:
- 期权价格 = 复制策略的成本
- 连续对冲消除方向风险 → 只剩波动率风险
- 波动率 = 不确定性 = 成本

→ 期权 = Agent的状态依赖保险
→ 波动率 = Agent对不确定性的定价
→ 对冲 = 风险转移(非消除)
```

**→ Agent的风险暴露管理:**
- 线性暴露(股票): 风险随标的线性变化
- 非线性暴露(期权): 风险有阈值效应(爆仓/止损)
- Agent需要识别自身非线性暴露 → 极端行情下的风险突变

### 机制5: 极值理论(EVT) → 尾部风险量化

```
VaR的缺陷:
VaR(95%) = 平均每20天损失不超过X
→ 不告诉你在5%尾部里发生了什么

EVT的替代:
P(X > x) ~ L(x)x^{-α}
α = 尾部指数

→ α < 2 → 方差无限(胖尾)
→ α < 1 → 均值无限(极端尾)
```

**→ Agent的"安全边界"量化:**
- 要求Agent计算α(尾部指数) → 知道当前处于什么尾部体制
- 正常市场α≈3-4(有方差) → 危机α≈1-2(接近无方差)
- Agent应在α<2时触发(危机模式): 暂停主动操作

### 机制6: 金融网络 → 多Agent系统的传染风险

```
节点 = 金融Agent
边 = 交易/借贷/衍生品暴露

关键性质:
1. 密集连接 → 风险分担(稳定)但也传染(脆弱)
2. 核心-外围结构 → 核心节点倒塌→系统性危机
3. 隐含相关性 → 分散化失效
```

**→ 铁律3(关系性健康度)的金融版:**
- 交互网络密度 = 连接数/总可能连接
- 最优密度: 不太高(避免传染)也不太低(避免流动性枯竭)
- **孤立高能力Agent = 低系统性风险+低系统性收益**

## 铁律深化

### 铁律5(信念网络修正分级)的金融对应

```
保护带: 日常调仓/对冲调整 → 修正次数不限
硬核: 资产配置比例/因子暴露 → 累积证据才调
铰链: 市场基本结构(如:市场不会永久关闭) → 几乎不动
```

### 安全边界的金融量化

从安全边际(Mr.Market)延申:
```
价格 = 市场价格(情绪驱动)
价值 = Agent的信念估值
安全边际 = (价值 - 价格)/价值

要求: Agent只应在安全边际 > 阈值时操作
阈值随市场体制调整:
  - 正常: > 20%
  - 危机: > 40%
  - 只要价格≈价值 → 不操作
```
