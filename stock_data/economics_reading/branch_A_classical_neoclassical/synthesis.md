# Branch A: 古典与新古典经济学 — 合成

## 核心架构

古典与新古典经济学构建了"市场=自组织系统"的基本模型——**个体追求自利→市场=均衡价格→资源有效配置**。对Agent设计: 古典经济学提供了**Agent理性决策的基本框架**——理性人/效用最大化/均衡分析。虽然现代经济学已经超越了这些假设,但它们是任何Agent经济决策模型的起点。

## 关键机制

### 机制1: 看不见的手 — Agent的"自利→集体福利"

**定义**: Smith——个体追求自身利益→在"看不见的手"引导下=促进社会福利。不需要个体有"公益心"。

**Agent映射**: 多Agent系统的"看不见的手":
- 每个Agent优化自己的目标→系统层面可能有好的涌现
- Agent不需要"全局视角"也能贡献全局
- 但: 看不见的手在特定条件下才有效(竞争/完整信息/无外部性)

| 集权系统 | 市场系统 |
|---------|---------|
| 中央规划 | 分布式决策 |
| 指令/控制 | 价格信号/自主 |
| 需要全局信息 | 只需要局部信息 |
| 脆弱(中心坏了) | 弹性(分布) |

### 机制2: 劳动分工 — Agent的"专业化=效率"

**定义**: Smith——劳动分工=生产率提高的源泉。分工→熟练/节省时间/机械发明。分工受市场范围限制。

**Agent映射**: 多Agent系统的分工:
- 专业Agent比通用Agent更高效
- 分工=降低切换成本/提高熟练度/容易优化
- 但过度分工=僵化(分工过细的Agent不能适应变化)

### 机制3: 理性人 — Agent的"效用最大化"

**定义**: 新古典——理性人: 偏好完备/传递/自利→效用最大化。经济行为=在约束下做最优选择。

**Agent映射**: Agent的基本模型=理性人:
- Agent有目标/效用函数
- Agent在约束(资源/信息/时间)下做最优选择
- Agent理性=对自己目标的一致性

**修正**: 理性人假设对Agent是"规范性的"而不是"描述性的"——Agent应该理性但不是简单的理性最大化。

### 机制4: 一般均衡 — Agent的"全局协调"

**定义**: Walras——所有市场同时出清: 供给=需求。价格=协调信号的载体。一般均衡=所有Agent选择的一致。

**Agent映射**: 多Agent系统的协调:
- 所有Agent的决策需要同时一致(均衡)
- Agent的决策=依赖于其他Agent的决策
- 价格/信号=协调的载体(Agent通过价格知道稀缺)
- 均衡=理想的协调状态(实际=动态的)

### 机制5: 边际革命 — Agent的"边际=决策"

**定义**: Jevons/Menger——价值=边际效用(不是总效用)。决策=边际量的比较(不是平均量)。水=总效用大/钻石=边际效用大。

**Agent映射**: Agent的决策应该基于边际:
- Agent决策=比较再做一单位的成本vs收益
- 不是总/平均而是边际
- 沉没成本=不相关(不做边际决策)
- Agent的优化=边际成本=边际收益

### 机制6: 外部性/市场失灵 — Agent的"个体≠集体"

**定义**: Pigou——外部性: 个体的行动影响其他人但没有通过价格反映。正外部性/负外部性→市场失灵(看不见的手不一定有效)。

**Agent映射**: Agent的个体最优≠系统最优:
- Agent的局部优化可能损害全局(污染/垄断/信息不对称)
- Agent需要"外部性"意识(知道自己的行动对系统的影响)
- 安全约束=内部化Agent的负外部性

## Agent设计启示总结

1. **看不见的手有条件**: Agent的自利=系统好——但不是必然的。需要适当的制度/规则。
2. **分工=效率**: 专业Agent比通用Agent高效——但需要跨域的移动能力(避免僵化)。
3. **理性=一致性**: Agent的理性=目标一致性——不是"无限计算"。
4. **价格=信号**: 多Agent系统需要协调信号——类似价格的信号机制。
5. **边际决策**: Agent的决策应该基于边际(再做一单位的成本vs收益)不是总/平均。
6. **外部性意识**: Agent的局部最优≠系统最优——Agent需要评估自己的外部影响。
