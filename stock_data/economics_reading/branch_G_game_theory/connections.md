# Branch G: 博弈论与信息经济学 — 跨域连接

## 与物理

| 博弈论 | 物理 | 连接 |
|--------|------|------|
| 纳什均衡 | 统计力学平衡态 | 均衡=系统在约束下的最概然状态,对应统计物理的系综理论 |
| 演化博弈(复制者动态) | 非平衡/相变 | 策略的演化=非线性动力学的复制者方程,不动点/分岔分析 |
| 博弈的势函数 | 自由能/势 | 潜博弈(Potential Game)=势函数驱动,与自由能最小化同构 |
| 合作涌现 | 统计物理的相变 | 从背叛到合作的转变=二级相变,临界条件可计算 |
| 信号的代价 | 能量消耗 | 昂贵的信号=信息的能量代价,与Landauer原理对应 |

## 与哲学

| 博弈论 | 哲学 | 连接 |
|--------|------|------|
| 囚徒困境 | 社会契约(霍布斯) | 个人理性→集体非理性=霍布斯的自然状态需要利维坦 |
| 博弈规则 | 正义的规则(罗尔斯) | 无知之幕=选择规则时的原初位置,独立于具体博弈 |
| 共同知识 | 知识的界限(Kripke) | 我知道你知道我知道...的无穷递归=共同知识的认识论分析 |
| 均衡选择 | 约定/规范(Hume/Lewis) | 多个均衡时的协调=社会约定的形成 |
| 演化稳定策略 | 美德伦理学 | ESS=稳定的行为模式,类似Aristotle的习惯美德 |
