# Branch G: 博弈论与信息经济学 — 合成

## 核心架构

博弈论提供了**多Agent互动的数学框架**：

### 多Agent博弈的四要素
```
1. 玩家(Agent集合) → 谁在互动
2. 策略(每个Agent的行动集) → 能做什么
3. 收益(每种行动组合的结果) → 偏好什么
4. 信息(谁知道什么) → 知识结构

博弈论的Agent假设:
- 理性: 最大化自己的收益(自利)
- 共同知识: 大家都理性+大家都知道大家都理性+...
- 策略: 预期到别人的预期
```

## 关键机制

### 机制1: 囚徒困境 — 个体理性→集体非理性
```
               合作        背叛
   合作    (3,3)        (0,5)
   背叛    (5,0)        (1,1)

纳什均衡: (背叛,背叛) → 互相背叛
帕累托最优: (合作,合作) → 更好但非均衡
个体理性 → 集体非理性 → 自由市场经济需要制度
```

**→ 多Agent的根本问题**: 个体最优≠系统最优
**→ 需要制度层**: 信任/协议/约束/激励结构

### 机制2: Axelrod合作的演化 — 如何走出囚徒困境
```
锦标赛结果: Tit-for-Tat(以牙还牙)胜出
TFT规则:
1. 首轮合作 → 先释出善意
2. 此后模仿对方上一轮 → 不记仇不占便宜
3. TFT特质: 善良/报复/宽容/清晰

长期互动改变博弈:
- 无限重复博弈 → 合作是均衡(Folk定理)
- 未来价值足够高(贴现因子大) → 合作
- 合作不是道德是策略 → 聪明的自私
```

**→ 多Agent的合作**: 不需要利他主义,只需要长期互动+对未来价值的关注
**→ Agent的合作策略**: 先合作→对方背叛→报复→对方合作→原谅

### 机制3: 信号博弈 — Agent的不对称信息
```
Spence经典: 劳动力市场信号
- 工人知道自己的能力(私人信息)
- 雇主不知道
- 教育作为信号: 高能力者低成本获取学位
- 分离均衡: 高能力受教育,低能力不受

信号的条件:
- 有成本(否则无信息)
- 不同Agent成本不同(否则信号无意义)
- 成本与不可观察质量负相关
```

**→ Agent的沟通**: 话是便宜的(cheap talk),行为是贵的(信号)
**→ 可信承诺 = 高成本信号**

### 机制4: 信息不对称 — 逆向选择与道德风险
```
逆向选择(Akerlof柠檬市场):
- 二手车市场: 卖者知道质量买者不知道
- 质量好的不愿意卖 → 市场出清的是劣质
- → 市场可能崩溃

道德风险:
- 委托人不观察代理人的努力
- 代理人可能偷懒(反正委托人不知道)
- 需要"激励相容"的设计
```

**→ Agent系统设计**: 必须考虑信息不对称
**→ 设计者不知道Agent的真实状态 → 激励相容约束**

### 机制5: 机制设计 — 让Agent说实话
```
Myerson的显示原理:
任何机制都可以转化为直接显示机制
→ Agent报告类型→按报告分配
→ 关键: 激励相容(说实话是最好策略)

VCG机制(Vickrey-Clarke-Groves):
每个Agent支付 = 他给其他人带来的外部性
→ 说实话该Agent的估价是真话的占优策略
```

**→ Agent的信息报告**: 设计机制使说实话=最优
**→ 不信任Agent的自我报告 → 需要验证机制**

### 机制6: 演化博弈 — 策略的适应性演化
```
Maynard Smith的演化稳定策略(ESS):
如果群体都采用ESS → 罕见突变不能侵入

鹰鸽博弈:
- 鹰(战斗到死) vs 鸽(展示但不打)
- ESS = 混合策略
- 稳态的"冲突水平"由收益矩阵决定

复制者动力学:
ẋ = x(f_x - f̄)
收益高的策略 → 在群体中扩散(自然选择)
```

**→ Agent的策略库**: 不是理性选择,是适应性演化的
**→ 多Agent系统的最佳策略=在给定环境中的ESS**

### 机制7: 协调博弈 — 不需要强制的一致
```
两个司机: 靠左靠右?
选择A(左,左)和(右,右)都是均衡
但不知道对方的选择→协调问题

解决方式:
- 焦点(Schelling): 某个突出的策略("纽约中央车站")
- 先发优势: 先动者设定规范
- 文化/历史: 已有的惯例
```

**→ 多Agent的协调**: 需要显著的"焦点"或起始约定
**→ 不需要显式协议**: 突出点自然成协调工具**
