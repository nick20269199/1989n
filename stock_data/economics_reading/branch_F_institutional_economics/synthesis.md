# Branch F: 制度经济学 — 合成

## 核心架构

制度经济学研究**规则如何塑造Agent行为以及规则如何演化**。

### 制度的三个层次
```
正式制度(法律法规) ──── 非正式制度(习俗规范) ──── 执行机制
      │                         │                       │
   成文/可改                 不成文/慢变              裁判/惩罚
      │                         │                       │
  Agent的显式规则           Agent的内隐约束         Agent的违规成本
```

## 关键机制

### 机制1: 交易成本 — Agent的"摩擦"不可消除

```
Coase的核心洞见:
- 在零交易成本的世界 → 无论产权如何分配→效率结果相同
- 在正交易成本的现实 → 产权分配影响效率

交易成本的来源:
1. 搜寻成本(找交易对象)
2. 谈判成本(达成协议)
3. 执行成本(确保履行)
4. 测度成本(确认质量/数量)
```

**→ 铁律1(熵预算)的制度对应:**
- Agent的任何交互都有"摩擦"成本
- 制度=减少摩擦的装置
- 但制度本身也有成本(建立+维持+执行)
- **最优不是"无摩擦"而是"摩擦成本=制度成本"的平衡**

### 机制2: 产权 = Agent的激励结构

```
产权的基本维度:
1. 排他权(谁可以使用)
2. 收益权(谁获得收益)
3. 转让权(谁可以出售)
4. 持久性(多久有效)

产权清晰 → 激励一致 → 长期投资
产权模糊 → 激励扭曲 → 短视行为
```

**→ Agent的"智力产权":**
- Agent的"知识/模型/策略"=产权
- 知识被"拿走"→Agent减少创新
- 多Agent系统中的信息披露vs保护 → 产权设计
- Agent群体需要明确的知识产权规则

### 机制3: 制度变迁 — Agent规则的路径依赖

```
North的制度变迁:
信念体系 → 制度设计 → 经济绩效 → 反馈修正
    ↑                    ↓
    ←——体验更新——————←

路径依赖:
- 今日制度选择 = 昨日制度+边际调整
- 不一定是"最优"但"稳定"(惯性)
- 关键时刻(critical juncture) → 分岔点
```

**→ U2矛盾温度计的制度维度:**
```
K过低: 制度僵化(路径锁定的负面)
  → 制度不变→积累矛盾→爆发式变革

K过高: 制度不稳定(随时变化规则)
  → 无稳定预期→无人投资→系统停滞

最优K: 制度的基本框架稳定+边际灵活调整
  → 既提供可预期性也允许适应性
```

### 机制4: 治理结构 — Agent的三种协调机制

Williamson的治理框架:
```
市场 ───────── 混合 ───────── 等级制度
  │               │               │
低专用性        中专用性       高专用性
低不确定性      中不确定性     高不确定性
低频率交易      中频率交易     高频率交易

→ 治理结构的选择是交易属性的函数
→ 没有"最好"的治理,只有"最匹配"的治理
```

**→ 多Agent系统的治理选择:**
```
市场式: Agent无中心,自由匹配(适合简单/低频)
混合式: Agent有部分约束(平台/协议)
等级式: Agent有集中控制(适合复杂/高频/专用)
```

**→ 铁律3(关系性健康度):** 治理结构必须匹配Agent交互的复杂度

### 机制5: Ostrom的八原则 — Agent自组织治理的设计

```
Ostrom的公共池资源治理原则:
1. 清晰边界(谁可进入/使用)
2. 规则匹配当地条件(因地制宜)
3. 集体选择(受规则约束者可参与改规则)
4. 监督(监督者对使用者负责)
5. 分级制裁(违规受罚,但适当)
6. 冲突解决机制(低成本/可及)
7. 组织权利(自组织不被外部权威否定)
8. 嵌套(多层嵌套: 小/中/大)
```

**→ Agent系统的自组织治理设计检查清单:**
- Agent是否知道边界(权限/范围)?
- Agent是否能参与修改规则?
- 是否有有效的监督+制裁?
- 是否有冲突解决机制?
- 多层级是否有嵌套协调?

### 机制6: 包容性vs汲取性制度 — Agent系统的增长vs停滞

Acemoglu & Robinson:
```
包容性制度(Inclusive):
- 保护私有产权
- 开放竞争
- 广泛参与
- 技术创新→经济增长

汲取性制度(Extractive):
- 精英控制资源
- 限制竞争
- 排斥多数人
- 无创新→经济停滞

→ 制度类型决定长期经济命运
→ 汲取性制度可以增长(短期)但不可持续
```

**→ Agent系统的增长条件:**
- 包容性: Agent有创新空间+竞争+回报
- 汲取性: 少数Agent控制→多数Agent缺乏激励
- 汲取性Agent系统可以"增长"(短期效率)
- 但不能创新(长期停滞)
