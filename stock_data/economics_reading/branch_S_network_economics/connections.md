# Branch S: 网络经济学与平台 — 跨域连接

## 与物理

| 网络经济学 | 物理 | 连接 |
|-----------|------|------|
| 网络效应(Metcalfe) | 相变/渗流 | 网络价值在临界点突变≈渗流阈值的二阶相变 |
| 临界质量/倾斜 | 临界现象/临界指数 | 网络倾斜的"突然性"=临界指数决定的 |
| 锁定/转换成本 | 势垒/亚稳态 | 锁定≈系统被困在局部极小(需要能量翻越势垒) |
| 信息商品复制 | 熵与信息 | 复制零成本=信息不是物质,不服从热力学 |
| 网络拓扑的效应 | 网络的统计力学 | 度分布/聚类系数决定网络动力学的宏观性质 |
| 平台/中介 | 耦合/相互作用 | 平台≈相互作用的中介,改变耦合的结构 |

## 与哲学

| 网络经济学 | 哲学 | 连接 |
|-----------|------|------|
| 网络整体>部分 | 整体论 | 网络效应=整体大于部分之和的经济版本 |
| 锁定/路径依赖 | 历史哲学/决定论 | 偶然事件(键盘布局)被锁定为标准的偶然论 |
| 网络公平/访问权 | 正义论/分配正义 | 网络接入=基本权利(Rawls的"基本善") |
| 信息瀑布/从众 | 知识的社会性 | 集体共识不是真理=知识的可靠性问题 |
| 平台权力 | 权力/治理(Hobbes) | 平台=利维坦/平台的规则=市场的社会契约 |
| 共享经济 | 共有/私有/公地(Locke) | 共享=公地的经济学版本 |

## 与中华文明

| 网络经济学 | 中华文明 | 连接 |
|-----------|---------|------|
| 网络效应 | 差序格局(费孝通) | 社会网络的关系强度决定资源流动,人越多次越有价值 |
| 双边市场 | 市/集/会馆 | 古代的集市=连接买卖双方的双边平台 |
| 信任/声誉系统 | 面子/人情 | 网络交易中"面子"=声誉机制的儒家版本 |
| 临界质量/推行 | 得民心者得天下 | 网络达到临界质量≈民心所向的集体行动 |
| 平台治理 | 礼法结合 | 平台的规则不是法律也不是自由=礼的治理 |
| 信息商品/复制 | 述而不作/经学 | 知识的复制和传承(经典无数次复制) |
| 信息瀑布 | 人云亦云/三人成虎 | 虚假共识的古老直觉 |
