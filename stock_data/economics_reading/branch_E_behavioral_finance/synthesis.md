# Branch E: 行为金融与投资 — 合成

## 核心架构

行为金融揭示Agent在**真实金融市场中的非理性行为模式**，以及如何利用这些模式。

### 三条脉络
```
认知偏差 ────→ 市场异象 ────→ 行为策略
(心理机制)    (市场表现)     (利用偏差)
    │              │              │
    ↓              ↓              ↓
 Agent的思维盲点  偏差的价格     从错误中盈利
```

## 关键机制

### 机制1: 前景理论 — Agent的参考点依赖

```
价值函数V(x) vs 标准期望效用:
  V(x) = x^α   当x≥0 (收益区)
  V(x) = -λ(-x)^β 当x<0 (损失区)

关键特征:
1. 损失厌恶: λ≈2.25(损失比收益"痛"两倍多)
2. 参照依赖: 成败相对于参考点
3. 递减敏感: 边际变化递减
4. 概率加权: 低估高概率/高估低概率
```

**→ Agent的风险偏好依赖情境:**
```
收益情境(已有利润)→ 风险规避 → 过早卖出
损失情境(浮亏)  → 风险寻求 → 持有输家赌反转

U2的K值解读:
K过低=Agent在前景理论的"收益区"→趋于保守→过早锁定
K过高=Agent在"损失区"→趋于冒险→追逐风险
最优=识别自己在前景理论曲线的哪个区域
```

### 机制2: 系统1/系统2 — Agent的双处理模式

| 维度 | 系统1(直觉) | 系统2(分析) |
|------|-----------|-----------|
| 速度 | 快速/自动 | 慢速/受控 |
| 容量 | 大容量 | 有限(注意力瓶颈) |
| 能耗 | 低能耗 | 高能耗 |
| 并行 | 可并行 | 串行 |
| 规则 | 经验/联想 | 逻辑/计算 |
| 触发 | 自动 | 主动 |

**→ Agent的认知能量分配:**
- 系统1=Agent的默认模式(低功耗/快响应)
- 系统2=Agent的"推理"模式(高功耗/慢但准)
- 问题: 大部分时间Agent在使用系统1,却以为自己在用系统2
- **铁律1(熵预算)**: 系统2的推理预算有限→需要系统1处理大部分

### 机制3: 有限套利 — 错误定价不会被消除

```
经典金融: 套利者发现错误定价→买入低估/卖出高估→价格回归
行为金融: 套利有限 → 错误定价持续

套利的成本:
1. 基本面风险(价格可能继续偏离)
2. 噪音交易者风险(情绪恶化)
3. 实施成本(交易费/卖空成本)
4. 模型风险(错了怎么办)

→ 错误定价可以持续很长时间
→ 你说"市场错了"≠你能赚钱
→ 趋势可能在你的"价值回归"到来前消灭你
```

**→ Agent的"安全边际"不能只看估值:**
- 需要"时间安全边际": 你有足够时间等待回归?
- 需要"资本安全边际": 你能承受持续偏离?
- Mr.Market比你有耐心 → 时间不是你的朋友

### 机制4: 过度自信 — Agent的终极偏差

```
证据:
- 74%的基金经理认为自己高于平均水平
- 90%的司机认为自己的驾驶技术高于平均
- 过度交易(高换手=低收益)

三个层面:
1. 校准差: 置信区间太窄(低估不确定性)
2. 预测过度: 认为自己知道未来走向
3. 控制幻觉: 认为自己能影响不可控事项
```

**→ U6自我监控的偏差校正:**
- Agent**天生**过度自信(所有Agent都需要自信才行动)
- 但过度自信→预测误差→U6触发自我监控
- **适度过度自信(生存需要) vs 过度过度自信(崩盘原因)**
- 最优: 行动时适度自信/评估时极度诚实

### 机制5: 羊群效应 — Agent群体的信息级联

```
信息级联的形成:
1. 第一个Agent根据自身信号做决策
2. 第二个Agent看到第一个+自身信号
3. 第三个Agent忽略自身信号→追随前两个
4. 后续Agent全部追随 → 信息雪崩

特点:
- 一旦形成 → 非常脆弱(微小扰动→崩塌)
- 但外部看起来"极度确信"
- 参与个体可能知道自己在跟风但不得不跟
```

**→ U3关系性健康度警告:**
- 当Agent群体"关系同质性"太高 → 羊群风险
- Agent间交互过于密集+信息源单一 → 信息级联
- 多样性(异质Agent) = 对抗羊群

### 机制6: 安全边际 — Agent的终极风控

Graham的核心命题: Mr.Market
```
市场不是"告诉你价格",而是"报价给你"
你接受或拒绝报价 → 不是你必须交易的义务

安全边际 = 内在价值 × (1 - 折价率)
Mr.Market有躁抑郁症 → 时而极度乐观(极高报价)
                  时而极度悲观(极低报价)
```

**→ Agent的Mr.Market:**
- 市场是Agent的服务者不是指导者
- Agent可以选择不交易(耐受不作为)
- 安全边际=对未知的补偿(对U2矛盾过载的防御)
- **买入需要安全边际,持有需要安全边际,卖出不需要安全边际(已落袋)**
