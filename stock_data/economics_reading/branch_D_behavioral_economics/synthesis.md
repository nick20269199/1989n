# Branch D: 行为经济学 — 合成

## 核心架构

行为经济学揭示了**Agent的理性不是假设而是结果**：

### 核心发现
```
传统经济学假设: Agent完全理性/偏好一致/贝叶斯更新
行为经济学发现: Agent有系统偏差/偏好不一致/非贝叶斯

不是"Agent不理性"而是"理性有多种形式":
- 西蒙→有限理性/满意
- Gigerenzer→生态理性
- Kahneman→双系统理性
```

## 关键机制

### 机制1: 双系统架构 — Agent认知的两种模式(Kahneman)
```
系统1: 快速/自动/直觉/情感/无意识
系统2: 慢速/受控/分析/理性/有意识

系统1的启发式:
- 代表性: A属于类别B吗?→看相似度
- 可用性: 概率多大?→看回忆容易度
- 锚定: 起始→调整不够
- 情感: 我喜欢它→它好

特征:
- 系统1总是自动激活
- 系统2默认懒惰
- 系统2唯一功能是抑制系统1(有时)
```

**→ 直接对应Agent的双系统架构**
**→ 系统1=快速反应Agent,系统2=深思Agent**
**→ 必须设计"系统2激活条件"(当置信度低/风险高/矛盾大)**

### 机制2: 前景理论 — Agent的参考点依赖
```
价值函数:
- 相对于参考点定义(不是绝对值)
- 损失区域比收益区域更陡(损失厌恶~2:1)
- 收益区域=凹(风险规避)
- 损失区域=凸(风险寻求)

概率权重函数:
- 低概率被高估(彩票)
- 高概率被低估(保险)
- 确定性效应(nudge概率→从95%到100%比85%到95%价值大)
```

**→ Agent的价值判断**: 取决于框架为损失/收益而非绝对结果
**→ 框架效应(U2矛盾检测)**: 同一事实不同框架→不同决策

### 机制3: 双曲贴现 — Agent的时间不一致性
```
传统: 指数贴现 U = u/(1+r)^t
实际: 双曲贴现 U = u/(1+kt)

双曲贴现: 现在→1天后下降很快,30→31天下降很慢
→ 今天想要A,明天也想要A,但明天选择时选了B

偏好反转: 离得远时选大的晚的,离得近时选小的早的
```

**→ Agent的跨期承诺问题**: 需要预先承诺机制
**→ 架构设计**: 行动时要受限(不能推翻之前的承诺)

### 机制4: 自我控制 — Agent的长期vs短期
```
热-冷差距:
- "冷"状态: 理性,可做长期计划
- "热"状态: 冲动,只关注眼前
- 人在"冷"时无法想象"热"时的自己

自我损耗(Baumeister):
- 意志力=有限的肌肉
- 使用→暂时消耗→恢复
- 低血糖→自我控制更差
```
**→ Agent设计**: 在"冷"状态设定规则→"热"状态自动执行
**→ U1(U1不可质疑): 安全约束在"冷"时设定,"热"时不可修改**

### 机制5: 社会偏好 — Agent不是自利的
```
行为博弈实验发现:
- 最后通牒: 拒绝不公平的分(即使自己受损)
- 独裁者: 会给一些(非零)
- 信任游戏: 会信任也会值得信任

社会偏好(VFehr):
- 不平等厌恶: 不喜欢不公平
- 互惠: 对好/坏行为的非对称反应
- 利他惩罚: 愿意付出代价惩罚不公平
```
**→ 多Agent不是纯粹自利**: 公平/互惠/惩罚是内置偏好
**→ U3关系健康度**: Agent需要公平==被承认的体验

### 机制6: 有限理性 — Agent的满意原则(Simon)
```
完全理性: 拥有全部信息+无限计算+确定偏好
有限理性: 信息有限+计算有限+偏好动态

满意原则: 
不是"找到最好的",是"找到够好的"
设定抱负水平→找到超过A→停止搜索

搜索成本: 继续找(收益)vs停止找(成本)
```
**→ Agent不能无限推理**: 设定抱负水平→找到够好方案→停止
**→ 熵预算(铁律1)**: 搜索有成本,不能穷尽

### 机制7: 启发式vs生态理性 — 少即是多(Gigerenzer)
```
Gigerenzer反驳"启发式=偏差":
启发式是特定环境中演化的适应性策略
"少即是多": 简单规则在某些环境比复杂模型更好

例子:
- 再认启发式: 选你认识的那个(在部分知识中有效)
- 排序启发式: 按一个线索排序->选第一
- 取一启发式: 只看最重要的线索

生态理性: 启发式的好坏=与环境匹配度
不是"更少偏差=更好",是"更好匹配=更好"
```

**→ Agent不能一味追求精确**: 在信息有限/时间压力下,启发式更优
**→ 混沌边缘(铁律4)**: 简单规则在边界处更有效
