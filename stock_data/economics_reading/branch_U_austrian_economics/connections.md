# Branch U: 奥地利学派与异端 — 跨域连接

## 与哲学

| 奥地利学派 | 哲学 | 连接 |
|-----------|------|------|
| 方法论个体主义 | 个体/集体/整体主义 | 所有社会现象解释到个体行动(Menger vs 整体论) |
| 主观价值 | 价值主观论/伦理 | 价值不在对象中,在主体评价中(≈价值反实在论) |
| 自发秩序 | 不可设计的社会/Hayek | 理性有限,不能设计一切(Hayek≈苏格兰启蒙) |
| 知识问题 | 知识论/默会知识 | Polanyi默会知识→Hayek分散知识 |
| 人的行动 | 行动哲学/意图 | 行动=有意图的行为(不是行为主义的反应) |
| 先验/后验 | 康德/经验论 | Mises的行动学≈康德式的先验范畴 |

## 与中华文明

| 奥地利学派 | 中华文明 | 连接 |
|-----------|---------|------|
| 自发秩序 | 无为而治/道家 | 上无为下有为≈最少干预 |
| 主观价值 | 义利之辩 | 利=价值不是"客观的"而是主体的需要 |
| 中小企业 | 庶民经济 | 千千万万的小企业主≈市场过程 |
| 法治 | 礼法/法家 | 规则下的自由≈礼治(规则不是命令) |
| 时间偏好 | 厚生/利用 | 现在vs未来的权衡=三事(正德利用厚生) |
| 企业家 | 商人/资本家 | 商人=市场过程的核心角色(商周) |

## 与物理学

| 奥地利学派 | 物理 | 连接 |
|-----------|------|------|
| 自发秩序 | 自组织/耗散结构 | Prigogine自组织=物理的自发秩序 |
| 分散知识 | 分布式处理 | 蚂蚁/免疫系统=生物学的分散知识 |
| 市场过程 | 非平衡动力学 | 市场不是均衡而是非平衡过程 |
| 时间偏好 | 热力学的时间 | 时间箭头=偏好的不可逆性 |

## 与复杂系统

| 奥地利学派 | 复杂系统 | 连接 |
|-----------|---------|------|
| 自发秩序 | 涌现 | 二者核心相同:从局部规则到全局秩序 |
| 知识问题 | 分布式认知 | 复杂系统的知识不可集中 |
| 市场过程 | 自适应系统 | 市场=adaptation + selection |
| 企业家 | 变异/创新 | 企业家≈系统演化的变异来源 |

## 跨域连接潜力评估

| 目标域 | 连接强度 | 最有价值的连接点 | 当前开发程度 |
