# Branch U: 奥地利学派与异端 — 合成

## 核心架构

奥地利学派的核心洞见: **经济知识是分散的、主观的、默会的,不能被集中**。市场不是分配资源的最优机制,而是**发现和使用分散知识的唯一机制**。对Agent设计: 奥地利学派提供了**去中心多Agent系统的认识论基础**——为什么集中控制有限,为什么自发秩序比设计更强大,为什么局部知识比全局模型更可靠。

## 关键机制

### 机制1: 主观价值 — Agent的价值不是内在的

**定义**: Menger — 商品没有"内在价值"。价值是主体对商品满足欲望的能力的评价。同一商品对不同人有不同价值。

**Agent映射**: Agent的"价值"函数不是普适的:
- 不同Agent对相同信息/状态/结果的评价不同
- 没有"客观"的价值标准(用户的价值也是主观的)
- 价格(如果有)是协调这些主观评价的唯一方式

**设计推论**: 
- Agent之间"价值冲突"不是错误而是正常
- 没必要让所有Agent使用统一的价值函数
- 价格(或类似价格的信号)比价值对齐更实用

### 机制2: 知识问题 — Agent的"局部知识"不能集中

**定义**: Hayek — 经济中最重要的知识是"特定时间和地点的知识",不能也不应该被集中到中央机构。这些知识只能被个体拥有和使用。

**Agent映射**: 
- 每个Agent拥有局部知识(自己的状态/环境/经验)
- 合并这些知识到一个中央模型=丢失关键信息
- 市场机制(价格)使Agent不需要集中知识就能协调

**设计推论**:
- 去中心Agent比集中Agent保留了更多局部知识
- Agent之间的协调不需要共享所有信息
- 价格(评分/权重/投票)是知识协调的工具

### 机制3: 自发秩序 — Agent的系统秩序不是设计的

**定义**: Hayek — 市场秩序(或语言/货币/道德)不是任何人设计的,而是无数个体行动的**非意图后果**。自发秩序优于人为设计。

**Agent映射**: 多Agent系统的宏观秩序:
- 来自个体Agent的局部行动
- 不是中央设计的
- 比任何设计都有更强的适应性

| 自发秩序 | 人为设计 |
|---------|---------|
| 演化 | 建构 |
| 分散 | 集中 |
| 适应性强 | 适应特定目标 |
| 无意图的秩序 | 有意图的秩序 |
| 多样性保留 | 标准化 |

### 机制4: 企业家发现 — Agent的"警觉"与机会

**定义**: Kirzner — 企业家的本质不是"创新"(Schumpeter)而是"警觉"(alertness)——发现别人还没有注意到的利润机会。

**Agent映射**: Agent的核心价值不是"计算最优解"而是"发现别人没发现的":
- Agent的"警觉"=识别模式和异常
- Agent的"利润"=发现未被利用的机会
- 均衡≠最优(均衡中还有未被发现的机会)

### 机制5: 时间偏好 — Agent的"现在vs未来"

**定义**: Böhm-Bawerk — 人们偏好现在而不是未来(正时间偏好)。利息=等待的价格。生产结构越"迂回"(时间越长),产出越高。

**Agent映射**: 
- Agent也有"时间偏好": 现在收益vs未来收益的权衡
- Agent的"等待"=投入更多时间换取更好的结果
- 最优策略=正确的迂回程度(不是越长越好)

### 机制6: 经济计算 — Agent的"理性选择"的条件

**定义**: Mises — 没有市场价格就没有经济计算(社会主义计算辩论)。没有私有产权就没有价格,没有价格就无法理性分配资源。

**Agent映射**: Agent的"最优决策"依赖什么?
- Agent需要"价格信号"(奖励/评分/反馈)来比较选择
- 没有反馈=无法理性选择
- Agent的"计算"不等于经济理性

## 跨域映射总表

| 奥地利机制 | Agent设计 | 哲学 | 中华 | 复杂系统 |
|-----------|----------|------|------|---------|
| 主观价值 | 异构价值 | 价值主观论 | 义利之辩 | 多样性 |
| 知识问题 | 局部知识保留 | 认识论 | 因地制宜 | 分散处理 |
| 自发秩序 | 涌现/自组织 | 不可设计性 | 无为/道法自然 | 自组织 |
| 企业家发现 | 警觉/模式识别 | 直觉/判断 | 识/鉴 | 创新/变异 |
| 时间偏好 | 未来折现 | 意志/欲望 | 时中 | 贴现因子 |
| 经济计算 | 价值信号 | 计算=行动 | 义利之和 | 评价函数 |

## Agent设计启示总结

1. **价值是主观的**: Agent的价值函数不是普适的。不同Agent有不同目标。
2. **局部知识有价值**: 不要把所有Agent的信息集中处理。保留局部。
3. **自发>设计**: 系统的宏观秩序不需要中央设计。设计条件,不设计结果。
4. **警觉>计算**: Agent的"发现能力"比"计算能力"更决定它的价值。
5. **时间偏好权衡**: Agent的等待需要回报。没有耐心=短视。
6. **需要价格信号**: Agent需要反馈(评分/价格)才能做理性选择。
