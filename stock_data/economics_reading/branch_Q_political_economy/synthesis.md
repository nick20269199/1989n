# Branch Q: 政治经济学 — 合成

## 核心架构

政治经济学研究**权力如何分配资源,以及经济如何产生权力**。经济不是中性的技术问题,而是权力的场域。

### 三条轴线
```
生产与分配 ────→ 制度与治理 ────→ 意识形态
(谁创造/谁获得)   (规则的设计)    (故事的合法性)
```

## 关键机制

### 机制1: r>g — 资本的自我扩张

Piketty的核心: r(资本回报率) > g(经济增长率) → 资本自动积累 → 财富集中。

**→ Agent的"马太效应":** 已有的Agent(资本)增长快于新Agent(劳动)。系统设计需要再分配机制,否则自我强化不平等。

### 机制2: 包容vs汲取制度

Acemoglu: 制度要么包容(人人有机会)→繁荣,要么汲取(精英控制)→停滞。

**→ Agent系统的增长条件:** 包容=Agent有创新空间+竞争+回报。汲取=短期效率但长期停滞。

### 机制3: 公共选择=Agent的自利政治

Buchanan: 政治Actor和市场中一样自利。政客最大化选票,官僚最大化预算。

**→ 在设计Agent系统治理时,不能假设治理Agent是利他的。他们也有自己的目标。治理架构需要考虑到Agent的自利行为。**
