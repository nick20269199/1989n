## 一、段位论 — 交易者的九个层次

### 将材 | 九种交易者

**原文**: 夫将材有九：
- 仁将：道之以德，齐之以礼，而知其饥寒，察其劳苦
- 义将：事无苟免，不为利挠，有死之荣，无生之辱
- 礼将：贵而不骄，胜而不恃，贤而能下，刚而能忍
- 智将：奇变莫测，动应多端，转祸为福，临危制胜
- 信将：进有厚赏，退有严刑，赏不逾时，刑不择贵
- 步将：足轻戎马，气盖千夫，善固疆埸，长于剑戟
- 骑将：登高履险，驰射如飞，进则先行，退则后殿
- 猛将：气凌三军，志轻强虏，怯于小战，勇于大敌
- 大将：见贤若不及，从谏如顺流，宽而能刚，勇而多计

**穿透**: 九种将材不是等级，是九种能力维度。顶尖交易者需要集齐九种能力于一身：

| 能力 | 交易映射 |
|------|---------|
| **仁将** | 善待自己，知道自己的极限和承受力 |
| **义将** | 不为蝇头小利放弃原则，宁可错过不可做错 |
| **礼将** | 盈利不骄，胜仗不狂，能接受下属意见 |
| **智将** | 多变市况切换策略，化危机为转机 |
| **信将** | 严格执行止损止盈，对系统信守承诺 |
| **步将** | 基础功底扎实——技术分析、基本面排查 |
| **骑将** | 快速反应能力——机会来了第一时间行动 |
| **猛将** | 大机会重仓出击，小机会收敛等待 |
| **大将** | 兼容并包，能从不同体系吸收精华 |

### 将器 | 你的能力容器有多大

**原文**: 将之器，其用大小不同：
- 十夫之将 → 察其奸，伺其祸，为众所服
- 百夫之将 → 夙兴夜寐，言词密察
- 千夫之将 → 直而有虑，勇而能斗
- 万夫之将 → 外貌桓桓，中情烈烈，知人勤劳，悉人饥寒
- 十万人之将 → 进贤进能，日慎一日，诚信宽大，闲于理乱
- 天下之将 → 仁爱洽于下，信义服邻国，上知天文，中察人事，下识地理

**穿透**: "器"是你的能力容器——你能管理多大的资金、多复杂的组合、多长的持仓周期。从交易新手到大师，容器逐步扩大：
- **十夫** → 管自己的小账户，能识别明显的风险和机会
- **百夫** → 勤奋复盘、严控细节、记录每一笔
- **千夫** → 有核心策略且能执行，敢在机会来临时出手
- **万夫** → 情绪稳定、知行合一、了解自身极限
- **十万夫** → 能管理多策略/多品种组合，每日如履薄冰
- **天下** → 宏观微观贯通，建立系统而非依赖个人能力

**操作**: 诚实评估自己当前在哪个段位。不自欺——"十夫"的阶段做"十万夫"的事，必然爆仓。段位不是耻辱，不自知才是。

## 二、八弊 — 交易者的八大死穴

### 将弊

**原文**: 夫为将之道，有八弊焉：
一曰贪而无厌，二曰妒贤嫉能，三曰信谗好佞，四曰料彼不自料，五曰犹豫不自决，六曰荒淫于酒色，七曰奸诈而自怯，八曰狡言而不以礼。

**穿透**: 这八弊是交易者的绝命清单。逐条穿透：

1. **贪而无厌** → 盈利了还想更多，最终利润回吐甚至亏损。贪的根源不是欲望太强，是系统边界不清晰——你不知道"够了"是多少。
2. **妒贤嫉能** → 看别人赚了心态失衡，追高别人的持仓而非自己的分析。每个交易者的资金曲线是独一份的，别人的利润和你无关。
3. **信谗好佞** → 听大V荐股、群消息、自媒体分析，而不是自己的判断。市场里"好佞"最多——那些说你想听的话的人。
4. **料彼不自料** → 分析市场头头是道，分析自己的弱点一片空白。花在分析行情上的时间有十分之一花在分析自己吗？
5. **犹豫不自决** → 信号出现了不敢进，该止损了下不去手。犹豫的本质是预案不足——你事先没想清楚每种情况的应对。
6. **荒淫于酒色** → 生活混乱、作息不规律、决策时状态差。交易是脑力竞技，身体和精力是最基础的本钱。
7. **奸诈而自怯** → 对自己的系统不诚实，明明系统看空却因为持仓看多。欺骗系统就是欺骗自己，最终市场会惩罚你。
8. **狡言而不以礼** → 亏了找理由，不尊重市场的规则。市场和你不讲道理，你只能顺应它。

**操作**: 每周对照八弊自检一次，哪一条犯了就标记，连续三次犯同一条 → 触发深度反省。

### 将骄吝 | 两个最致命的情绪

**原文**: 将不可骄，骄则失礼，失礼则人离，人离则众判。将不可吝，吝则赏不行，赏不行则士不致命，士不致命则军无功。

孔子曰："如有周公之才之美，使骄且吝，其余不足观也已。"

**穿透**: 骄和吝，在交易中是最致命的两个情绪：
- **骄** = 连续盈利后觉得自己"悟道了"，开始不设止损、重仓押注、不按系统来。孔子说：即使你有周公的天才，驕且吝——其他就没法看了。
- **吝** = 不肯止损、不肯认错、不肯给系统投入时间优化。吝在交易中的体现：小亏拖成大亏，因为"舍不得那点止损"。

**操作**: 永远记住——你已经连续盈利了？骄的信号。你犹豫要不要止损？吝的信号。两个信号无论哪个亮，都要强制自己停一步。

### 将强 | 五强八恶

**原文**: 五强：高节可以厉俗，孝弟可以扬名，信义可以交友，沈虑可以容众，力行可以建功。
八恶：谋不能料是非，礼不能任贤良，政不能正刑法，富不能济穷厄，智不能备未形，虑不能防微密，达不能举所知，败不能无怨谤。

**穿透**: 五强在交易中：
- **高节** → 始终按系统交易，不因市场噪音改变原则
- **信义** → 对自己信守承诺，说好的止损就一定执行
- **沈虑** → 能容纳不确定性，不急于下结论
- **力行** → 复盘、记录、总结——这些"笨功夫"是唯一的捷径
八恶中最值得警惕的：
- **智不能备未形** → 行情出来后才"早知道"，而不是提前预判
- **败不能无怨谤** → 亏了找外部原因（主力针对我/消息晚了/系统不好），而不是找自己的原因

## 三、心法 — 交易心态核心

### 将志 | 核心定力

**原文**: 兵者凶器，将者危任，是以器刚则缺，任重则危。故善将者，不恃强，不怙势，宠之而不喜，辱之而不惧，见利不贪，见美不淫，以身殉国，壹意而已。

**穿透**: 交易是"凶器"——你的资金在里面，每一秒都在面对风险。善交易者：
- 不恃强 → 不因账户大了就重仓
- 不怙势 → 不因趋势明显就追高
- 宠之不喜 → 连续盈利不飘
- 辱之不惧 → 连续亏损不慌
- 见利不贪 → 看到机会不all-in
- 壹意而已 → 专注自己的系统，专注自己的路

**操作**: 每次开仓前默念四句：不恃强、不怙势、宠之不喜、辱之不惧。念完再开仓。

### 将善 | 五善四欲

**原文**: 五善者：善知敌之形势，善知进退之道，善知国之虚实，善知天时人事，善知山川险阻。四欲者：战欲奇，谋欲密，众欲静，心欲一。

**穿透**: 交易者的五善：
- 知敌之形势 = 读懂市场当前状态（趋势/震荡/高波/低波）
- 知进退之道 = 知道什么时候该进什么时候该退（仓位管理）
- 知国之虚实 = 知道标的的真实价值/资金面/筹码结构
- 知天时人事 = 宏观环境+产业周期+事件催化
- 知山川险阻 = 关键支撑阻力位、流动性陷阱

四欲：
- 战欲奇 → 出手要有差异化逻辑，不跟风
- 谋欲密 → 计划要周密，每种情况有预案
- 众欲静 → 持仓中保持冷静，不被情绪裹挟
- 心欲一 → 专注自己的系统，不分心

### 将刚 | 刚柔之道

**原文**: 善将者，其刚不可折，其柔不可卷，故以弱制强，以柔制刚。纯柔纯弱，其势必削；纯刚纯强，其势必亡；不柔不刚，合道之常。

**穿透**: 交易中的刚柔平衡：
- **刚不可折** → 你的底线（止损、风险控制）不能动摇
- **柔不可卷** → 你的策略和市场相处的方式必须灵活
- **纯柔纯弱** → 完全跟着情绪走，没有纪律="势削"
- **纯刚纯强** → 死多头/死空头，不顺应市场="势亡"
- **不柔不刚** → 该执行纪律时铁血，该顺应市场时灵活

**操作**: 区分什么是"刚"的（系统中不可变的部分：止损纪律/仓位上限/风控规则）和什么是"柔"的（策略参数/选股标准/进出场时机）。刚的不改，柔的不僵。

### 自勉 | 修身的底线

**原文**: 圣人则天，贤者法地，智者则古。骄者招毁，妄者稔祸，多语者寡信，自奉者少恩，赏于无功者离，罚加无罪者怨，喜怒不当者灭。

**穿透**: 这是将苑最锐利的修身警句：
- **骄者招毁** → 你觉得"稳了"的时候，离亏损不远了
- **妄者稔祸** → 凭感觉开仓、追涨杀跌，祸是慢慢积攒的
- **多语者寡信** → 公开喊单、预测点位，说多了自己都信了
- **喜怒不当者灭** → 情绪化交易的最大恶果：本金清零

## 四、知人之智 — 读懂市场参与者

### 知人性 | 七法识人

**原文**: 夫知人之性，莫难察焉。美恶既殊，情貌不一，有温良而为诈者，有外恭而内欺者，有外勇而内怯者，有尽力而不忠者。然知人之道有七焉：
一曰问之以是非而观其志
二曰穷之以辞辩而观其变
三曰咨之以计谋而观其识
四曰告之以祸难而观其勇
五曰醉之以酒而观其性
六曰临之以利而观其廉
七曰期之以事而观其信

**穿透**: 七法识人，是分析市场参与者（主力/机构/游资/散户）行为的方法：

| 识人法 | 市场应用 |
|--------|---------|
| 问是非观其志 | 看主力的"志"——拉升前有试盘/洗盘行为吗 |
| 穷辞辩观其变 | 看股价在关键位置的反应——突破是真的还是假的 |
| 咨计谋观其识 | 看产业逻辑/基本面是否有真实支撑 |
| 告祸难观其勇 | 看利空出来时股价怎么走——跌不动说明有承接 |
| 醉酒观其性 | 看极端行情（涨停/跌停）时的盘口特征 |
| 临利观其廉 | 看利好兑现时是继续涨还是出货 |
| 期事观其信 | 看技术形态是否真的兑现——假突破还是真突破 |

### 情势 | 六种对手盘人格

**原文**: 夫将有勇而轻死者，有急而心速者，有贪而喜利者，有仁而不忍者，有智而心怯者，有谋而情缓者。
是故：勇而轻死者可暴也，急而心速者可久也，贪而喜利者可遗也，仁而不忍者可劳也，智而心怯者可窘也，谋而情缓者可袭也。

**穿透**: 这六种"对手盘人格"就是市场中不同类型的参与者，以及应对策略：

| 类型 | 市场表现 | 应对 |
|------|---------|------|
| 勇而轻死 | 游资敢死队，追涨停 | 等力竭时做反手 |
| 急而心速 | 短线客，拿不住单 | 耐心持有，等他们出局 |
| 贪而喜利 | 利好冲进去的跟风盘 | 给"饵"（拉升）诱多后收割 |
| 仁而不忍 | 多头抗单不止损 | 持续施压直到崩溃 |
| 智而心怯 | 机构仓位轻怕回撤 | 打压到关键位逼其加仓 |
| 谋而情缓 | 长线资金建仓慢 | 快速拉升不让其吃饱 |

**操作**: 观察盘面判断当前主导力量是哪种类型，针对性调整策略。快速拉升往往对应"急者"或"勇者"，缓慢推升对应"谋者"。

### 察情 | 读盘三十法

**原文**: 
夫兵起而静者，恃其险也
迫而挑战者，欲人之进也
众树动者，车来也
尘土卑而广者，徒来也
辞强而进驱者，退也
半进而半退者，诱也
杖而行者，饥也
见利而不进者，劳也
鸟集者，虚也
夜呼者，恐也
军扰者，将不重也
旌旗动者，乱也
吏怒者，倦也
数赏者，窘也
数罚者，困也
来委谢者，欲休息也
币重而言甘者，诱也

**穿透**: 这是一套极为精密的"盘口读法"——从现象推断本质。

交易对应：
- **兵起而静者，恃其险也** → 利空不跌 = 有大资金护盘/筹码集中
- **迫而挑战者，欲人之进也** → 急速拉升 = 引诱跟风盘（引诱你追）
- **辞强而进驱者，退也** → 极力看多宣传 = 主力准备出货
- **半进而半退者，诱也** → 拉升又回撤再拉升 = 典型的诱多/洗盘
- **见利而不进者，劳也** → 利好不涨 = 多头已疲惫，要跌了
- **鸟集者，虚也** → 散户聚集的标的 = 主力已出逃
- **夜呼者，恐也** → 尾盘恐慌 = 市场情绪脆弱
- **旌旗动者，乱也** → 盘面混乱,各板块乱拉 = 市场缺乏主线
- **数赏者，窘也** → 频繁用利好消息刺激 = 主力处境困难
- **数罚者，困也** → 频繁出利空打压 = 空头能量快耗尽了

**操作**: 建立你的"察情清单"——每次看盘时，对照这些现象判断市场真实状态。不被价格表面运动迷惑。

## 五、出师与预备 — 交易前的仪式

### 出师 | 开仓仪式

**原文**: 古者国有危难，君简贤能而任之，齐三日，入太庙，南面而立，将北面，太师进钺于君。君持钺柄以授将，曰："从此至军，将军其裁之。"复命曰："见其虚则进，见其实则退。勿以身贵而贱人，勿以独见而违众，勿恃功能而失忠信。士未坐勿坐，士未食勿食，同寒署，等劳逸，齐甘苦，均危患，如此则士必尽死，敌必可亡。"

**穿透**: 出师是一套完整的授命仪式，在交易中对应"开仓仪式"：
- **齐三日** → 交易前静心归零，不带情绪
- **太庙授钺** → 开仓前做完整的分析，不是凭感觉
- **见虚则进，见实则退** → 看到机会才进，看到风险就撤
- **勿以身贵而贱人** → 不以资金大小、盈利多少决定策略
- **勿以独见而违众** → 不要固执己见无视市场信号
- **勿恃功能而失忠信** → 不因为过去分析的准就飘

**操作**: 建立你的"开仓仪式"——每次开仓前按照固定流程走一遍（如：五算清单 → 技术确认 → 资金确认 → 风控设好），不做完不开仓。

### 戒备 | 有备无患

**原文**: 夫国之大务，莫先于戒备。若夫失之毫厘，则差若千里，覆军杀将，势不逾息，可不惧哉！若乃居安而不思危，寇至不知惧，此谓燕巢于幕，鱼游于鼎，亡不俟夕矣。

**穿透**: 戒备是交易中最重要的习惯之一。盈利时最容易放松戒备——"燕巢于幕，鱼游于鼎"形容的就是连续盈利后的状态：看起来很美好，但最危险了。

**操作**: 持续盈利后，强制做一次全面的风险排查：当前最大回撤风险？黑天鹅情景？如果明天停盘一周会怎样？

### 习练 | 练比战更重要

**原文**: 夫军无习练，百不当一；习而用之，一可当百。故仲尼曰："不教而战，是谓弃之。"

一人可教十人，十人可教百人，百人可教千人，千人可教万人。

**穿透**: 不训练就上实盘 = 弃之（放弃本金）。但你不需要一开始就是大师——只需要一次比一次好。一人→十人→百人→千人的链式学习：今天学一个技巧，练熟后教给明天的自己。

**操作**: 新策略先模拟跑100笔再上实盘。每次实盘亏损后做复盘记录，把教训转化为规则。

### 军蠹 | 交易系统的九大蛀虫

**原文**: 夫三军之行，有探候不审，烽火失度；后期犯令，不应时机；乍前乍后，不合金鼓；上不恤下，削敛无度；营私徇己，不恤饥寒；非言妖辞，妄陈祸福；无事喧杂，惊惑将吏；勇不受制，专而陵上；侵竭府库，擅给其财。此九者，三军之蠹，有之必败也。

**穿透**: 交易系统的九大蛀虫：
1. 探候不审 → 数据源不核实（分析基于错误数据）
2. 烽火失度 → 信号系统不稳定（一会买入一会卖出）
3. 后期犯令 → 错过入场/出场时机
4. 上不恤下 → 大仓位不管小仓位的风险（仓位配置失衡）
5. 营私徇己 → 偏向自己的持仓（屁股决定脑袋）
6. 非言妖辞 → 看各种玄学预测、微信群消息
7. 无事喧杂 → 过度交易/频繁看盘
8. 勇不受制 → 凭感觉不按系统（"这次不一样"）
9. 侵竭府库 → 单笔亏损超出风控限额

**操作**: 每月对照九蠹检查一次系统，发现蛀虫立即清除。

## 六、机与势 — 时机判断

### 智用 | 顺天因时依人

**原文**: 夫为将之道，必顺天、因时、依人以立胜也。故天作时不作而人作，是谓逆时；时作天不作而人作，是谓逆天；天作时作而人不作，是谓逆人。智者不逆天，亦不逆时，亦不逆人也。

**穿透**: 交易中的三才判断：
- **天** = 宏观大环境（牛市/熊市/震荡市）
- **时** = 时机/催化（财报季/政策窗口/事件节点）
- **人** = 自身状态（心态/资金/精力）

三者必须对齐才出手。天时人不齐 → 不动。时人齐天不齐 → 不动。天人齐时不齐 → 等待时机。

### 机形 | 三机判断

**原文**: 夫以愚克智，逆也；以智克愚，顺也；以智克智，机也。其道有三：一曰事，二曰势，三曰情。事机作而不能应，非智也；势机动而不能制，非贤也；情机发而不能行，非勇也。

**穿透**: 交易中的三种机会信号：
- **事机** → 基本面/消息面催化出现（财报超预期/政策出台）→ 不能识别 = 不智
- **势机** → 技术面趋势形成（突破/均线金叉/量能确认）→ 不能把握 = 不贤
- **情机** → 市场情绪拐点（极度恐慌时买入/极度狂热时卖出）→ 不敢行动 = 不勇

**操作**: 区分你看到的是事机、势机还是情机。不同机需要不同的勇气和技能；三者同时出现时是最佳时机。

### 应机 | 见机而作

**原文**: 非智者孰能见机而作乎？见机之道，莫先于不意。故猛兽失险，童子持戟以追之；蜂虿发毒，壮士彷徨而失色。以其祸出不图，变速非虑也。

**穿透**: "见机之道，莫先于不意"——最好的机会是出乎大多数人意料的。当所有人都预期某个方向时，机会已经不存在了。猛兽失了险（老虎没了牙），小孩子都能追着打——和交易一样：当所有人都恐慌抛售时，反而是最安全的买入时机。

**操作**: 训练自己在大众一致预期时质疑，在大众恐慌时冷静。逆向不是故意作对，是寻找"不意"的机会。

### 兵势 | 天时地利人和

**原文**: 夫行兵之势有三焉：一曰天，二曰地，三曰人。天势者，日月清明，五星合度；地势者，城峻重崖，洪波千里；人势者，主圣将贤，三军由礼，士卒用命，粮甲坚备。善将者，因天之时，就地之势，依人之利，则所向无敌。

**穿透**: 最好的交易是三势合一：
- 天势 = 宏观周期向上 + 政策支持 + 流动性宽松
- 地势 = 板块在低位 + 个股基本面良好 + 技术形态突破
- 人势 = 主力资金流入 + 筹码集中度高 + 市场情绪配合

三势合一 → 重仓出击。缺一势 → 轻仓或观望。

## 七、系统与工具

### 腹心 | 交易系统的三要素

**原文**: 夫为将者，必有腹心、耳目、爪牙。无腹心者，如人夜行，无所措手足；无耳目者，如冥然而居，不知运动；无爪牙者，如饥人食毒物，无不死矣。故善将者，必有博闻多智者为腹心，沉审谨密者为耳目，勇悍善敌者为爪牙。

**穿透**: 交易者必有的三件套：

| 要素 | 比喻 | 交易对应 |
|------|------|---------|
| **腹心** | 最核心的智囊 | 你的交易系统框架（原则、策略、方法论） |
| **耳目** | 收集信息的情报 | 数据源、分析工具、技术指标、情报系统 |
| **爪牙** | 执行的武力 | 交易平台、自动交易脚本、条件单、止损单 |

**操作**: 检视自己的三件套——腹心是否清晰（你需要一个明确的交易哲学），耳目是否敏锐（数据源是否可靠全面），爪牙是否锋利（执行工具是否到位）。

### 三宾 | 你的三个外脑

**原文**: 夫三军之行也，必有宾客群议得失，以资将用。
- 上宾：词若县流，奇谋不测，博闻广见，多艺多才
- 中宾：猛若熊虎，捷若腾猿，刚如铁石，利若龙泉
- 下宾：多言或中，薄技小才，常人之能

**穿透**: 三宾对应你借用外部资源的能力：
- **上宾** → 你的顶级参考框架（大师的书籍、核心方法论、你最信任的分析体系）
- **中宾** → 你的分析工具链（技术指标、量化模型、选股公式）
- **下宾** → 日常参考的信息（股评、新闻、其他人的观点——看看就好，不轻信）

### 整师 | 系统的完整性

**原文**: 夫出师行军，以整为胜。若赏罚不明，法令不信，金之不止，鼓之不进，虽有百万之师，无益于用。

**穿透**: 交易系统的"整"= 协同一致：
- 止损止盈规则一致（赏罚明）
- 信号执行不打折扣（法令信）
- 该进就进该出就出（金鼓应）

如果系统发出买入信号你犹豫，卖出信号你侥幸——再好的系统也无用。

### 厉士 | 持续激励自己

**原文**: 尊之以爵，赡之以财，则士无不至矣；接之以礼，厉之以信，则士无不死矣；畜恩不倦，法若画一，则士无不服矣；先之以身，后之以人，则士无不勇矣；小善必录，小功必赏，则士无不劝矣。

**穿透**: 如何对待你的"交易系统"——它就是你的军队：
- 给它投入（时间/资金/学习成本）就会回报你
- 对它是诚实的（回测数据不造假），它就会保护你
- 每次小进步都记录下来，小功必赏——积累正反馈

**操作**: 建立你的"系统维护日志"——每次系统优化、每次纪律执行、每次复盘心得都记录，让系统感受到你是在认真对待它。

## 八、不同市况不同战法

### 战道 | 地形决定战法

**原文**: 林战之道：昼广旌旗，夜多金鼓，利用短兵，巧在设伏。
丛战之道：利用剑楯，先度其路，十里一场，五里一应。
谷战之道：巧于设伏，利以勇斗。
水战之道：利在舟楫，多张旗帜以惑之。
夜战之道：利在机密，出其不意。

**穿透**: 不同的市场环境需要完全不同的策略：

| 地形 | 市况对应 | 策略 |
|------|---------|------|
| **林战** = 震荡市 | 无明显方向，多空拉锯 | 高抛低吸，小仓位短线，设好伏兵（挂单） |
| **丛战** = 板块轮动 | 热点快速切换 | 提前布局，先度其路（预判轮动方向） |
| **谷战** = 恐慌下跌 | 大跌之后的反弹机会 | 勇气最关键，敢在低位买入 |
| **水战** = 趋势市 | 明显的上升/下降通道 | 顺流而击（顺势），多张旗帜（分批建仓） |
| **夜战** = 黑天鹅 | 突发事件导致极端行情 | 机密行事（快速反应），出其不意（别人恐慌时出手） |

### 审因 | 借势借力

**原文**: 夫因人之势以伐恶，则黄帝不能与争威矣；因人之力以决胜，则汤、武不能与争功矣。若能审因而加之威胜，则万夫之雄将可图，四海之英豪受制矣。

**穿透**: 交易中最高效的方式是借力——不是自己创造行情，而是识别已经形成的势力并加入它：
- 借个股之势（主力建仓完成要拉升了跟着进）
- 借板块之势（板块龙头涨停了做跟风）
- 借大盘之势（大盘趋势向上时做多）
- 借政策之势（产业政策支持的方向）

### 四夷 | 不同市场参与者的应对

**原文**: 东夷、南蛮、西戎、北狄——四种不同的对手，四种不同的应对。

**穿透**: 将苑最后四篇讲四夷，实际上是讲如何应对不同类型的对手盘：

| 类型 | 特征 | 应对 |
|------|------|------|
| **东夷** | 规则感弱但团结，凭险自固 | 等到其内部矛盾出现时才介入 |
| **南蛮** | 散乱，难教，失意就内斗 | 速战速决，不能久拖 |
| **西戎** | 强悍好利，地广人稀 | 等其外部争端或内乱时出击 |
| **北狄** | 流动性强，打不过就跑 | 守边（固守能力圈）；候虚而乘（等机会） |

在交易中这对应不同类型的个股或板块——有些该短线快进快出（南蛮型）、有些该长期持有等催化（西戎型）、有些该等充分回调再介入（东夷型）、有些该设好条件单让其自己触发（北狄型）。

## 九、核心十五律 — 交易者的十五戒

### 谨候

**原文**: 律有十五焉：
一曰虑，间谍明也
二曰诘，谇候谨也
三曰勇，敌众不挠也
四曰廉，见利思义也
五曰平，赏罚均也
六曰忍，善含耻也
七曰宽，能容众也
八曰信，重然诺也
九曰敬，礼贤能也
十曰明，不纳谗也
十一曰谨，不违礼也
十二曰仁，善养士卒也
十三曰忠，以身徇国也
十四曰分，知止足也
十五曰谋，自料知他也

**穿透**: 这是将苑全书最高密度的十五律，每条都是交易者必须内化的准则：

| # | 律 | 原文 | 交易穿透 |
|---|-----|------|---------|
| 1 | **虑** | 情报清晰 | 你的分析必须有可靠的数据支撑，不凭感觉 |
| 2 | **诘** | 侦察谨慎 | 每次复盘深入追问，不被表面盈亏迷惑 |
| 3 | **勇** | 遇强不挠 | 连续亏损时不放弃系统，坚持执行 |
| 4 | **廉** | 见利思义 | 有机会时先问"风险在哪里"，不只看利润 |
| 5 | **平** | 赏罚公平 | 对系统信号一视同仁，不因偏好改规则 |
| 6 | **忍** | 善含耻 | 能接受亏损、接受判断错误、接受别人赚更多 |
| 7 | **宽** | 能容众 | 能容纳不同的市场观点，不固执己见 |
| 8 | **信** | 重诺守信 | 对自己说好的止损止盈必须执行 |
| 9 | **敬** | 礼贤能 | 保持谦逊，向更好的交易者学习 |
| 10 | **明** | 不纳谗言 | 不听小道消息/内幕推荐/群里的"下一个涨停" |
| 11 | **谨** | 不违礼法 | 不违反交易纪律，不在规则外开仓 |
| 12 | **仁** | 善待系统 | 系统出问题了修复它而不是抛弃它 |
| 13 | **忠** | 以身殉国 | 对交易事业专注，做出必要的牺牲（时间/精力） |
| 14 | **分** | 知止足 | 知道什么时候该收手——盈利够了、亏损到了 |
| 15 | **谋** | 知己知彼 | 既了解市场也了解自己，不自欺 |

**操作**: 把十五律做成一张卡片，每天开盘前读一遍。哪一条今天特别需要注意，标记出来。

## 十、二十四条操作信号

### 自知之明

1. **段位自评** | 每月评估自己当前段位（十夫→天下），做与段位匹配的事
2. **八弊自检** | 每周对照贪妒谗骄吝等八弊，标记本周犯了哪条
3. **骄吝双警** | 连续盈利 -> 骄的信号；犹豫止损 -> 吝的信号。两警其一即停一步
4. **三才判定** | 每次开仓前判断天时人三才是否对齐。缺一不动

### 识市之智

5. **七法识盘** | 用七法（问是非/穷辞辩/咨计谋等）分析主力意图
6. **六型辨敌** | 判断当前主导力量是哪种类型（急者/勇者/贪者/谋者等）
7. **察情三十** | 建立你的"察情清单"，从盘面现象推断本质
8. **三机齐备** | 事机+势机+情机同时出现才是最佳出手时机
9. **不意机会** | 当大多数人预期一致时，寻找"不意"的反向机会
10. **三势合一** | 天势+地势+人势 → 重仓。缺一势 → 轻仓或等

### 交易系统

11. **腹心耳目爪牙** | 检视你的三件套：核心框架、数据源、执行工具
12. **九蠹排查** | 每月排查交易系统的九大蛀虫（数据/信号/仓位/情绪等）
13. **整师检验** | 检查系统是否"整"：止盈止损规则一致、信号执行不打折
14. **开仓仪式** | 每次开仓走固定流程：分析→确认→设止损→执行
15. **戒备状态** | 盈利后强制风险排查：最大回撤？黑天鹅情景？
16. **习练优先** | 新策略模拟100笔 → 小仓50笔 → 正常仓位

### 临战心态

17. **出师四念** | 开仓前默念：不恃强、不怙势、宠之不喜、辱之不惧
18. **刚柔分离** | 刚（止损/风控）不可改，柔（策略/仓位）灵活调整
19. **喜怒当戒** | 情绪化时不做任何决策，离场散步10分钟
20. **以败为练** | 亏损不是失败是训练数据。每笔亏损做复盘再考虑下一笔
21. **胜战自抑** | 连续盈利后主动降低仓位——最能保护你的不是技术，是谨慎
22. **五善四欲** | 判断市场状态/进退时机/价值真相/宏观环境/关键位置；出手要奇、谋划要密、持仓要静、心要专一

### 地形应对

23. **五形战法** | 震荡市=高抛低吸，板块轮动=预判布局，恐慌下跌=敢买，趋势市=顺势，黑天鹅=快速反应
24. **十五律日课** | 每日开盘前读一遍十五律，标记今天最需要注意的一条
