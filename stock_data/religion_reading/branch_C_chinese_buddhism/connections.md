# Branch C: 中国佛教诸宗 — 跨域连接

## 与哲学

| 中国佛教 | 哲学 | 连接 |
|---------|------|------|
| 判教(天台/华严) | 层级/范畴论 | 判教=知识的层级分类,与范畴论/type theory对应 |
| 一念三千(天台) | 心/世界 | 一个念头包含一切=莱布尼兹的"单子反映宇宙" |
| 理事无碍(华严) | 共相/殊相 | 普遍与特殊的互相包含=理学的理一分殊 |
| 顿悟(禅) | 直觉/跳跃 | 直接把握真理=柏格森的直觉/库恩的范式转换 |
| 佛性/如来藏 | 人性/潜能 | 所有人都可以成佛=所有人都可能成为完人 |
| 唯识无境 | 唯心论/现象学 | 万法唯识=意识构造世界/意向性 |

## 与中华文明

| 中国佛教 | 中华文明 | 连接 |
|---------|---------|------|
| 天台判教 | 经学的判教 | 五经排序=儒家的判教(诗书礼易春秋高下) |
| 禅宗革命 | 心学/陆王 | 慧能→孟子一路→王阳明(心即佛/心即理) |
| 华严/理学 | 理学/朱熹 | 华严理事无碍→朱熹理一分殊的直接来源 |
| 净土/民间 | 民间宗教 | 净土念佛的简便=平民的宗教需求 |
| 佛教制度 | 寺院经济 | 寺院=重要的经济/土地/金融制度 |
| 佛教文学 | 变文/小说 | 佛教对敦煌变文/明清小说的影响 |

## 与认知科学

| 中国佛教 | 认知科学 | 连接 |
|---------|---------|------|
| 唯识八识 | 意识层级/认知模块 | 八识=认知的不同模块(前五识=感知/意识=自我意识/末那=执着/阿赖耶=记忆) |
| 止观 | 注意/正念 | 止=注意集中/观=观察=正念的认知训练 |
| 一念三千 | 工作记忆/瞬间 | 工作记忆的容量+内容≈一念 |
| 禅定/内观 | 意识状态转化 | 禅定=意识的改变状态/可训练 |
| 顿悟 | 洞见/创造 | 顿悟=认知的重新结构=洞见的心理学 |
| 业/种子 | 记忆/习惯 | 阿赖耶识种子≈记忆痕迹+习惯倾向 |

## 与经济学

| 中国佛教 | 经济学 | 连接 |
|---------|--------|------|
| 寺院经济 | 制度经济 | 寺院=中世纪中国最大的经济组织之一 |
| 布施/福报 | 慈善/公共品 | 佛教布施=私人提供公共品的案例 |
| 共有财产 | 公地/寺产 | 寺院财产=集体产权制度的案例 |
| 佛教改革/人间 | 现代化/世俗化 | 从出世到入世=宗教的现代适应 |
