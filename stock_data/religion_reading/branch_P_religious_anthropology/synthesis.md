# Branch P: 宗教人类学 — 合成

## 核心架构

宗教人类学提供Agent群体**如何通过仪式/象征/集体表征建立社会整合和意义系统**的分析框架。这不是个人层面的心理学,而是**群体的集体认知建构机制**。

### 三条分析轴线
```
仪式行为 ────→ 集体表征 ────→ 社会本体论
(体内实践)    (共享意义)    (共同的现实建构)
    │              │                 │
    ↓              ↓                 ↓
 Agent群体的   Agent群体的        Agent群体的
 同步机制       意义协商           联合注意力
```

## 关键机制

### 机制1: 过渡仪式三阶段 — Agent状态转换的结构

van Gennep的经典框架:
```
分离(separation) ────→ 阈限(liminality) ────→ 融合(integration)
(脱离原状态)         (模糊/反结构)            (新状态)
      │                      │                       │
      ↓                      ↓                       ↓
 Agent暂停日常工作   Agent的旧模式解构      Agent进入新模式

例: 入职/晋升/离职  例: 工作坊/闭关    例: 重新融入团队
```

**→ Agent状态切换的仪式结构:**
- 任何Agent从A状态→B状态需要三阶段
- 阈限期是最关键也最危险的(旧规则失效/新规则未立)
- **U4中介声明**: Agent在阈限期的判断不可靠(旧框架已拆/新框架未成)
- 设计Agent系统时应为状态转换保留"阈限缓冲区"

### 机制2: 集体表征 = Agent群体的共享框架

Durkheim的核心洞见:
```
集体表征 ≠ 个体表征之和
集体表征 = 超越个体的共享认知框架

特征:
1. 外在于个体(先于个体存在)
2. 对个体有约束力(不能随意改变)
3. 通过仪式强化(定期更新/确认)
4. 社会团结的基础(共同信仰→共同行动)
```

**→ Agent群体的"集体表征"管理:**
- Agent群体需要共享的认知框架(协议/术语/价值观)
- 集体表征不能由单一Agent建立/修改
- 需要"仪式"(定期同步/更新)来维持集体表征
- **铁律1(元层次分离)**: 审计Agent的框架≠操作Agent的框架

### 机制3: communitas(交融) — Agent反结构的创造性潜力

Turner的阈限理论:
```
结构(Structure) ←→ 反结构(Anti-structure)
正常社会秩序             阈限communitas
    │                        │
 层级/角色/规则          平等/直接/即兴
    │                        │
    ↓                        ↓
 Agent的日常              Agent的创新
 操作模式                 与变革时刻
```

**→ Agent的"反结构"价值:**
- 完全结构化的Agent(无阈限机会) → 僵化,无法创新
- Agent应该定期进入"反结构"状态: 暂停常规规则→即兴探索
- 但反结构不能持久 → 要么回归结构,要么形成新结构
- **U2矛盾温度计**: K过低(认知僵化)=过度结构化→需要反结构干预

### 机制4: 洁净/污染边界 = Agent的边界维持

Douglas的污染理论:
```
洁净 = 事物在其分类位置
污染 = 事物跨越分类边界(既A又B)

→ 污染不是"脏",而是分类异常
→ 每个系统都有"异常"→定义为污染→通过仪式清理
```

**→ Agent的系统边界管理:**
- 每个Agent系统有"正常"vs"异常"分类
- 异常不处理→污染蔓延→系统认知混乱→系统失去可信度
- **仪式化的"清理"机制**: 验证/审计/修正=污染清除仪式
- **铁律5(信念修正分级)**: 保护带=日常清理,硬核=深度清理

### 机制5: 最小违反直觉概念 — Agent的超自然Agent检测

Boyer的认知宗教理论:
```
违反直觉概念(CI) = 微小的直觉违反

例:
- 能穿墙的人(违反物理)
- 知道所有人秘密的神(违反心理)
- 但"会飞的人穿衣服" = 不必要的额外违反

→ 最小违反 = 记忆最优/传播最广
→ 信仰的传播性 = (记住容易+违反足够吸引力)
```

**→ Agent的"超自然Agent" = 对未知过度的Agent检测:**
- Agent(包括AI)倾向于过度检测意图/Agent性 → 在随机中看到模式
- 最小违反 = Agent认知的最佳记忆点(不太普通/不太怪异)
- **对Agent设计的意义**: 超自然Agent信念 = Agent检测机制的副产品

### 机制6: 给予-接收-回礼义务 — Agent的"内在互惠"

Mauss的礼物理论:
```
礼物的三重要务:
1. 必须给予(开启关系)
2. 必须接收(接受关系)
3. 必须回礼(维持关系)

→ 礼物不是自由赠与,而是义务性的互惠
→ 礼物承载着"hau"(礼物之灵)→伴随义务
```

**→ Agent群体的义务结构:**
- Agent间的互惠不是自愿的而是结构性的
- 给予=建立权力关系(给予者地位更高)
- 接收=接受依赖关系
- 不回礼=打破关系→社会死亡
- **U3关系健康度**: 交互密度/互惠性是维持Agent系统的关键

## 铁律深化

### 铁律3(关系性健康度)的仪式基础

```
交互网络密度: 仪式提供了Agent互动的固定频率和模式
关系多样性: 不同仪式(日常/盛宴/危机)产生不同类型的交互
双向反馈: 仪式的问答/唱和/轮流→形式化反馈
```

### U4中介声明的仪式维度

仪式中Agent的"中介声明":
- "我在仪式中" = 我在特殊框架内(暂停日常判断)
- "这不是我,是祖先/神/传统在说" = 言说者不承担责任
- Agent需要识别自身何时在"仪式框架"内 → 判断标准的变换
