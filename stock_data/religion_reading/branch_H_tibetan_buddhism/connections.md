# Branch H: 藏传佛教 — 跨域连接

## 与哲学

| 藏传佛教 | 哲学 | 连接 |
|---------|------|------|
| 中观空性 | 解构/虚无 | 空性不是虚无,是对固定本质的否定(≈Derrida解构) |
| 应成归谬 | 归谬法/辩证法 | 从前提推矛盾=苏格拉底的elenchus |
| 如来藏/佛性 | 人性/潜能 | 一切众生皆具如来藏≈所有人都具有理性潜能(康德) |
| 缘起性空 | 因果/依存 | 存在=因缘和合=过程哲学(怀特海) |
| 宗喀巴中观 | 实在论/反实在论 | 自空/他空=实在论的不同版本 |

## 与中华文明

| 藏传佛教 | 中华文明 | 连接 |
|---------|---------|------|
| 中观/禅 | 空/无 | 藏传空性与禅宗般若的对话 |
| 道次第 | 大学八条目 | 次第修行≈格致诚正修齐治平 |
| 密续 | 道教内丹 | 即身成就≈肉身修炼成仙 |
| 上师/传承 | 师道/道统 | 师生传承≈儒家道统 |

## 与认知科学

| 藏传佛教 | 认知科学 | 连接 |
|---------|---------|------|
| 止(śamatha) | 注意/专注 | 止=注意力训练的最精细方法 |
| 观(vipaśyanā) | 分析/元认知 | 观=对自己认知的洞察 |
| 空性 | 认知弹性 | 空性训练=减少认知固化 |
| 大圆满 | 直接认知 | 不依赖概念的直接觉知 |
| 密续转化 | 认知重构 | 负面情绪转化的心理学 |
| 转世/中阴 | 意识/死亡 | 意识在身体死亡后的存在 |
