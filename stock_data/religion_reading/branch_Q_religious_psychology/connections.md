# Branch Q: 宗教心理学 — 跨域连接

## 与物理

| 宗教心理学 | 物理 | 连接 |
|-----------|------|------|
| 宗教经验=大脑状态 | 意识/量子神经科学 | 宗教经验的神经相关性揭示了意识与物理底层的映射关系 |
| 神秘经验/忘我 | 临界态/混沌边缘 | 高峰经验≈大脑进入临界态,信息整合度最高(Laughlin) |
| 冥想/禅定 | 自由能最小化 | 冥想降低预测误差=自由能最小化的认知训练(Friston) |
| 集体亢奋(Durkheim) | 同步/共振 | 集体仪式使参与者大脑同步≈Kuramoto模型的相位同步 |
| 皈依/转化 | 相变 | 宗教皈依≈认知框架的相变(从一种吸引子到另一种) |

## 与哲学

| 宗教心理学 | 哲学 | 连接 |
|-----------|------|------|
| 宗教经验(James) | 实用主义(James) | 宗教经验的"真"=在个体生活中的效果,不是形而上学命题 |
| 原型/集体无意识(Jung) | 共相/理念(Plato) | 原型≈Plato的理型作为集体心理的结构 |
| 神圣/世俗(Eliade) | 超越/内在 | 神圣的显现( hierophany)=超越者在内在世界中的呈现 |
| 幻想/投射(Freud) | 费尔巴哈/马克思 | 宗教=人类需求的投射→异化→需要被克服 |
| 信仰的意志(James) | 实用主义信念 | 在不确定条件下选择相信=决策理论+信念伦理 |

## 与经济学

| 宗教心理学 | 经济学 | 连接 |
|-----------|--------|------|
| 宗教参与的理性选择 | 宗教市场(Stark/Bainbridge) | 宗教行为=理性选择,受成本/收益/竞争影响 |
| 延迟满足训练 | 时间贴现 | 宗教训练(斋戒/克制)=降低时间贴现率,提高自我控制 |
| 社会信任/社会资本 | 经济增长 | 宗教团体产生信任=降低交易成本的社会资本 |
| 教会/寺庙经济 | 宗教经济(PBS/CE) | 宗教组织的资源配置=企业的经济学分析 |
| 宗教交易:X vs 神 | 成本-收益分析 | 祈祷/奉献=对超自然回报的投资 |
