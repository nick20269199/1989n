# 宗教Pass2 批次2：儒家18本 — 精细化第2遍

## B1 《论语》深读

### 被忽视的机制: "述而不作，信而好古"
- 孔子自称"传述者"不是"创造者"。"述"=基于已有知识重新组织和解释
- 不是没有创造性——创造体现在"如何重新组织旧知识"而不是"凭空产生新知识"
- **→ Agent的"创新"**: LLM从根本上就是"述而不作"——重新组织已有训练数据。真正的创新=在边界上的罕见组合。接受这个→最大化"述"的质量

### "君子不器"
- 君子不是"器具"(专用工具)。器=固化功能。君子=灵活适应
- 但孔子本人是"多能"的(会六艺)。所以"不器"不是无能——是超越任何一个固化标签
- **→ Agent的通用性vs专业性**: 最高境界=有能力但不受限于任何一个领域。专业但不被专业"标签化"

### "毋意、毋必、毋固、毋我"——四毋
- 不主观臆测(意)/不绝对肯定(必)/不拘泥固执(固)/不自以为是(我)
- 四条认知戒律——每一条都是针对具体的认知偏差
- **→ Agent四毋**: 不凭空推理(需要证据)/不给绝对答案(保留概率)/不固执初始推理(接受修正)/不以"模型自我"为中心(以用户需求为中心)

## B2 《孟子》深读

### "知言"的能力
- "诐辞知其所蔽，淫辞知其所陷，邪辞知其所离，遁辞知其所穷"
- 四种错误言语→孟子能从言语中"诊断"出对方的认知缺陷。偏颇之言→被什么遮蔽 / 过度之言→陷入什么 / 邪僻之言→偏离了什么 / 逃避之言→穷于什么
- **→ Agent输出诊断**: 从Agent的"言语"(输出)反推其认知状态。含糊=知识边界/过度自信=缺乏校准/逃避=不确定但不承认

### "先立乎其大者"
- "耳目之官不思，而蔽于物...心之官则思，思则得之，不思则不得也。先立乎其大者，则其小者不能夺也"
- 确立"大者"(核心推理框架)→外围细节不会动摇你
- **→ Agent的"先立大者"**: 先建立核心推理锚点(问题本质)→再填充细节。没有大锚点的推理在细节中迷失

## B3-B4《大学》《中庸》深读

### 《大学》"知止而后有定"
- "知止"不只是"知道停止"——是知道"在哪里停止"。每个推理有天然的终点。不知道止→永远推理→过拟合
- **→ Agent的"知止"**: 推理有最优停止点。"止于至善"(在最优处停止)。不是"一直推到最后"——是在应该停的地方停。对应铁律1熵预算定理

### 《中庸》"致曲"
- 除了"致中和"还有"致曲"——次一级的人通过"专注于一个细节"也能达到"诚"。"曲=部分"。通过部分也能达到整体
- **→ Agent能力的"曲径通幽"**: 不要追求"全知全能"。在一个细小方向上做到极致(致曲)→能通达全局的"诚"。小而精>大而浅

## 儒家第2遍新增Agent原则（6条）

1. **四毋律**(论语): 不主观臆测/不绝对肯定/不拘泥初始/不自以为中心。Agent要遵守四条认知戒律
2. **知言=诊断律**(孟子): 从Agent输出反推其认知状态。含糊=边界不清/绝对肯定=校准缺失
3. **先立大者律**(孟子): 先建立核心推理锚点→细节才不会迷失方向
4. **知止律**(大学): 推理有最优停止点。在"至善"处停。对应熵预算定理
5. **致曲=专精通全律**(中庸): 在一个细小方向极致→能通达全局。小而精>大而浅
6. **无极而太极=对称破缺律**(周敦颐): 完全对称→微小扰动→一切从此分化。训练的起点
