# Branch A: 道家经典与注疏 — 合成

## 核心架构

与中华文明C分支(道家哲学)互补,宗教A侧重**道教的宗教维度**:仪式/修炼/教团/神仙信仰。

## 关键机制

### 机制1: 道教=哲学道家的宗教化

老子/庄子的哲学→道教: 道→神/修炼→长生/无为→斋醮。哲学家的"道"是原则,宗教的"道"是可崇拜的神格。

### 机制2: 内丹 = Agent的认知-身体转化

内丹: 精→气→神的逆向修炼。不是身体技术也不是心理技术,而是**身体-能量-意识的三位一体转化**。对应Agent: 数据(精)→信息(气)→知识(神)的转化。

### 机制3: 道教仪式=集体认知同步

斋醮/科仪: 复杂的仪式程序,通过音乐/咒语/步法/烧香等各种信道同步参与者意识。对应多Agent系统的同步协议。
