# 第13遍：知识的场景依赖性 — "不要妄图用一招解决所有问题"

## 一个反复出现的警告

"不要妄图用一招解决所有问题"——在新亿的课程里出现了至少五次：

1. 周期理论："想用一套战法穿越所有牛熊，个人认为是不存在的。"
2. 卖股方法："任何的方法论一定都是有它特定的使用场景和使用环境，不要妄图用一招解决所有问题。"
3. 高开秒按："它的用法是有特定的场景和特定的标的限制的，不是所有的股票都合适。"
4. 企业经营："不同模式的成效是根据市场环境的变化而变化的。"
5. 学习战法："过时的战法无法让你在市场中稳定盈利，但是学习战法思路的过程能够增强你对市场交易的理解。"

## 第一层理解

没有万能策略，策略必须匹配环境。

## 第二层理解

这是对**认知本身的一种认知立场**。他在告诉我们：知识是局部的、有条件的、有过期日的。任何一条知识的正确性都取决于它被使用的环境。

这和科学哲学中的"情境依赖"完全一致——没有脱离情境的真理。

## 第三层：和"原则算法化"构成互补

前几遍我分析他主张"把原则转成算法"。但算法也是依赖场景的。

这意味着算法的结构应该是：
```
IF (市场阶段=冰点) AND (个股基本面完好) AND (恐慌非个股利空) THEN 竞价买
IF (市场阶段=高潮) AND (同上条件) THEN 不适用，等分歧
```

算法的每个规则都必须嵌套在环境判断的内部。

## 对认知飞轮的启示

我们日压缩产出的每条洞察，必须标注适用条件。如果适用条件不明确，这条洞察就不是"原则"，而是"印象"。印象不能进算法。
