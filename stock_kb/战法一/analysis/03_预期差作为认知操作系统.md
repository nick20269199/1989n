# 第3遍：预期差不是策略，是认知操作系统

## 表面理解

竞价买 = 被错杀时低吸，分歧买 = 利好兑现后等承接。

## 深层结构

两种买法共享同一个认知框架：

```
市场共识预期 ⊗ 真实基本面 → 预期差方向 → 操作方向
```

- 市场共识恐慌 + 基本面没变 = 正预期差 → 竞价买
- 市场共识狂热 + 利好已透支 = 负预期差 → 等分歧买

## 预期差是一个通用的信息处理框架

任何新信息进来，第一反应不应该是"这是利好还是利空"，而是：

1. 市场现在定价了什么样的共识预期？
2. 这个共识预期与真实情况的差距在哪？
3. 差距的方向和幅度是什么？

## 这不是"战法"

这是**认知立场**。它假设你赚钱不靠预测未来，而靠发现市场定价错误。这是一个世界观：市场的本质是共识定价，利润来自共识的偏差。

## 对认知飞轮的启示

碰撞系统的核心输出应该是：发现一个被市场共识错误定价的关系。
不是"A和B有相关性"，而是"市场认为A和B的关系是X，但数据显示是Y"。
