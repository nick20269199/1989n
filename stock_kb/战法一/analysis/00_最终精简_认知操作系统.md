# 新亿认知操作系统 — 20遍深读后的最优精简

本文是对30张课程图片 + PDF买股方法论的20遍深读后，提炼出的认知架构。

## 一、核心认知操作系统（一句话）

**市场永远在错误定价。你的全部工作是：用算法化规则在执行层面绕过情绪脑，持续发现共识预期与真实基本面的偏差，并在偏差被修复之前行动。**

## 二、十三个认知原则

### 原则1：预期差是第一性原理

一切分析的第一问不是"利好还是利空"，而是"市场正在定价什么共识？这个共识对吗？"

- 竞价买：市场共识恐慌 → 定价了利空 → 个股基本面没被影响 → 正预期差 → 竞价直接买
- 分歧买：市场共识狂热 → 定价了利好 → 利好已被透支 → 不存在正预期差 → 等共识破裂后再买

**操作公式：** `市场共识 ⊗ 真实情况 → 预期差方向 → 操作方向`

### 原则2：情绪脑比智力脑快25倍 → 原则必须算法化

脑科学事实：情绪脑（5000万年）比智力脑（200万年）古老25倍。市场压力下情绪脑必然接管智力脑。

意志力对抗情绪脑 = 必输。唯一解：**在情绪脑激活之前，算法已经给出信号。**（达利欧 + 林彪的共同答案）

**操作公式：** `原则 → 可执行规则（含适用条件+执行动作+失效信号）→ 代码化 → 在情绪脑反应前触发`

### 原则3：比率异常检测取代随机碰撞

林彪的认知方法论：不看绝对数据，看比率。手枪/步枪比例、军官/士兵比例偏离基线 → 反推出隐藏结构（指挥所）。

我们对碰撞系统的正确理解应该是：
- 定义关键比率组（如北向资金/成交量、炸板率/连板率、大单净买入/总成交）
- 持续跟踪比率的历史基线
- 当任一比率偏离2σ时触发深度研究
- 研究目标：这个比率异常揭示了什么隐藏的市场结构变化？

**操作公式：** `持续监控(关键变量A/关键变量B) → 偏离基线2σ → 反推隐藏结构`

### 原则4：从高维到低维是唯一的认知顺序

每次分析、每次决策都遵循：天时（指数/情绪周期）→ 地利（主线/题材方向）→ 人和（个股/买点）。

反了（先看个股再看大盘）= 确认偏误，你会为个股走势找理由。

**操作公式：** `先定位周期阶段 → 再定位主线方向 → 最后看个股机会`

### 原则5：规则有有效期

"想用一套战法穿越所有牛熊，个人认为是不存在的。"

每条规则必须标注：
- 适用哪个周期阶段（冰点/启动/主升/高潮/衰退）
- 在哪个阶段会失效甚至反向
- 当前处于哪个阶段（每日更新）

**操作公式：** `规则 = 执行动作 + 适用前提(周期阶段) + 失效条件`

### 原则6：认知跃迁需要ego death，不是知识增量

作者从第三阶段到第四阶段的跃迁，触发点是章安强帮他翻领口的那个行为——不是学了新理论，而是自我叙事被击穿后重建。

日压缩必须包含一个字段：**今天有什么证据挑战了我的核心假设/自我认知？** 没有这个，认知飞轮只是在同一框架内自我强化。

**操作公式：** `认知跃迁 = 遭遇反例 → 自我叙事崩塌 → 框架重建`

### 原则7：复盘是认知迭代的科学循环

PDCA不是管理工具，是波普尔证伪主义在交易中的实现：
- Plan = 把模糊认知转化为可验证假设
- Do = 实盘验证（必须实盘，模拟盘没有情绪脑参与）
- Check = 市场给出答案后对照检验
- Act = 根据检验结果升级认知、修改规则

**操作公式：** `假设 → 实验 → 数据 → 修正 → 新假设`

### 原则8：多源锚定加固信念

同一个结论从商业/历史/政治/军事四个不相关领域得到印证 → 信念不会被单一领域的反例动摇。

碰撞系统的正确输出不是"A和B有相关性"，而是"同一个模式在资金面、情绪面、技术面三个独立维度被同时观察到"。

**操作公式：** `可信度 = 独立验证源的数量`（一个源=参考，三个源=行动）

### 原则9：用行为塑造认知

不是先想明白再做，做的过程让你想明白。学习过时战法不是浪费时间，因为学习过程本身在重塑你的认知结构。

日压缩不是整理经验，日压缩的过程本身在重新加工今天的经历。

**操作公式：** `行为 ⇄ 认知`（双向因果，非单向）

### 原则10：AI是认知延伸，不是替代

"AI不会淘汰人类，而是会用AI的人类会淘汰不会用AI的人类。"
"把你的原则转换成算法，让计算机和你一起决策。"

人的角色：定义原则、判断框架有效性、处理模糊情境。
AI的角色：执行规则、监控异常、在情绪脑接管前发出警报。

**操作公式：** `人定义原则 → AI执行和监督 → 人根据异常反馈修正原则`

### 原则11：坚持不是意志力问题，是工程问题

坚持可以被方法论训练（三人推磨法 = 三人互相监督推动）。认知飞轮必须有外部强制力，不能假设自己会坚持执行。

周审计不能AI自己审计自己。必须有外部输入（用户）。

**操作公式：** `坚持 = 社会协作机制 + 外部约束力`，而非靠内在意志

### 原则12：真正的学会是凝练

"弱水三千只取一瓢"——知道所有方法没用，能对自己模式内的个股凝练出固定规则才叫学会。

凝练 = 从自己的反复实践中结晶出来的规则，含：适用条件 + 执行动作 + 失效信号。

日压缩的"认知增益"必须是凝练级别的输出，不能是"学到了什么"的印象。

**操作公式：** `凝练 = 适用条件 + 执行动作 + 失效信号`（缺一则未凝练）

### 原则13：辨识度（共识跟随）与预期差（共识挑战）是互补

- 辨识度：选什么标的 → 跟随共识（大众认为谁最美）
- 预期差：什么时候入场 → 挑战共识（大众在什么地方错了）

两个看似矛盾的框架在同一体系内共存。不是趋势跟踪也不是逆向投资，而是**选标跟随共识，择时利用共识的错误**。

**操作公式：** `标的选择 = 共识跟随` | `入场时机 = 共识偏差`

## 三、认知处理管道

```
第1层 [天时定位]：指数择时 + 情绪周期阶段判定
  ↓ 输出：当前处于冰点/启动/主升/高潮/衰退
第2层 [地利扫描]：主线系统 + 题材轮动方向
  ↓ 输出：当前主线板块、主流资金方向
第3层 [比率监控]：林彪式关键比率异常检测
  ↓ 输出：偏离基线的异常比率及其方向
第4层 [预期差分析]：对每个异常问"市场共识是什么？偏差在哪？"
  ↓ 输出：发现被错误定价的关系
第5层 [假设生成]：将预期差转化为可验证的明日假设
  ↓ 输出：Plan（可证伪的预测）
第6层 [算法执行]：通过算法化规则执行操作（绕过情绪脑）
  ↓ 输出：Do（实盘执行记录）
第7层 [复盘验证]：对照假设检查结果，凝练规则
  ↓ 输出：Check + Act（认知增益 + 规则更新）
第8层 [信念审计]：周期性检查核心信念是否被挑战
  ↓ 反馈到第1层，修正框架 → 下一循环
```

每一层都是下一层的过滤器。天时错了，地利就没意义。地利错了，选股就没意义。没有比率异常，预期差分析缺少锚点。没有预期差，假设是瞎猜。

## 四、对认知飞轮的五个核心改动

1. **日压缩结构改为高维→低维**：天时判断 → 比率异常 → 预期差发现 → 明日假设 → 心态自检
2. **碰撞系统改为比率监控**：不再随机配对，改为持续跟踪关键比率，偏离2σ时触发深度研究
3. **每条洞察必须凝练级输出**：含适用条件 + 执行动作 + 失效信号，否则标为"未凝练"
4. **周审计加入ego death检查**：本周什么证据挑战了核心假设？
5. **认知飞轮终点不是文档，是可执行规则**：每条规则进入算法库，标注周期阶段依赖
