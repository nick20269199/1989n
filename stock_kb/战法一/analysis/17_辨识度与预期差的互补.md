# 第17遍：辨识度 — 审美从众的认知机制

## 辨识度的定义

"你可以把股票当作是美女，现在有一排美女站在了我们所有股民的面前，我们要选出那个最美的女子。……对于做股票而言，我们要选的是大部分人认为的美女，也就是大众之心所选之股，尤其是大资金的审美；当你的审美逻辑是跟随大众之心的选择而选时，并不是一味的选择以自我为标准的方式，你就可以将最具辨识度的股票选出并第一时间上车。"

## 这不是选股技巧，这是一个认知立场

你的审美不重要。大众的审美才重要。辨识度 = 大众认为谁最美。

这和预期差框架构成互补：
- 预期差：市场共识可能是错的 → 发现定价错误
- 辨识度：市场共识决定了资金流向 → 跟随共识选标的

两个看似矛盾的认知框架在同一套体系里共存。这就是为什么他的体系不是简单的"跟随趋势"或"逆向投资"，而是：**在选标的时跟随共识，在择时上利用共识的错误。**

## 对认知飞轮的启示

碰撞系统需要两个不同的模式：
1. 共识发现模式：辨识度 = 市场在认可什么？大资金在看什么？
2. 共识挑战模式：预期差 = 市场在什么地方错了？共识的缺陷在哪？

这两者不矛盾。一个给"选什么"提供方向，一个给"什么时候买"提供透视。
