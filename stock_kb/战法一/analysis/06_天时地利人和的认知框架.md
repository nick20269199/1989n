# 第6遍：天时地利人和 — 三维认知脚手架

## 三层不是比喻，是认知结构

新亿把看盘逻辑总结为三句话：
1. 识大局（站在山顶）→ 天时 → 指数择时 + 情绪研判
2. 观人和（站在山腰）→ 地利 → 主线系统 + 题材方向
3. 抓核心（回到山脚）→ 人和 → 模式系统出个股

## 为什么是"从高维到低维"

每次复盘和每次看盘都用同样的顺序：先看指数环境和情绪周期 → 再看板块和主线 → 最后看个股和买点。

这意味着：**个股的任何分析如果不先定位它在天时地利中的位置，就是噪音。**

你不能直接分析一只股票的技术形态。你必须先知道：
- 现在是什么周期阶段？（天时）
- 它在不在主线板块里？（地利）
- 它是不是板块里的核心标？（人和）

## 对认知飞轮的启示

我们现在的碰撞系统是二维的（变量A × 变量B），但缺少一个维度层级。应该：
- Tier 1：先确定天时（宏观周期阶段）
- Tier 2：再确定地利（当前主线/轮动方向）
- Tier 3：最后在Tier1和Tier2的约束下做碰撞

不是所有碰撞对在所有市场环境下都有意义。碰撞必须先通过周期阶段的过滤器。
