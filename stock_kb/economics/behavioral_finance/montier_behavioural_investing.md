# Montier《行为投资》— 精读

## 一、这本书在解决什么问题

传统金融教"市场是有效的 → 你不可能战胜市场"。行为金融说"市场是无效的 → 但你还不能战胜市场，因为你的大脑就是无效的原因"。

Montier 的核心命题是：**知道偏差不等于能避免偏差**。这不是一本"偏差科普"，而是一本"你知道了偏差之后怎么办"的操作手册。

## 二、七个最致命的交易偏差（及对策）

### 偏差1: 过度自信 — 所有偏差之母

**表现:**
- 置信区间设太窄（你觉得"大概率到100元"，实际概率只有40%）
- 预测过度（你觉得知道下周走势）
- 控制幻觉（你觉得你的操作会影响股价）

**蒙特利尔的对抗方法 — "事前检验" (Pre-mortem):**
```
买入前写一段话：
"假设今天买进，6个月后跌了30%。原因是什么？"
—— 这强迫大脑从"看多模式"切换到"找错模式"
```

**A股映射:** 涨停板追入前，强制写下跌原因。如果写不出3条合理解释 → 你还没想清楚风险。

### 偏差2: 证实偏差 — 你只看你想看的

**表现:** 决定买一只票后，只找利好信息，忽略利空。

**蒙特利尔的对抗方法:**
```
建仓前必须回答：
"什么证据会让我改变主意？"
如果答不出来 → 你没有可证伪的假设 → 你不是在投资，是在信仰
```

**A股映射:** 龙虎榜出来后，如果你买了，你倾向于解读为"主力进场"；如果你没买，你倾向于解读为"游资对倒"。同一数据，不同解释 → 证实偏差。

### 偏差3: 处置效应 — 卖赢持亏

**核心机制**（来自 Kahneman 前景理论）:
- 亏损区 → 风险寻求 → 继续持有等反弹
- 盈利区 → 风险规避 → 过早卖出锁定利润

**蒙特利尔的对抗方法 — "如果你现在没有持仓，你会买入吗？"**
```
对每笔持仓每天问：
"如果我现在空仓，以当前价格，我会买入这只票吗？"
如果不会 → 为什么还持有？

这绕过"参考点"陷阱——你的买入价不是决策依据
```

**A股映射:** 这是散户最大的系统性亏损来源。浮亏的票死扛（等回本），浮盈的票跑得快（怕利润回吐）。结果：账户里剩下的全是烂票。

### 偏差4: 可用性启发式 — 最近发生的 = 最可能发生

**表现:** 刚经历一轮牛市 → 觉得还会涨。刚经历暴跌 → 觉得还要跌。

**蒙特利尔的对抗方法 — 检查基础概率:**
```
"历史上在这种估值/这种位置，后续6个月的正收益概率是多少？"
—— 用统计数据代替最近记忆
```

### 偏差5: 羊群效应 — 信息级联

**表现:** 别人在买所以我也买。

**蒙特利尔的区分:**
```
信息模仿（理性）：别人可能知道我不知道的信息 → 可以跟
欲望模仿（非理性）：别人买所以我也想买 → 不能跟
```

区分方法：你能说出别人知道什么你不知道的信息吗？如果说不出来 → 是欲望模仿。

### 偏差6: 锚定 — 买入价成为参考点

**表现:** 跌到买入价了 → "等反弹再出"。涨到买入价了 → "到成本了快跑"。

**对抗方法:** Montier 建议用**基本面锚**代替**价格锚**:
```
价格锚：我买在10元 → 10元是参考点
基本面锚：这只票的合理估值区间是8-15元 → 8元以下是机会，15元以上警惕

—— 每次看价格，先问：估值变了吗？不是问：价格比我买时高还是低
```

### 偏差7: 后见之明 — "我早就知道"

**最危险的偏差**，因为它在阻止你学习：
```
- 涨了后："我早就知道会涨" → 强化了你的"预测能力幻觉"
- 实际上你当时只是"觉得会涨"，并不是"确认会涨"
- 两者差别：前者是概率判断，后者是确定性判断
—— 但你的大脑把它们混为一谈
```

**Montier 的日记法:**
```
每次交易记录：
1. 为什么买/卖（逻辑）
2. 置信度（0-100%）
3. 关键验证点

回头看时：不是看你"猜对没"，而是看你"在当时的置信度下，决策是否合理"
```

## 三、蒙特利尔最实用的三个框架

### 框架1: 行为检查清单

买入前逐项检查（Montier 原版 + A股适配）:

| # | 问题 | 偏差 | A股验证 |
|---|------|------|---------|
| 1 | 我买这只票是因为别人在买吗？ | 羊群 | 龙虎榜/热点板块 |
| 2 | 我对这只票的看好，有可证伪的假设吗？ | 证实 | "如果XX发生，我就认错" |
| 3 | 我买的理由是这个价格便宜，还是因为这个票"好公司"？ | 锚定 | 好公司≠好投资，价格呢？ |
| 4 | 最近关于这只票都是好消息吗？我在选择性注意吗？ | 可用性 | 翻利空新闻，不只看利好 |
| 5 | 如果现在空仓，我会买吗？ | 处置 | 持仓不是买入理由 |
| 6 | 我这次操作的预期回报/风险比是多少？ | 过度自信 | 算赔率，不算胜率 |
| 7 | 如果错了，我什么时候止损？ | 损失厌恶 | 提前写，不是到了再想 |

### 框架2: 价值投资的行为解释

Montier 认为，价值投资之所以有效，不是因为"市场最终会回归价值"，而是因为：

```
价值股 = 被厌恶的股票（坏消息/低增长/冷门）
—— 买入它们需要逆人性（对抗羊群+可用性）
成长股 = 被喜爱的股票（好消息/高增长/热门）
—— 买入它们顺人性（追随羊群+过度外推）

价值溢价 = 对逆人性行为的补偿
不是你聪明，而是你愿意做别人不愿意做的事
```

**A股映射:**
- 热门板块的"龙"追到就是赚到吗？统计显示大部分追龙头的人亏钱
- 冷门板块的低估票，拿着难受但长期胜率高
- 问题是：你能**持有**冷门票多久？Montier 说"价值投资需要耐心，而人类天生没有耐心"

### 框架3: 心理会计的破除

Montier 最狠的一招：

```
你同时持有：
A: 盈利20% — 想卖（怕利润回吐）
B: 亏损30% — 想持（等回本）

Montier 问：如果把 A 和 B 都卖了，拿到现金，你会用这笔钱买 A 还是 B？
大部分人两者都不买——这说明你既不该持有 A 也不该持有 B。
```

**操作规则:**
> 对每笔持仓，每季度做一次"现金测试"：如果现在你持有的是现金，你会按当前价格买这只票吗？

## 四、与已有知识框架的连接

### 与 U 公式的连接

| U公式 | Montier 对应 | 强化 |
|-------|------------|------|
| U2 矛盾温度 | 认知失调=持有浮亏票找理由不卖 | 事前写"什么证据会让我认错" |
| U4 认知中介 | 每个判断都基于某个"参考点" | 用基本面锚替代价格锚 |
| U5 信念保护 | 价值投资的信念=硬核，过度自信=保护带 | 区分核心信念vs可修正判断 |
| U6 自我监控 | 过度自信→预测误差→触发自我审查 | 事前检验(Pre-mortem)作为U6触发器 |
| U7 对齐深度 | 100%合规但对偏差无深度理解=低对齐 | 日记法强制事后归因，不只是检查 |

### 与交易纪律的连接

| 纪律 | Montier 增强 |
|------|-------------|
| 止损 | 处置效应告诉你为什么你做不到止损 |
| 六问自检 | 行为检查清单直接补充 |
| R7 超大单 | 超大单是"别人知道的我不知道的信息"→信息模仿的理性使用 |
| 置信度 | Montier的日记法强制记录置信度 |

### 与切面深挖的连接

这句评价链接回之前切面的盲区：

> "知道偏差≠能避免偏差" 解释了为什么切面1（Thaler三部曲）的框架对但没有检验——知道赢家的诅咒不等于你能在涨停板前停下来。

## 五、三条可执行规则

**规则1: 买入前 Pre-mortem**
> 写一段话来回答"如果这只票6个月跌了30%，原因是哪三条？"写不出来不动手。

**规则2: 每日空仓测试**
> 收盘时对每只持仓问："如果我现在空仓，以当前价我会买入吗？"不会 → 明天卖。

**规则3: 交易日记三要素**
> 每次操作记录: 买入逻辑(一句) + 置信度(0-100%) + 止损位。周回顾只看"置信度是否校准"，不看盈亏。
