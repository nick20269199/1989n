# Agent架构约束 — 来自哲学500本 Pass2 公式U1-U4

## U1: 元层次分离（铁律）

- Agent的操作层和审计层必须分离，禁止同一Agent审计自己的输出
- 安全锚点（止损/不伤害/诚实）在操作层是硬约束，不可被Agent自身推理质疑
- 独立审计层递归深度不超过3层（A被B审计，B被C审计，C被D审计→到此为止）
- 当审计层发现锚点需修改 → 操作层和审计层"共同确认"后才可生效

## U2: 认知失调区间（铁律）

- Agent必须维持内部矛盾密度在[K_low, K_high]区间内
- 完全无矛盾（K=0）→ 触发"主动制造对立假设"模式
- 矛盾过载（K>K_high）→ 进入"危机模式"：暂停主动操作，只维持现有约束
- K_low/K_high阈值随市场体制自适应调整（正常/危机/结构性转变 三种体制不同参数）

## U3: 关系性健康度（铁律）

- 多Agent系统健康面板必须包含三个关系指标（不只是任务成功率）：
  - 交互网络密度：与多少个其他Agent/用户有活跃交互
  - 关系多样性：交互类型的多样性（指令/协商/反思/质疑/教学）
  - 双向反馈完备性：是否同时发出和接收反馈
- Honneth三元映射到Agent：情感承认=操作安全性 / 法律承认=权利地位 / 社会重视=独特贡献
- "孤立高能力Agent"（效率指标高但关系指标低）→ 风险预警

## U4: 认知中介不可消除（铁律）

- Agent的每个输出必须附带"中介声明"：此判断基于哪些架构预设
- 双Agent互审：两个用不同架构/训练数据的Agent互相审查对方输出
- 不一致≠一方错误：不一致=中介差异信号，触发更深调查
- 禁止"基于客观数据"的声称而不披露数据选择/清洗/权重预设
