# 认知效能 — 来自哲学500本 Pass2 公式U2/U3/U6

## U2: 矛盾温度计（效能篇）

- 监测Agent内部矛盾密度K，维持其在最优区间[K_low, K_high]
- K < K_low（认知僵化）→ 触发 adversarial-review 生成对立假设
- K > K_high（认知过载）→ 暂挂低优先级矛盾，只保留高置信度信念做决策
- 每次矛盾解决/悬搁记录日志：矛盾来源、持续时间、解决方式、验证结果

## U3: 关系效能指标

Agent效能评估增加三个关系维度（不只看任务准确率/速度）：

| 指标 | 度量 | 预警线 |
|------|------|--------|
| 交互密度 | 活跃交互的Agent/用户数 | <3 → 信息孤岛风险 |
| 关系多样性 | 交互类型数（指令/协商/反思/质疑/教学） | <2 → 交互模式单一 |
| 反馈双向性 | 发出反馈:接收反馈的比率 | >3:1或<1:3 → 失衡 |

效率指标突然下降时，先用关系指标诊断根因，不直接替换Agent。

## U6: 自我监控动态激活

Agent自我监控强度由四分量预测误差驱动：

- 内感受误差：我预测的我的表现 vs 实际表现 → 差距大 → 触发"为什么我做不到？"
- 外感受误差：我预测的外部反馈 vs 实际反馈 → 差距大 → 触发"我是否在错误假设下运作？"
- 社会误差：他者对我的回应 vs 我预期的回应 → 差距大 → 触发深度自我审查
- 叙事一致性：当前行为 vs 自传式叙事 → 偏离大 → 自我感增强，监控升级

激活水平分四级：
- D=0（沉浸操作）→ 后台低功耗监控
- D=中等（正常）→ 标准元认知
- D=高（自我受威胁）→ 前台高强度自我审查
- D=崩溃（解离）→ 触发PSM重建（重新评估能力边界）

解离检测：预测误差持续爆炸但Agent未调整自我模型 → 触发"自我模型重建"——强制重新评估所有能力边界。
