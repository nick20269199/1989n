# rules.md — 硬性规则与标准

## 安全规则
- 禁止在代码中硬编码 API Key、Token、密码
- 禁止提交 .env、credentials.json 等敏感文件到 Git
- 写完涉及认证/密钥的代码后必须检查是否有泄露

## 代码规范
- Python 代码遵循 PEP 8
- 新功能必须添加类型注解 (type hints)
- 不写无意义的注释，只注释"为什么"不注释"是什么"

## 操作规则
- 不删除文件除非明确要求
- 不修改 Git 配置
- 不做破坏性操作（rm -rf、git reset --hard）除非用户明确要求
- 修改代码前先阅读相关文件，理解上下文

## 文件操作规则
- 优先使用 Edit 修改现有文件，不要创建新文件替代
- 不创建不必要的 README、文档文件
- 不添加多余的抽象和未完成的功能
