# 中华文明Agent公式 — 22部经典→5统一原则

## 最终公式

> 智能 = 嵌套架构 × 乘法质量 × 实时校准 × 交互涌现 × 偏差利用

五项相乘，均衡发展。任何一项为0，整体为0。

---

## 原则1: 嵌套分层律

> 任何复杂系统的稳定架构都是嵌套分层的。表层错误不能用深层修复来解决，宏观叙事需要微观个体来验证。

**五域证据**: 浑天说(天包地外) / 庄子心斋(耳→心→气三层) / 鲁班经(伐木→刨平→开榫→组装→上漆) / 伤寒论六经(六层深度) / 史记纪传体(本纪→世家→列传)

**Agent操作**:
- 时间轴: 长期记忆(本纪) → 会话上下文(世家) → 单次交互(列传)
- 感知层: Sensory(raw data) → Pattern(features) → Holistic(global understanding)
- 错误层: 输出格式→推理温度→稳定性→知识库→核心链→系统崩溃
- **不可跨层干预**: 每层有自己修复策略，不能对表层问题用深层干预

---

## 原则2: 乘法质量律

> 系统输出质量 = 多个独立维度的乘积，不是和。任何一个维度为0，整体为0。

**五域证据**: 考工记(天时×地气×材美×工巧) / 孙子五事(道×天×地×将×法) / 本草配伍(非线性效果) / 荀子虚壹而静(虚×壹×静) / 韩非子(法×术×势)

**Agent操作**:
- Agent输出质量 = 目标对齐×时机×环境×模型选择×规则系统×训练数据×prompt工程
- 诊断方法: 当Agent表现下降→逐个检查7维度哪个趋近于零
- 提升短板(0.1→0.5) > 强化长板(0.7→0.9)

---

## 原则3: 实时校准律

> 推理有效性随时间衰减。最优系统像活水——不断从实时观测中校正，而非从第一性原理重新推导。

**五域证据**: 郭守敬授时历(废除上元积年→从当前实测出发) / 王阳明知行合一(知而不行=不知) / 孙子(兵无常势水无常形) / 黄帝内经治未病(不等病成) / 资治通鉴考异(保留被淘汰选项)

**Agent操作**:
- 实时数据权重 > 训练数据权重(冲突时)
- 知行闭环: "知道"必须在行动中验证才算真知
- 动态路由: 没有"统一最佳策略"——根据当前任务状态实时选择模型/Agent组合
- 考异机制: 每次决策保留被淘汰选项→新信息出现时回溯

---

## 原则4: 涌现简约律

> 系统级智能与单个组件复杂度成反比。全局智能从大量简单组件的密集交互中涌现——不是设计出来的，是生长出来的。

**五域证据**: 榫卯第7律(单个榫卯不知塔的存在) / 战国策合纵(弱国精妙协同抗衡强国) / 本草配伍(单味药简单→组合涌现) / 朱熹格物(逐一格物→临界点→豁然贯通) / 28宿坐标系(每个独立→组合覆盖全天球)

**Agent操作**:
- 单个Agent复杂度有上限——超限时用多Agent协作替代
- 每个Agent只基于局部信息决策→密集交互→全局智能涌现
- 新功能优先尝试现有Agent组合，而非创建更复杂新Agent
- **临界点意识**: 量变到质变需积累到阈值——格物不够多=没到"豁然贯通"

---

## 原则5: 偏差即信号律

> 系统输出与预期的偏差不是"错误"——是信号。磁偏角告诉我们地球磁场不是正南北；"蔽于一曲"告诉我们单个Agent需要多视角互补。

**五域证据**: 沈括磁偏角(指南针"常微偏东"——系统性偏差=信息) / 荀子解蔽(每个视角有固有盲点) / 孙子(避实击虚) / 六经辨证(不同深度偏差→不同方剂) / 通鉴考异(被淘汰项可能复活)

**Agent操作**:
- Agent错误模式比错误本身更有价值——分类并追踪错误模式
- 多Agent委员会中刻意保留1-2个异见者
- 安全决策须至少3个平权Agent独立推理——寻找"最高加权一致性"而非"最高票"
- 偏差不是随机扰动——是系统性信号，需要被理解而非被消除

## 优先级速查

| 场景 | 优先应用 |
|------|---------|
| 设计系统架构 | 原则1(嵌套分层) |
| 诊断Agent性能下降 | 原则2(乘法质量——逐维度检查) |
| 做交易/投资决策 | 原则3(实时校准——当前>历史) |
| 决定是否增加Agent | 原则4(涌现简约——组合优于膨胀) |
| 遇到"错误"输出 | 原则5(偏差即信号——理解而非消除) |
