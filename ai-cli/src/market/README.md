# 📊 A股集合竞价量价统计工具

## 功能

每天9:25分集合竞价结束后，自动抓取数据并生成报告，包含：

### 1. 市场总览
- 上涨/下跌/涨停/跌停数量
- 总竞价金额
- 主力资金净流入

### 2. 热门板块 TOP 10
- 各板块涨停数、涨跌比、平均涨幅
- 主力资金净流入

### 3. 热门题材 TOP 10
- 热度评分（涨停数+涨幅+资金）
- 涨停数、平均涨幅、主力资金

### 4. 资金流向
- 主力流入/流出 TOP 5
- 总竞价金额、主力净流入

### 5. 涨停分类
- 一字板 / T字板 / 换手板 / 趋势板

### 6. 竞价异动强势股
- 涨幅>3% + 成交量>1万手 + 主力净流入>100万

### 7. 自选关注（适合30万资金）
- 股价适中、流动性好、有资金关注的标的

### 8. 🎯 5-6月策略：大容量科技成长股
- 科技行业（半导体/AI/新能源/通信等）
- 流通市值>50亿
- PE合理（10-50）或有业绩支撑
- 有主力资金关注

### 9. ⚡ 7月策略：短线交易标的
- 高换手率>2%
- 成交量>2万手
- 波动>2%
- 30万资金能买
- 有题材概念

### 10. 📈 业绩优良标的
- PE在10-50之间
- 有主力资金流入
- 市值适中

## 使用方法

### 方式1：立即运行一次
```bash
bun run src/market/index.ts
```
或双击 `jingjia.bat`

### 方式2：持续监控（每5分钟刷新）
```bash
bun run src/market/index.ts --watch
```

### 方式3：定时模式（每天9:25自动运行）
```bash
bun run src/market/index.ts --schedule
```

### 方式4：使用批处理脚本
```bash
jingjia           # 立即运行
jingjia --watch   # 持续监控
jingjia --schedule # 定时运行
```

## 数据来源

- 东方财富免费API（`push2.eastmoney.com`）
- 非交易时间使用模拟数据展示格式
- 交易时间自动抓取真实数据

## 注意事项

- 集合竞价时间：9:15-9:25
- 数据在9:25后可用
- 建议每天9:25-9:30之间运行
- 报告自动保存为 `jingjia_日期_时间.txt`

## 策略说明

### 5-6月（当前）
- **风格**: 大容量、有业绩的科技成长股
- **关注**: 半导体、AI、新能源、通信等
- **选股**: 市值>50亿、PE合理、主力流入
- **仓位**: 单票不超过6万(20%)

### 7月（计划）
- **风格**: 短线交易
- **关注**: 高换手、有量、有题材
- **选股**: 换手率>2%、成交量>2万手
- **仓位**: 灵活控制
