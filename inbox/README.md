# 收件箱 — 从手机/GitHub 直接丢东西进来

## 怎么加

手机浏览器打开 github.com/nick20269199/1989n，点进 `inbox/` 文件夹：

| 你要加的 | 丢到哪里 | 怎么操作 |
|---------|---------|---------|
| 随手想法/交易灵感 | `inbox/ideas.md` | 打开文件 → 点铅笔 → 在底部加一行 `- [日期] 内容` |
| 看到的好文章/链接 | `inbox/links.md` | 同上，加链接+一句话说明 |
| 截图/图片 | `inbox/images/` | Add file → Upload |
| 报错/Bug | Issues 标签页 → New issue | 标题写清楚，正文贴报错 |
| 想研究的问题 | `inbox/questions.md` | 打开 → 编辑 → 加一行 |

## 我会读到吗

会。每天 `daily-load` 晨间08:07 自动从 GitHub pull 最新内容，然后读 `inbox/` 里所有未处理的内容。

## 处理标记

我读完会在条目后标记 `[processed]`。你加新内容时写在文件底部即可，已经 `[processed]` 的不要删（留作记录）。
